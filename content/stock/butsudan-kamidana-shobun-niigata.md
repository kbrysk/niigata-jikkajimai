# 仏壇・神棚・位牌の処分｜新潟市・長岡市で市のごみに出せるか、閉眼供養の考え方、相談先

## 先に答え：仏壇は粗大ごみ。供養は市がしません

新潟市も長岡市も、仏壇は粗大ごみです。指定袋に入る小さな物は燃やすごみで出せます。長岡市は料金を公表していて、仏壇は600円か1,000円です。位牌は、両市の表に載っていません。市は供養をしないので、寺や仏具店への相談が先になります。

実家じまいでは、仏壇の扱いで手が止まることがあります。この記事は、市の公式情報で分かる範囲と、相談の順番を整理します。宗教上の作法は宗派や寺で違うため、一般的な考え方にとどめます。内容は2026年10月3日の確認時点です。

この記事で分かること

- 新潟市・長岡市で、仏壇・神棚・位牌が市のごみとして出せるか
- 閉眼供養の一般的な考え方と、仏具店・寺への相談の順番
- 親が亡くなったあと、仏壇をすぐ処分しなくてよい理由と、墓じまいとの関係
- 自分で運べないときの持ち込みの条件

## 新潟市・長岡市の早見表

|------|--------|--------|
| 仏壇 | 粗大ごみ（指定袋に入れば燃やすごみ） | 粗大ごみ（指定袋に入れば燃やすごみ） |
| 仏壇の料金 | 品名なし（下の説明を参照） | 長辺90cm以下で1人で持てない物は600円 |
| 仏壇（大きい物） | 品名なし（同上） | 長辺90cm超で2人で持てる物は1,000円 |
| 神棚 | 品名なし（下の説明を参照） | 200円（指定袋に入れば燃やすごみ） |
| 位牌 | 品名なし（下の説明を参照） | 品名なし（下の説明を参照） |
| 線香・ろうそく | 燃やすごみ | 燃やすごみ |

| 申込 | 粗大ごみ受付センター（ネット・LINE・電話など） | 事前申込（ネット・FAX・電話） |
| 運び出し | 収集員は住宅内に入らない | 家屋内には入らない。2人で持てない物は収集不可 |

新潟市の料金一覧には、仏壇という品名がありません。「その他」の欄に、幅・奥行・高さの合計で決まる4段階があります。1.5m未満が100円、2m未満が200円、3m未満が300円、3m以上が500円です。この欄はインターネット申込ができず、粗大ごみ受付センター（025-290-5353）への電話が必要です。仏壇がここに当たるかは、公式に明記がありません。[要確認: 新潟市の仏壇の料金区分]

長岡市の仏壇は、運び方にも条件があります。2人で持ち運べない物は収集できません。申込のときに、縦・横・高さを伝える必要があります。

長辺90cm以下で1人で持てる物の行は、品目一覧にありません。一覧の冒頭には、一覧にない場合は電話で申し込むよう書かれています。収集の時間は、午前8時30分から夕方までで、指定できません。留守でも、処理券を貼って玄関先に出してあれば収集します。

## 品目ごとの出し方の手順

### 仏壇

手順は、市の粗大ごみの流れに沿います。先に、中身と引き取り先を決めておきます。

1. 引き出しや中の物を取り出します。位牌や写真、書類は、残す物と分ける物を決めておきます。
2. 市のごみにするか、仏具店や寺に相談するかを決めます。
3. 市のごみにする場合は、大きさを測り、粗大ごみとして申し込みます。
4. 新潟市は、申込のときに金額を聞きます。処理券を買って貼り、収集日の午前8時までに指定場所へ出します。
5. 長岡市は、処理券シールを買って貼り、収集日の午前8時30分までに玄関先へ出します。

長岡市は、家屋内に入って収集しません。新潟市も、収集員は住宅の中に入りません。どちらの市でも、重い仏壇は、外まで運ぶ人手が必要です。

### 神棚

長岡市の品目一覧では、神棚は200円です。備考に「指定袋に入れば燃やすごみ」とあります。新潟市は、分別早見表と料金一覧に神棚の記載を確認できませんでした。[要確認: 新潟市の神棚の区分]です。

神棚は神社のお札や神具を納めている場合があります。お札の扱いは、授かった神社に相談するのが一般的です。

### 位牌

位牌は、新潟市・長岡市とも、分別の表に記載を確認できませんでした。[要確認: 位牌の分別区分]です。

位牌は、ごみとして出す前に、寺への相談が先になる品です。仏壇の中にある位牌は、仏壇を処分する前に取り出して、行き先を決めます。

### 線香・ろうそく・数珠

線香とろうそくは、両市とも燃やすごみです。新潟市では、数珠も燃やすごみです。ガラス製と金属製の数珠は、燃やさないごみです。

## 自分で運べないとき：持ち込みの条件

収集に出せない事情があるときは、処理施設への持ち込みも制度としてあります。条件は市で違います。

新潟市は、自己搬入ができます。公式の案内は、次のとおりです。

- 引っ越しなどで一時的にごみが多量に出る場合や、収集日に出せない場合の制度です。
- 家庭系ごみの手数料は、重さ10kgまでごとに100円です。支払いは現金のみです。
- 荷降ろしは自分で行います。重い物は、複数人で行くよう案内されています。
- 搬入できる施設は、住んでいる区ごとに決まっています。

長岡市は、粗大ごみを原則として戸別収集にしています。引っ越しなどでやむを得ず多量に出たときに限り、中之島信条クリーンセンターへ持ち込めます。前日までに電話をして、施設の確認を受けます。処理券シールを貼って持ち込み、料金は戸別収集と同額です。

新潟市の詳しい条件は、[新潟市の粗大ごみの出し方](../niigata-shi-sodaigomi/)にまとめています。長岡市は、[長岡市の粗大ごみの出し方](../nagaoka-shi-sodaigomi/)です。

## 親が亡くなったあと、仏壇はすぐ処分しなくてよい

実家の片付けに期限があっても、仏壇の行き先は急いで決めなくて構いません。市のごみに出す手続きは、あとからでもできます。

決める前に、次の点を家族で確認します。

- 位牌・写真・遺影など、仏壇の中に何があるか。
- 親族の中に、引き取りたい人がいるか。
- 菩提寺があるか。法要の予定があるか。
- 実家をいつまでに空にする必要があるか。

急ぐ事情があるときは、仏壇だけを残して、先に他の片付けを進める方法もあります。宗教上の考え方は、宗派や寺で違います。ここでは一般的な進め方にとどめます。実家じまい全体の順番は、[新潟の実家じまいの手順](../jikkajimai-tejun-niigata/)で整理しています。

## 閉眼供養の考え方（一般論）

閉眼供養は、仏壇や位牌を処分する前に、僧侶に読経してもらう儀式です。魂抜きやお性根抜きと呼ぶ地域もあります。呼び方や進め方は、宗派や寺で違います。

ここでは、一般的な考え方だけを述べます。費用や作法は、この記事では扱いません。

- 市の粗大ごみ収集は、供養を含みません。長岡市は公式に「供養はしない」と書いています。
- 供養をしたいかどうかは、家族と親族で決めます。
- 菩提寺があるなら、まず菩提寺に相談するのが一般的です。
- 菩提寺がない場合は、仏具店や、地域の寺に相談する方法があります。

供養をしてから市のごみに出すか、仏具店や寺に引き取りを頼むかは、考え方が分かれます。どちらが正しいということは、一般論では言えません。

## 仏具店・寺への相談の順番

相談先は、次の順番で考えると迷いにくいです。

1. 菩提寺がある場合は、先に菩提寺へ連絡します。
2. 菩提寺がない場合は、仏壇を買った店や、近くの仏具店に聞きます。
3. 引き取りの可否や条件は、店や寺ごとに違います。先に確認します。
4. 市のごみにする場合は、市の粗大ごみの申込に進みます。

仏壇は、墓や位牌と一体で考える家もあります。墓じまいや改葬を考えている場合は、順番を間違えないでください。先に墓の方針を決めると、仏壇と位牌の行き先も決めやすくなります。

墓じまい・改葬の手続きは、姉妹サイトのハカラウで案内しています。

- [ハカラウ（墓じまい・改葬の情報）](https://hakarau.jp/)

## よくある間違い

- 仏壇を、処理券なしで玄関先に置いてしまう。粗大ごみは、申込と処理券が必要です。
- 新潟市の料金を、長岡市の表で見てしまう。両市で料金の仕組みが違います。
- 位牌や写真を取り出さずに、仏壇ごと出してしまう。戻せなくなります。
- 親族に話す前に、処分を進めてしまう。仏壇は家族の気持ちが絡みます。
- 寺に相談する前に、供養の有無を決めてしまう。寺の考え方を先に聞いてください。
- 2人で持てない仏壇を、長岡市に申し込んでしまう。収集できません。

## まとめて片付けるときの考え方

実家じまいでは、仏壇だけが単独で出ることは少ないです。たんす、布団、食器も同時に出ます。仏壇は、感情と手続きの両方が重い品です。後回しにすると、全体が止まります。

考え方は三つです。

1. 仏壇・位牌・遺影は、先に家族で行き先を決めます。ほかの片付けと同じ日にしません。
2. 重い仏壇は、運び出しの人手を先に考えます。長岡市は家屋内に入って収集しません。
3. 自分で出すか、業者に頼むかは、運び出しの手間で決めます。判断の軸は、別の記事にまとめています。

供養が必要な品は、片付けの対象から先に外します。残りの品を、市の収集か業者かに分けると、進めやすくなります。たんすやベッドなどの大型家具は、[ソファ・ベッド・タンスの捨て方](../sofa-bed-tansu-sutekata-niigata/)で料金を比べられます。

## よくある質問

### 仏壇は燃やすごみで出せますか。

指定袋に入る大きさなら、新潟市も長岡市も燃やすごみです。袋に入らない仏壇は、粗大ごみになります。

### 仏壇の粗大ごみの料金はいくらですか。

長岡市は、長辺90cm以下で1人で持てない物が600円です。長辺90cm超で2人で持てる物は1,000円です。新潟市は、仏壇の品名が料金一覧にありません。[要確認: 新潟市の仏壇の料金区分]です。

### 神棚はごみに出せますか。

長岡市は200円の粗大ごみで、指定袋に入れば燃やすごみです。新潟市は、[要確認: 新潟市の神棚の区分]です。お札や神具は、授かった神社に相談するのが一般的です。

### 位牌はごみに出せますか。

両市の表に、位牌の記載は確認できませんでした。[要確認: 位牌の分別区分]です。位牌は、寺への相談を先にしてください。

### 市は閉眼供養をしてくれますか。

長岡市は「供養はしない」と書いています。新潟市は、記載を確認できませんでした。[要確認: 新潟市の記載]です。供養を望むなら、寺や仏具店に相談します。

### 仏壇が重くて運べないときはどうしますか。

長岡市は、家屋内に入って収集しません。2人で持てない仏壇は、収集できません。人手が足りない場合は、運び出しを含めて頼める方法を、別の記事で比べてください。持ち込みの条件は、上の「自分で運べないとき」にまとめています。

### 親が亡くなりました。仏壇はすぐ処分しますか。

すぐに決める必要はありません。仏壇の中の物と、親族の意向を先に確認します。菩提寺があれば、先に相談するのが一般的です。

### 仏壇を、自分で処理施設に持ち込めますか。

新潟市は自己搬入ができ、家庭系ごみは10kgまでごとに100円です。長岡市は、やむを得ず多量に出たときに限り、中之島信条クリーンセンターへ持ち込めます。前日までに電話が必要です。

### 墓じまいもするつもりです。仏壇は先ですか、後ですか。

どちらが先と決まっているわけではありません。墓の方針が決まると、位牌や仏壇の行き先も決めやすくなります。墓じまいの手続きは、ハカラウで案内しています。
