# 遺品整理を自分でやる手順（新潟版）｜1週間の進め方、市のごみで出せる範囲、持ち込み、業者に頼む線引き

## 結論：先に市へ申し込み、重要な物を探してから、出す順に動きます

遺品整理は自分でできます。ただし、収集の日程が先に決まります。新潟市の粗大ごみは、申込後3日〜1週間以降の収集です。長岡市は、混雑時に受付後2週間程度かかります。1週間の片付けでは、初日に申し込むのが基本です。重要な書類を探す作業と、ごみを出す作業は、並行して進めます。量が多い、期限が近い、遠方に住んでいる場合は、業者への相談も考えます。

法律や税の期限は、一般論です。個別の判断は専門家に確認してください。内容は2026年10月3日の確認時点です。

この記事で分かること

- 遺品整理を自分でやる1週間の進め方と、先にやる順番
- 新潟市・長岡市で、市のごみとして出せる物と持ち込みの条件
- 一人暮らしの片付けで気をつけること、業者に頼む線引き

| 1回の点数 | 公式ページに上限の記載なし | 5点まで |

## 始める前に確認すること

### 重要な物と期限を先に確認します

遺品整理では、捨てると困る物が混ざります。遺言書、通帳、権利証、契約書、鍵、スマホなどです。

遺言書は、勝手に開封できません。家庭裁判所の検認が必要な場合があります。相続放棄は、相続の開始を知った時から3か月以内に申述します。財産を処分すると、単純承認とみなされる場合があります（民法921条）。

放棄を考えている場合は、処分の前に専門家へ相談してください。詳しい期限と物のリストは、[遺品整理はいつから？捨ててはいけない物](../ihinseiri-itsukara-sutetewa-ikenai/)で整理しています。放棄との関係は、[相続放棄をするなら遺品整理に注意](../ihinseiri-souzokuhouki/)を見てください。

### 相続人の了承を取ります

相続人が複数いる場合は、ひとりで処分すると、あとで揉める原因になります。形見になりうる物は、相続人に確認してから出します。

### 賃貸住宅は、退去の期限を確認します

賃貸住宅は、契約書で解約の予告期間と退去の条件を確認します。管理会社や大家さんに、片付けの期限を相談します。

## 1週間の進め方

次の表は、一人で進める場合の一例です。市の収集日に合わせて、順番を入れ替えてください。

| 日 | やること | ポイント |
|------|------|------|
| 1日目 | 部屋を見て、出す物のリストを作り、粗大ごみを申し込む | 収集まで日数がかかるため、最優先です |
| 2日目 | 遺言書、通帳、権利証、契約書、鍵、スマホを探す | 見つけた物は、箱に集めて開封しません |
| 3日目 | 貴重品、形見、写真を仕分ける | 迷う物は「迷う箱」に入れます |
| 4日目 | 家電4品目、パソコンなど市で出せない物を確認する | 出し方は、販売店や引取場所に聞きます |
| 5日目 | 燃やすごみ、燃やさないごみ、資源物を分けて出す | 市の分別表を見ながら進めます |
| 6日目 | 粗大ごみに処理券を貼り、収集日の朝までに出す | 持ち込みは、日程と重さを確認します |
| 7日目 | 掃除、鍵の確認、残りの物の最終確認をする | 迷う箱は、期限が過ぎるまで処分しません |

収集の日程が間に合わない場合は、持ち込みを使います。それでも間に合わない場合は、日程を延ばすか、業者への相談を考えます。

## 新潟市で出せる範囲

### 粗大ごみの申込と料金

新潟市の粗大ごみは、粗大ごみ受付センターへ先に申し込みます。ネット、チャットボット、LINEは24時間です。電話は025-290-5353で、月〜土の9:00〜17:00です。

処理券は、スーパーやコンビニなどで買います。品物ごとに貼り、収集日の午前8時までに、指定した場所へ出します。収集時の立会いは不要で、作業員は住宅の中に入りません。

| 品目 | 料金 |
|------|------|
| たんす（幅・奥行・高さの合計2.5m未満／以上） | 300円／500円 |
| 食器棚・本棚（合計2m未満／2m以上2.5m未満／2.5m以上） | 200円／300円／500円 |
| 布団 | 100円 |
| ベッド | 500円 |
| マットレス（スプリング式以外／スプリング式） | 200円／500円 |
| 金庫 | 200円 |
| ストーブ／ファンヒーター | 100円／200円 |
| 自転車／電動アシスト自転車 | 200円／300円 |

仏壇と神棚は、料金一覧に品目名がありません。受付センターで大きさを伝えて確認します。

### 持ち込みの条件

新潟市に住んでいる人は、処理施設へごみを持ち込めます。引っ越しなどで多量に出るときや、収集日に出せないときが対象です。

家庭ごみの手数料は、10kgまでごとに100円です。2026年6月1日に改定されました。受入は、多くの施設で月〜土の8:30〜12:00と13:00〜16:00です。土曜は15:00までです。区ごとに使える施設は、市の一覧で確認します。

燃やすごみ、燃やさないごみ、粗大ごみに分けて持ち込みます。袋に入るごみは、90リットル以下の透明か半透明の袋に入れます。荷下ろしは自分で行います。

家電4品目、パソコン、産業廃棄物、タイヤなどは持ち込めません。年末年始、お盆、連休明け、土曜は混雑します。多い日は1時間以上待つと案内されています。

詳しい施設と料金は、[新潟市の粗大ごみの出し方](../niigata-shi-sodaigomi/)にあります。

### 運び出しが難しいとき

重い家具を出せないときは、市の「ごみ出し支援事業」があります。高齢者や障がい者などで、ごみ出しが困難な世帯が対象です。自治会などの団体が実施し、実施していない地域もあります。問い合わせ先は、廃棄物対策課（025-226-1407）か各区の窓口です。

## 長岡市で出せる範囲

### 粗大ごみの申込と料金

長岡市の粗大ごみは、事前申込制です。ネットは24時間、FAXも24時間です。電話は0258-25-0053で、月〜金の8:30〜17:00です（祝日と年末年始を除く）。1回の収集は5点までです。

処理券は、市指定ごみ袋の販売店で買います。当日の8:30までに、品物ごとに貼って出します。玄関先に出してあれば、留守でも収集します。

| 品目 | 料金 |
|------|------|
| 布団（1枚・丸めて縛る） | 200円 |
| 自転車／電動アシスト自転車 | 200円／600円 |
| たんす（長辺90cm以下・1人で持てない） | 600円 |
| 仏壇（長辺90cm以下・1人で持てない／長辺90cm超・2人で持てる） | 600円／1,000円 |
| 神棚 | 200円 |
| ストーブ（1人で持てる） | 200円 |
| カーペット（6畳未満／6畳以上） | 200円／600円 |

スプリング入りのベッド、マットレス、ソファーは、市で収集できません。ピアノ、耐火金庫、家電4品目、パソコンも対象外です。

手数料は、今後変わる可能性があります。申し込む前に、市の公式ページで最新の料金を確認してください。

### 持ち込みの条件

長岡市の持ち込みは、「引越しなどでやむを得ず多量のごみが出たときに限り」と案内されています。粗大ごみを受け入れるのは、中之島信条クリーンセンターだけです。電話は0256-97-7260です。

受付は、月〜土の8:30〜16:30です。祝日と年末年始は休みです。料金は戸別収集と同額で、処理券を貼って持ち込みます。前日までに電話し、施設の確認を受けます。

寿クリーンセンターは、燃やすごみのみです。詳しくは、[長岡市の粗大ごみの出し方](../nagaoka-shi-sodaigomi/)にあります。

## 一人暮らしの方が亡くなった場合の片付け

一人暮らしだった親や家族が亡くなった場合は、家族が短期間で動くことが多くなります。次の点を先に確認します。

- 賃貸住宅なら、管理会社に連絡し、契約の内容と退去の期限を確認します。
- 冷蔵庫の食品や生ごみは、早めに処理します。
- 家の中に入る前に、鍵、立ち入りの可否、近隣への連絡を確認します。

強い臭いや汚れがある場合は、無理に自分で入らず、専門の業者へ相談してください。特殊清掃の公的な基準は、今回の確認では見つかりませんでした。

遺品の仕分けは、重要な書類を探す作業から始めます。年金の届出は、すみやかに行うよう日本年金機構が案内しています。

## 業者に頼む線引き

次の場合は、業者への相談を考えます。

| 状況 | 理由 |
|------|------|
| 量が多く、1週間で出し切れない | 収集まで日数がかかります。長岡市は1回5点までです |
| 階段や2階から、重い物を出す | 人手と安全の確保が必要です |
| 冬場で、雪や凍結がある | 搬出と持ち込みの条件が悪くなります |
| 遠方に住んでいて、通えない | 日程の調整が難しくなります |
| 賃貸の退去期限が近い | 収集日を待てません |
| 強い臭いや汚れがある | 衛生面の問題があります |
| 市で出せない物がある | 家電4品目、ピアノなどは別の手段が必要です |

家庭の廃棄物を回収できるのは、一般廃棄物処理業の許可を持つ業者だけです。環境省は、無許可の回収業者を利用しないよう案内しています。

見積もりの聞き方は、[新潟市で遺品整理を頼むとき](../ihinseiri-niigata-shi-gyosha-erabikata/)にまとめています。判断の基準は、[自分で出す？業者に頼む？](../jibun-de-dasu-ka-gyousha-ka/)を見てください。

## よくある質問

**Q　遺品整理を自分でやる場合、最初に何をしますか。**
粗大ごみの申込と、重要な物の捜索を同時に始めます。収集まで日数がかかるためです。遺言書、通帳、権利証、契約書、鍵、スマホは、捨てずに集めます。

**Q　新潟市の粗大ごみは、当日に出せますか。**
できません。申込後3日〜1週間以降が通常です。申込が多いと、さらに延びます。急ぐ場合は、持ち込みも選べます。

**Q　長岡市では、自分でごみを持ち込めますか。**
引越しなどで、やむを得ず多量のごみが出たときに限ります。粗大ごみは、中之島信条クリーンセンターだけです。前日までに電話が必要です。

**Q　家電やパソコンは、市で出せますか。**
新潟市も長岡市も、家電4品目とパソコンは市のごみとしては出せません。販売店や指定の引取場所に相談します。

**Q　処分する前に、相続放棄を考える必要がありますか。**
放棄の可能性があるなら、処分の前に考えます。財産を処分すると、単純承認とみなされる場合があります。迷うときは、弁護士や司法書士に先に相談してください。

**Q　一人暮らしの親の部屋が汚れていた場合は、自分で片付けますか。**
強い臭いや汚れがある場合は、無理をしないでください。専門の業者に相談する方法があります。許可の有無は、市の公式情報で確認します。
