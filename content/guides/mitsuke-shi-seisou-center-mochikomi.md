# 見附市清掃センターへの持ち込み｜条件・受付時間・料金・届出書・持ち込めない物

## 結論：持ち込めるのは「一時的に大量」か「収集日まで待てない緊急」のときだけです

見附市清掃センターは、見附市椿澤町4834番地にあります。電話は0258-63-3564です。家庭ごみの直接持ち込みは、特別な事情があるときに限られます。

持ち込める事情は、2つです。引越しや冠婚葬祭などで、一時的に大量のごみが出たとき。引越しの日が決まっているなど、収集日まで待てない緊急のときです。どちらにも当たらないときは、直接持ち込めません。

- **受付**：月〜金の9:00〜16:00と、土曜の9:00〜12:00です。日曜日、祝日、年末年始は休みです。荷下ろしと精算の時間を含むので、早めに行きます。
- **事前の手続き**：「廃棄物処理施設直接搬入届出書」を、事前に書いて持ち込みます。持ち込むたびに必要です。
- **料金**：燃えるごみ・燃えないごみは、10kgまで110円です（2026年8月1日改定）。10kgを超えると、10kgごとに110円が加わります。現金で払います。指定袋には入れません。
- **粗大ごみ**：粗大ごみ処理券を貼って持ち込みます。清掃センターでは売っていないので、スーパーなどで先に買います。
- **予約**：公式ページに、予約や事前連絡が必要との記載はありません。
- **持ち込めない物**：家電リサイクル対象品目、家庭用パソコン、消火器・ボンベ、灯油・ガソリン、重さ60kg以上のもの（ピアノ、耐火金庫）、建築廃材などです。持ち込めなかった物は、持ち帰ります。

この記事は、見附市の公式情報だけでまとめました。内容は2026年10月17日の確認時点です。持ち込む前に、公式ページで最新の情報を見てください。

この記事で分かること

- 直接持ち込める事情と、持ち込めない事情
- 受付時間・休み・所在地・電話
- 届出書の入手先と、書く内容
- 料金（重さで決まる場合の計算例と、粗大ごみ処理券）
- 持ち込めない物と、持ち込み先が別の物
- 実家の片付けで持ち込むときの考え方

## 持ち込める事情は2つだけです

見附市の案内（ごみの分け方・出し方ガイドブック、令和8年7月改訂、9ページ）は、直接持ち込める場合を限定しています。

1. 引越しや冠婚葬祭などで、一時的に大量のごみが出る場合
2. 引越しの日が決まっているなど、収集日まで待てない緊急性がある場合

ガイドブックには、①と②の特別な事情がないときは、清掃センターへ直接持ち込むことはできない、と書かれています。

家庭の燃えるごみ・燃えないごみは、町内のごみステーションへ出すのが原則です。粗大ごみは、戸別収集に出すのが原則です。

草や落ち葉が多いときも、持ち込みの対象ではありません。ガイドブックは、1回につき2袋程度の量で、何回かに分けて町内のごみステーションへ出すよう案内しています。

## 受付時間と休み

清掃センターの業務案内（2026年7月2日更新）と、直接搬入のページ（2026年3月18日更新）の記載です。

| 項目 | 内容 |
|------|------|
| 月〜金 | 9:00〜16:00 |
| 土曜 | 9:00〜12:00 |
| 休み | 日曜日、祝日、年末年始 |
| 年末（令和8年度） | 12月28日（月）の正午まで |
| 年始（令和8年度） | 1月4日（月）の午前9時から |

受付時間は、荷下ろしと精算を含みます。時間に余裕を持って来るよう、市が案内しています。

清掃センターは、2019年6月1日から、見附グリーンテック株式会社が運営・維持管理を担当しています（市の業務案内ページ）。問い合わせ先は、市の都市環境課 環境施設係（電話0258-62-1700）も案内されています。

所在地の書き方は、資料で少し違います。市のページは「椿澤町4834番地」、ガイドブックは「椿澤町滝ノ入4834番地」です。番地は同じです。

## 届出書：事前に書いて、清掃センターに出します

直接持ち込むときは、「廃棄物処理施設直接搬入届出書」が要ります。

| 項目 | 内容 |
|------|------|
| 提出先 | 清掃センター（持ち込み時に窓口へ提出） |
| 書くタイミング | 事前に記入してから持ち込む |
| 複数回に分けるとき | 持ち込むたびに、届出書が必要 |
| 入手先 | 市役所1階の都市環境課 環境企画係の窓口、今町出張所、ネーブルみつけ、中央公民館、北谷公民館、葛巻公民館、新潟公民館、上北谷公民館、今町公民館、保健福祉センター、北谷南部地区ふるさとセンター。市のホームページからもダウンロードできる |

届出書に書く項目は、次のとおりです（様式の第1号、見附市のPDF）。

- 住所、氏名、電話番号
- 搬入予定日
- 廃棄物の種類と数量（燃えるごみ、燃えないごみ、粗大ごみ、それぞれの内容）
- 運搬車両（車の種類とナンバー）
- 理由（引越しのため、大量のため、その他）

届出書の注意書きには、「事前にご記入のうえ処理施設へ搬入してください」とあります。

## 搬入の流れと、計量の方法

市の届出書（裏面の案内）に、持ち込み方法が載っています。

1. 届出書を用意し、事前に書きます。
2. 受付時間内に清掃センターへ運びます。
3. ごみの種類ごとに計量します。降ろしやすいように積み込みます。
4. 降ろして、精算します。

混ぜて積んだ場合は、種類ごとに分けて計量します。届出書の例では、粗大ごみ（可燃）、粗大ごみ（不燃）、燃えるごみを混ぜて積んだとき、3回に分けて計量します。最大で5回程度計量することがあります。

## 料金：燃えるごみ・燃えないごみは重さで、粗大ごみは処理券で

### 燃えるごみ・燃えないごみ

重さで決まります。2026年8月1日から改定されました（市のお知らせ、2026年7月14日更新）。

| 区分 | 改定前 | 2026年8月1日以降 |
|------|------|------|
| 家庭ごみ：10kgまで | 100円 | 110円 |
| 家庭ごみ：10kgを超えた分、10kgごと | 100円 | 110円 |

燃えるごみと燃えないごみの料金は、同額です。支払いは現金です。市の指定ごみ袋に入れたものも、重さで計算します。ガイドブックは、指定袋には入れないよう案内しています。

10kgごとに110円として単純に計算すると、次のとおりです。

| ごみの重さ | 料金 |
|------|------|
| 10kg | 110円 |
| 50kg | 550円 |
| 100kg | 1,100円 |

10kgに満たない端数の扱いは、公式ページに記載がありません。精算のときに、清掃センターで聞いてください。

公式の資料のなかには、改定前の100円が残っているものがあります。清掃センターの業務案内（2026年7月2日更新）、直接搬入のページ（2026年3月18日更新）、届出書の裏面の案内です。この記事は、更新が新しく、改定を知らせる市のお知らせとガイドブック（令和8年7月改訂）に従い、110円としました。

### 粗大ごみ

粗大ごみは、粗大ごみ処理券を貼って持ち込みます。

| 処理券（1枚、運搬費・消費税込み） | 大 | 中 | 小 |
|------|------|------|------|
| 令和8年8月1日以降の価格 | 990円 | 660円 | 330円 |

処理券は、清掃センターでも市役所でも売っていません。スーパー、コンビニ、ドラッグストア、ホームセンターなどの取扱店で買います。品目ごとにどの券を貼るかは、ガイドブックの「分別早見表」に載っています。

戸別収集で出すときも、処理券の金額は同じです。申込先や収集日は、[見附市・小千谷市の粗大ごみの出し方](../mitsuke-ojiya-sodaigomi/)で説明しています。

### その他の有料のごみ

ガイドブック（10ページ）には、次の2つが有料のごみとして載っています。10kgにつき110円です。指定袋には入れません。

- 灰
- 犬や猫などの死体（小型犬程度の大きさで、重さ10kg未満）

## 持ち込める物・持ち込めない物

### 持ち込める物

直接搬入のページが案内している物は、燃えるごみ、燃えないごみ、粗大ごみ（可燃・不燃・布団）です。ごみの種類ごとに分けて、計量と荷下ろしをします。

庭木のせん定枝は、条件に合えば、チップ用として無料で清掃センターへ直接持ち込めます（ガイドブック10ページ）。

- 直径1cm以上10cm以下
- 長さ1m以内
- 葉がついていないもの
- 杉や松などの針葉樹は、チップにできないため対象外

葉がついた小枝は、燃えるごみとして町内のごみステーションへ出します。チップ用のせん定枝は、葛巻資源回収棟でも回収しています。回収したせん定枝から作ったチップは、清掃センターで無料で配っています（配布時期は都市環境課へ問い合わせ）。

### 持ち込めない物（引き取れないごみ）

直接搬入のページに、引き取れないごみが載っています。引き取れないごみは、持ち帰りになります。

| 区分 | 品目 |
|------|------|
| 家電リサイクル対象品目 | 別ページ「家電リサイクル対象品目の処分方法」を参照 |
| 家庭用パソコン | 別ページ「家庭用パソコンの処分方法」を参照 |
| 在宅医療廃棄物 | 別ページ「在宅医療廃棄物の処分方法」を参照 |
| 有害性のあるもの | 農薬、工業薬品、その他薬品類 |
| 爆発のおそれのあるもの | 消火器、ボンベ、火薬類 |
| 引火性のあるもの | 灯油、ガソリン、燃料油脂類 |
| 重さが60kg以上のもの | ピアノ、耐火金庫など |
| その他 | 自動車部品、農機具、農業用ハウスの廃材、建築廃材など |

ガイドブックは、処理困難ごみの処理を、販売店・取扱店や一般廃棄物許可業者に相談するよう案内しています。

家電4品目の指定引取場所は、[新潟の家電4品目の出し方](../kaden4hinmoku-niigata/)にまとめています。

事業系のごみは、家庭ごみとは別の扱いです。市の業務案内では、事務所の飲食残さ、たばこの吸殻、紙くずなどが対象で、粗大ごみと資源ごみは持ち込めません。会社の社員本人が運ぶ必要があります。

見附市の直接搬入のページ、ガイドブック、届出書には、持ち込み時の身分証の提示や、品目ごとの数量の上限は書かれていません。

## 実家の片付けで持ち込めますか

公式ページに、実家の片付けが「一時的に大量」に当たるかどうかの記載はありません。届出書の「理由」欄には、「引越しのため」「大量のため」「その他」の3つがあります。また、届出書の住所欄には、あらかじめ「見附市」と印字されています。見附市外・県外に住む家族が、実家のごみを持ち込めるかどうかも、記載がありません。[要確認: 実家の片付けが「一時的に大量」に当たるか。持ち込む人が市外・県外在住の場合の扱い（都市環境課 環境施設係 0258-62-1700）]

市は、②の例として「引越しの日が決まっているなど」を挙げています。実家の片付けで日が決まっているときに当たるかは、上の確認先に聞きます。

次の順で進めます。

1. 出す物をリストにします。品目、大きさ、数量を書きます。
2. 家電4品目、パソコン、ピアノ、耐火金庫などを、先に外します。
3. 持ち込める事情に当たるかを、都市環境課 環境施設係に確認します。
4. 届出書を入手して、事前に書きます。
5. 粗大ごみは、処理券を買って貼ります。清掃センターでは売っていません。
6. 燃えるごみ・燃えないごみは、指定袋に入れず、種類ごとに分けて積みます。
7. 平日9:00〜16:00か、土曜9:00〜12:00に運びます。

予約や事前連絡が必要との記載は、公式ページにありません。必要なのは、事前に書く届出書です。初めてのときは、あわせて電話で聞いておくと安心です。

持ち込みの事情に当たらないときは、戸別収集を使います。粗大ごみの収集は、1回につき5個までです。収集日の1か月前から1週間前までに、市の指定収集運搬業者へ電話で申し込みます。詳しくは、[見附市・小千谷市の粗大ごみの出し方](../mitsuke-ojiya-sodaigomi/)をご覧ください。

量が多いときや、運び出せないときは、一般廃棄物許可業者に頼む方法があります。自分で運ぶか業者に頼むかの考え方は、[自分で出す？業者に頼む？](../jibun-de-dasu-ka-gyousha-ka/)が判断の材料になります。

## 見附市清掃センター、よくある質問

**Q　見附市清掃センターに、ごみを持ち込めますか。**
一時的に大量のごみが出たときと、収集日まで待てない緊急のときに限り、持ち込めます。どちらにも当たらないときは、直接持ち込めません。事前に届出書を書きます。

**Q　見附市清掃センターの受付時間は、いつですか。**
月〜金は9:00〜16:00、土曜は9:00〜12:00です。日曜日、祝日、年末年始は休みです。受付時間は、荷下ろしと精算を含みます。

**Q　見附市清掃センターの持ち込み料金は、いくらですか。**
燃えるごみ・燃えないごみは、10kgまで110円です。10kgを超えると、10kgごとに110円が加算されます。現金で払います。粗大ごみは、粗大ごみ処理券（大990円・中660円・小330円）を貼って持ち込みます。

**Q　見附市清掃センターで、粗大ごみの処理券は買えますか。**
売っていません。スーパー、コンビニ、ドラッグストア、ホームセンターなどの取扱店で買って、貼ってから持ち込みます。

**Q　見附市清掃センターに、予約は要りますか。**
公式ページに、予約や事前連絡が必要との記載はありません。必要なのは、事前に書く届出書です。心配なときは、都市環境課 環境施設係（0258-62-1700）に確認します。
