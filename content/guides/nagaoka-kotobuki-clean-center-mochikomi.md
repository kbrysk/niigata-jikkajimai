# 寿クリーンセンターのごみ持ち込み｜長岡市・受付時間と料金と持ち込める物

## 結論：受付は月〜土曜の8:30〜16:30です。持ち込めるのは燃やすごみだけで、前日までに電話が要ります

寿クリーンセンターは、長岡市寿3-6-1にあるごみ処理施設です。長岡市が持ち込みを受け付ける2施設のうちの1つです。電話は、0258-24-2856です。

受付は月曜から土曜の8:30〜16:30です。日曜、祝日、振替休日、年末年始は休みです。

持ち込めるごみは、燃やすごみだけです。燃やさないごみ、粗大ごみ、枝葉・草は、受け付けません。それらは、もう1つの施設の中之島信条クリーンセンターへ持ち込みます。

持ち込めるのは、引越しなどで、やむを得ず多量のごみが出たときだけです。前日までに電話をして、施設の確認を受けます。

料金は、指定袋に入っていれば無料です。入っていなければ、100kgまで300円です。

この記事は、長岡市の公式ページだけで書いています。確認日は2026年10月17日です。出かける前に、公式ページで最新の情報を確かめてください。

長岡市の2施設に共通するルールは、[長岡市のごみ持ち込みは2か所、前日までに電話が必要](../nagaoka-shi-gomi-mochikomi/)にあります。この記事は、寿クリーンセンターに絞って説明します。

## どんなときに持ち込めますか

長岡市のごみは、ステーション収集が原則です。粗大ごみは、戸別収集が原則です。

処理施設に持ち込めるのは、「引越しなどで、やむを得ず多量のごみが出たとき」に限られます。前日までに電話をして、施設の確認を受けてから持ち込みます。

実家の片付けが、この条件に当たるかどうかは、公式ページに書かれていません。電話で、実家の片付けであることを伝えて確かめてください。[要確認: 実家の片付けが「やむを得ず多量のごみ」に当たるか（寿クリーンセンター 0258-24-2856）]

市の「家庭ごみと資源物の分け方と出し方」（令和8年度版）には、次の決まりもあります。

- 他人のごみは、持ち込めません。
- 火事ごみを持ち込むときは、事前に電話をします。
- 業者が剪定・除草した枝葉は、持ち込めません。

## 電話は、どうかければよいですか

持ち込みの前日までに、寿クリーンセンターへ電話します。電話番号は、0258-24-2856です。

市の持込ページには「24-2856」と、市外局番なしで書かれています。市の別のページには、0258つきで書かれています。「動物が死亡したときは」のページと、国際交流センターの多言語案内です。市外局番つきの表記があるので、0258をつけてかけます。

電話をかけられる時間帯は、市の持込ページに書かれていません。受付時間の8:30〜16:30の中でかけるのが無難です。

見学の電話番号は、別にあります。寿クリーンセンターの見学は、0258-24-2837（平日8:30〜17:15）です。持ち込みの電話ではありません。

| 項目 | 内容 |

| 受付日 | 月曜〜土曜 |
| 受付時間 | 8:30〜16:30 |
| 休み | 日曜、祝日、振替休日、年末年始 |

昼休みの記載は、市の持込ページにありません。昼の時間帯に行くときは、電話で確かめてください。

年末年始の休みの日付は、持込ページに書かれていません。参考になるのは、市の多言語案内です。2025年末は、12月31日の正午から1月3日（土）まで、持ち込めないと案内されていました。今年の日付は、年末が近づいたら、市の広報か電話で確かめてください。

## 持ち込めるのは「燃やすごみ」だけです

市の持込先の表では、燃やすごみだけが「○」です。燃やさないごみ、粗大ごみ、枝葉は「×」です。

### 燃やすごみには、何が入りますか

市の「燃やすごみ」のページ（2026年3月16日更新）に、主な品目があります。

| 区分 | 主な品目 |
|------|------|
| 衣類・紙類 | 紙おむつ、破れ・汚れた衣類、汚れた紙、加工紙（紙皿、写真、シールなど） |
| 生ごみ・自然物 | 生ごみ、貝殻・カニの殻、固化した食用油、家庭菜園の作物の茎やつる |
| 日用品 | 使い捨てカイロ、乾燥剤、保冷剤、ペット用トイレの砂、たばこの吸殻 |

この表は、ステーションに出す場合の説明です。持ち込みの寸法は、次の節にあります。

### 持ち込めないごみ

| ごみ | 持ち込み先 |
|------|------|
| 燃やさないごみ（金属、陶磁器、ガラス、ゴム、小型家電など） | 中之島信条クリーンセンター |
| 粗大ごみ | 中之島信条クリーンセンター |
| 枝葉・草 | 中之島信条クリーンセンター（月・火・金・土、1月・2月は不可） |

家電4品目、パソコン、スプリング入りのソファー・マットレス、ピアノ、建築廃材などは、市で収集処理できないごみです。持込ページには、これらを受け入れるとは書かれていません。持ち込まず、市の「収集処理できないもの」のページで、処分方法を確かめてください。一覧は、[長岡市のごみ持ち込みは2か所、前日までに電話が必要](../nagaoka-shi-gomi-mochikomi/)にもまとめています。家電4品目は、[新潟の家電4品目の処分方法](../kaden4hinmoku-niigata/)をご覧ください。

家庭菜園用のポリマルチは、例外です。事前に連絡し、燃やさないごみ用の指定袋に入れれば、持ち込めます。農家で使ったものは、持ち込めません。

## 切り方・袋・積み方の決まり

- 正しく分別し、中身が見えるようにして持ち込みます。
- 段ボール箱に入れての持ち込みは、禁止です。
- 大きい物は、50cm四方に切ります。
- 布団やカーペットは、50cm四方に切ります。切れない場合は、粗大ごみに申し込みます。機械に絡まって、故障の原因になるためです。
- 太さ5cm・長さ50cmを超える木材は、焼却炉に送る装置の停止や故障の原因になります。5cm・50cm以下に切るか、粗大ごみとして出します。
- 生ごみ用の指定袋に入った生ごみは、持ち込めません。持ち込むときは、燃やすごみ用の指定袋に入れます。

1回に持ち込める量や、車の種類の制限は、持込ページに書かれていません。量が多いときは、前日の電話で相談してください。

## 料金はいくらですか（計算例つき）

燃やすごみは、持ち込み方で料金が変わります。

| 持ち込み方 | 料金 |
|------|------|
| 燃やすごみ用の指定袋に入れて持ち込む | 無料 |
| 指定袋に入れずに持ち込む | 100kgまで300円 |
| 100kgを超えた分 | 10kgあたり30円を加算 |

指定袋を使わず、重さだけで料金が決まる場合の計算例です。

| ごみの重さ | 料金 |
|------|------|
| 100kg | 300円 |
| 150kg | 300円＋30円×5＝450円 |
| 200kg | 300円＋30円×10＝600円 |

10kgに満たない端数の扱いと、支払い方法（現金のみか）は、持込ページに書かれていません。[要確認: 10kg未満の端数の計算方法と、支払い方法（寿クリーンセンター 0258-24-2856）]

燃やすごみの指定袋は、黄色系の半透明の袋です。10枚入りの価格は、大（約40ℓ）が520円、中（約25ℓ）が320円、小（約10ℓ）が130円、極小（約5ℓ）が60円です。

事業所のごみの手数料は、家庭ごみとは別です。市の「事業系一般廃棄物の出し方」のページを見てください。

## 長岡市のごみ処理場の一覧

「長岡 ごみ処理場」で探すと、持ち込み先ではない施設も出てきます。市の施設概要（令和6年4月1日現在稼働中の施設）には、次の施設があります。

| 施設 | 所在地 | 個人の持ち込み |
|------|------|------|
| 寿クリーンセンター（ごみ焼却施設、リサイクルプラザ、し尿前処理施設） | 寿3丁目6番1号 | 燃やすごみのみ |
| 生ごみバイオガス発電センター | 寿3丁目6番1号 | 市の持込ページには載っていません（事業者向けページに、事業系の生ごみの持込先として載っています） |
| 中之島信条クリーンセンター | 中条新田1080-2 | 燃やすごみ、燃やさないごみ、粗大ごみ、枝葉・草 |
| 柿最終処分場ほか | 柿町、文納、小国町 | 持込先として載っていません |

寿クリーンセンターと同じ所在地には、市の環境衛生センターがあります。環境衛生センターは、資源物の拠点回収の会場でもあります。毎週土・日曜（祝日・年末年始を除く）の9時から正午に、資源物10品目を無料で回収します。ごみの持ち込みとは、別の制度です。

## 行き方

市の持込ページに、行き方の案内はありません。所在地は、長岡市寿3-6-1です。ごみを運ぶので、車で行く前提です。

## 寿クリーンセンターのごみ持ち込み、よくある質問

**Q　寿クリーンセンターの営業時間は、何時から何時までですか。**
受付は、月曜から土曜の8:30〜16:30です。祝日、振替休日、年末年始は休みです。

**Q　寿クリーンセンターは、日曜も開いていますか。**
開いていません。月曜から土曜が受付日です。日曜と祝日は休みです。

**Q　寿クリーンセンターに、粗大ごみは持ち込めますか。**
持ち込めません。粗大ごみを受け付けるのは、中之島信条クリーンセンターだけです。粗大ごみは、戸別収集もあります。

**Q　寿クリーンセンターに持ち込むとき、予約は要りますか。**
必要なのは、前日までの電話です。電話で施設の確認を受けてから、持ち込みます。

**Q　寿クリーンセンターの持ち込みは、いくらかかりますか。**
指定袋に入れれば無料です。指定袋を使わないと、100kgまで300円です。超えた分は、10kgあたり30円を加算します。
