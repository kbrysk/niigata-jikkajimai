# 佐渡市・村上市の粗大ごみの出し方｜処理券・自己搬入・許可業者

佐渡市は、粗大ごみ処理券を1点に1枚貼って、集積所へ出します。処理券は1枚520円です。村上市は、粗大ごみの戸別収集が公式ページで確認できません。ごみ処理場へ自分で運びます。料金は重量制で、10kgまで60円です。運べないときは、許可業者に頼みます。

## この記事で分かること

- 佐渡市は処理券を貼る定額制、村上市は処理場へ持ち込む重量制、という違い
- 実家じまいで出やすい家具、寝具、自転車などの扱いと料金
- 持ち込み先、受付時間、許可業者に頼むときの考え方

2市は、島と本土で事情が違います。この記事は、両市の公式情報だけでまとめました。確認日は2026年10月3日です。申し込む前に、公式ページで最新の情報を見てください。

## 佐渡市

### 申込

粗大ごみの対象は、家具、寝具類、小型の乗り物類などです。公式ページには、ストーブ、机、一輪車、ふとん、マットレス、ソファー、たんす、自転車の例が載っています。

出し方は、粗大ごみ処理券を1個に1枚貼る方法です。ごみは、収集日の朝8時までに、決められた集積所へ出します。

事前の申込が必要かどうかは、公式ページに記載がありません。[要確認: 粗大ごみの事前申込の要否]

収集日は、地区別のごみ収集カレンダーに載っています。令和8年度の両津A地区では、年5回です。6月、8月、10月、12月、3月の第1土曜日です。ほかの地区は、確認していません。[要確認: 両津A地区以外の粗大ごみの収集日]

### 料金

| 出し方 | 料金 |
|--------|------|
| 集積所に出す | 粗大ごみ処理券 1枚520円（税込）を1個に1枚貼る |
| クリーンセンターへ持ち込み | 30kgまで520円。超えると10kgごとに100円を加算 |

処理券は、市内の小売店で買います。品目別の料金表はありません。一律です。

「燃やさないごみ指定袋」に入りきらない物は、1点につき処理券を1枚貼ります。指定袋を2枚使って粗大ごみを出すのは、市が違反の例に挙げています。

サイズの上限が決まっています。次のとおりです。

| 形 | 上限 |
|----|------|
| 一般 | 横1.2m、高さ2.0m、奥行き0.6m |
| パイプ状 | 径20cm、長さ2.0m |
| 板状 | 横1.2m、縦2.0m、厚さ2mm |

トタンは、5枚までを1束にします。畳は、1日に10枚以内です。

### 持ち込み

| 項目 | 内容 |
|------|------|
| 施設 | 佐渡クリーンセンター |
| 住所 | 佐渡市中原103 |
| 電話 | 0259-52-3336 |
| 受付 | 月〜土（祝日を含む）8:30〜16:30。日曜は休み |
| 支払い | 現金。分別して持ち込む |
| 予約 | 公式に記載がありません。[要確認: 持ち込みの予約の要否] |

受付時間は、令和8年度のごみ収集カレンダーに載っています。同じカレンダーに、令和9年1月23日と2月8日は、工事のため直接搬入を全面停止する、とあります。ごみ処理手数料のページは、2021年3月の更新です。料金が変わっていないか、申し込む前に確認します。

両津クリーンセンターと南佐渡クリーンセンターは、中継施設です。公式の施設一覧では、稼働停止と書かれています。両津は平成27年4月から、南佐渡は平成21年4月からです。市の「環境衛生施設の住所連絡先一覧」には、この2か所を、市民等がごみを直接搬入する施設として使っている、とあります。持ち込まれたごみは、佐渡クリーンセンターへ運んで処理します。この2か所で粗大ごみを受け付けるかどうかは、確認できません。[要確認: 両津・南佐渡クリーンセンターの持ち込み可否]

### 市で出せない物

テレビ、冷蔵庫、洗濯機、エアコンは、市で収集しません。石膏ボードや魚網も、収集しない物として市の資料に載っています。

原動機付自転車は、排気量50cc以下に限ります。燃料、オイル、バッテリーを取り除いて、クリーンセンターへ直接運びます。

### 家電4品目

手順は、次のとおりです。郵便局で、リサイクル料金を払います。振込証明書（家電リサイクル券）を受け取ります。廃家電と証明書を、クリーンセンターへ持ち込みます。窓口で、家電リサイクルに伴う手数料を払います。

| 品目 | 手数料（クリーンセンター窓口） |
|------|------------------------------|
| 冷蔵庫・冷凍庫 | 1,200円 |
| 洗濯機・衣類乾燥機 | 800円 |
| テレビ | 800円 |
| エアコン | 1,000円 |

### 許可業者

許可業者の一覧は、市の「一般廃棄物処理業等許可業者」のページ（2021年3月1日更新）にあります。ごみの収集運搬の許可業者として、10社が載っています。料金と依頼方法は、公式ページに記載がありません。[要確認: 佐渡市の許可業者への依頼方法と料金]

## 村上市

### 申込

市による粗大ごみの戸別収集は、公式ページに記載がありません。申込制度も、確認できません。

ステーションに出せる物は、燃やすごみと燃やさないごみです。指定袋か、中型ごみ処理券を使います。中型ごみ処理券は、1枚100円です。指定袋に入らない物のうち、80cm×50cm×40cm以内で15kg以内の物に使えます。

分別一覧表で「収集できない物」とされた家具は、ごみ処理場で受け入れます。たんす、学習机、テーブル、ソファーなどです。

### 料金

| 出し方 | 料金 |
|--------|------|
| 自己搬入 | 10kgまで60円。超えると10kgごとに60円を加算 |
| ステーション（中型ごみ処理券） | 1枚100円 |
| 許可業者 | 業者ごとに異なる |

自己搬入では、指定袋は使いません。

### 持ち込み

| 項目 | 内容 |
|------|------|
| 施設 | 村上市ごみ処理場（Kanadeviaエコパークむらかみ） |
| 住所 | 村上市桧原1147番地 |
| 電話 | 0254-60-2430 |
| 受付 | 月〜土（祝日を含む）8:30〜16:00 |
| 休み | 日曜、12月31日〜1月3日 |
| 予約 | 公式に記載がありません。[要確認: 持ち込みの予約の要否] |

手順は、次のとおりです。燃やすごみと燃やさないごみに分別して、車に積みます。受付で車ごと計量します。係員の指示で、荷物を降ろします。もう一度計量して、現金で払います。

持ち込めると書かれている物は、布団類、自転車、たんすや家具類（木製もスチール製も）、スプリングマットです。絨毯、スキー、スノーボード、エレクトーン、電化製品も載っています。

持ち込めない物は、原動機付自転車、ピアノ、事業活動に伴う木材（建設業の出材）、資源ごみ（雑誌、缶類）です。

### 許可業者

自分で運べないときは、市の収集運搬許可業者に頼みます。許可業者は、住んでいる地区ごとに決まっています。

| 地区 | 許可業者数 |
|------|-----------|
| 村上 | 6 |
| 荒川 | 3 |
| 神林 | 2 |
| 朝日 | 3 |
| 山北 | 2 |

合計16業者です。市のページは2022年2月の更新です。料金は業者ごとに違います。市の料金表はありません。依頼する前に、各業者へ料金を確認するよう案内されています。[要確認: 許可業者の現在の一覧]

許可がない人が、本人以外のごみを運んで処分することは、法律で罰せられます。

### 市で出せない物

市の処理困難物の一覧には、タイヤ、バイク、農機具、ガスボンベ、ピアノ、バッテリー、消火器などがあります。販売店に相談します。パソコンとテレビは、リサイクル対象品として収集しません。

## 分別で迷いやすい品目のQ&A

**Q1　布団は。**
佐渡市は、粗大ごみです。処理券を1枚貼ります。村上市は、汚れた物、化繊綿、羊毛なら、燃やすごみです。座布団くらいに切って出します。切らずに運ぶなら、処理場へ持ち込みます。

**Q2　マットレスとソファーは。**
佐渡市は、どちらも粗大ごみです。市の分別一覧表では、マットレスとソファーは、スプリング入りを含めて粗大ごみです。 村上市は、どちらも収集できない物で、処理場で受け入れます。スプリングは、外して分けます。

**Q3　たんすは。**
佐渡市は、粗大ごみです。横1.2m、高さ2.0m、奥行き0.6mに収まる物が対象です。村上市は、処理場で受け入れます。木製もスチール製も持ち込めます。

**Q4　自転車は。**
佐渡市は、粗大ごみの例に載っています。村上市は、収集できない物で、処理場で受け入れます。

**Q5　石油ストーブは。**
佐渡市は、ストーブが粗大ごみの例に載っています。油の抜き方は、公式に記載がありません。村上市は、石油・ガス・電気のストーブが燃やさないごみです。乾電池と油を抜いて出します。

**Q6　原動機付自転車は。**
佐渡市は、50cc以下に限り、クリーンセンターへ直接運びます。燃料、オイル、バッテリーを取り除きます。村上市は、処理場に持ち込めません。

**Q7　ピアノは。**
村上市は、ピアノを持ち込めません。電子ピアノは、処理場で受け入れます。佐渡市は、分別一覧表で、ピアノは引き取れないごみです。廃棄物処理業者等へ処理を頼みます。

**Q8　仏壇と神棚は。**
2市とも、仏壇と神棚は、取得した範囲の公式ページで見つかりませんでした。[要確認: 仏壇・神棚の分別（佐渡市・村上市）] 位牌や仏具も同じです。

**Q9　佐渡市の粗大ごみ処理券は、どこで買えますか。**
市内の小売店で買います。1枚520円（税込）です。販売店の一覧は、取得した範囲の公式ページで確認できません。[要確認: 処理券の取扱店]

## 実家をまるごと片付けるときの考え方

佐渡市は、処理券が1点520円です。点数が多いほど、費用が増えます。サイズの上限もあります。上限を超える物は、分解するか、別の方法を考えます。収集日が決まっているので、日程に合わせます。

村上市は、重量で決まります。大きな家具を何点か運んでも、10kgごとに60円です。ただし、車と人手が要ります。平日と土曜の日中に、処理場へ運ぶ必要があります。

佐渡市の実家は、本土からの移動も加わります。遠方の方は、何度も通うのが難しいことがあります。

次のようなときは、市の制度だけでは足りないことがあります。量が多い。家電4品目やピアノがある。搬出が難しい。遠方で通えない。そのときは、許可業者に見積りを取る方法があります。

見積りの取り方は、[自分で出す？業者に頼む？](../jibun-de-dasu-ka-gyousha-ka/)を見てください。費用の目安は、[新潟で実家を片付ける費用の目安](../jikkajimai-hiyou-niigata/)にあります。
