# 中之島信条クリーンセンターのごみ持ち込み｜長岡市・粗大ごみと枝葉も受付

## 結論：長岡市で粗大ごみを持ち込めるのは、ここだけです。月〜土曜の8:30〜16:30、前日までに電話が要ります

中之島信条クリーンセンターは、長岡市中条新田1080-2にあるごみ処理施設です。長岡市が持ち込みを受け付ける2施設のうち、受け入れる種類が多いほうです。電話は、（0256）97-7260です。

受け入れるのは、燃やすごみ、燃やさないごみ、粗大ごみ、枝葉・草です。粗大ごみと燃やさないごみを受け付けるのは、長岡市ではこの施設だけです。

受付は月曜から土曜の8:30〜16:30です。祝日、振替休日、年末年始は休みです。枝葉・草は、月・火・金・土曜だけで、1月・2月は持ち込めません。

持ち込めるのは、引越しなどで、やむを得ず多量のごみが出たときだけです。前日までに電話をして、施設の確認を受けます。

この記事は、長岡市の公式ページだけで書いています。確認日は2026年10月17日です。出かける前に、公式ページで最新の情報を確かめてください。

長岡市の2施設に共通するルールは、[長岡市のごみ持ち込みは2か所、前日までに電話が必要](../nagaoka-shi-gomi-mochikomi/)にあります。この記事は、中之島信条クリーンセンターに絞って説明します。

## どんなときに持ち込めますか

長岡市のごみは、ステーション収集が原則です。粗大ごみは、戸別収集が原則です。

処理施設に持ち込めるのは、「引越しなどで、やむを得ず多量のごみが出たとき」に限られます。前日までに電話をして、施設の確認を受けてから持ち込みます。

実家の片付けが、この条件に当たるかどうかは、公式ページに書かれていません。電話で、実家の片付けであることを伝えて確かめてください。[要確認: 実家の片付けが「やむを得ず多量のごみ」に当たるか（中之島信条クリーンセンター （0256）97-7260）]

市の「家庭ごみと資源物の分け方と出し方」（令和8年度版）には、次の決まりもあります。

- 他人のごみは、持ち込めません。
- 火事ごみを持ち込むときは、事前に電話をします。
- 業者が剪定・除草した枝葉は、持ち込めません。

## 電話は、どうかければよいですか

持ち込みの前日までに、中之島信条クリーンセンターへ電話します。市のページの表記は、「（0256）97-7260」です。

粗大ごみは、電話であわせて金額の確認を受けます。市のページに、「持込む前に連絡をして金額を確認してください」とあります。

電話をかけられる時間帯は、市の持込ページに書かれていません。受付時間の8:30〜16:30の中でかけるのが無難です。

見学の電話番号は、別にあります。中之島信条クリーンセンターの見学は、0256-97-7251（平日9:00〜12:00、13:00〜16:00）です。持ち込みの電話ではありません。

## 粗大ごみの持ち込み方

粗大ごみを持ち込めるのは、長岡市では中之島信条クリーンセンターだけです。寿クリーンセンターは受け付けません。

持ち込み方は、次のとおりです。

1. 前日までに電話して、品目と金額を確認します。
2. 粗大ごみ処理券シールを買います。指定ごみ袋を売っている店で、買えます。
3. 金額分のシールを、粗大ごみに貼ります。
4. 受付時間内に持ち込みます。

料金は、戸別収集と同額です。200円、600円、1,000円の3段階です。処理券シールは、200円のものだけが販売されています。600円なら3枚、1,000円なら5枚を貼ります。

大型の家具を解体しても、粗大ごみの料金です。市のガイド（令和8年度版）には、粗大ごみ処理手数料を、令和9年（2027年）7月1日の受付分から改定する検討が載っています。料金は、変わる可能性があります。

市の粗大ごみの定義は、燃やすごみ・燃やさないごみの指定袋に入らない物です。50cm四方に切っていない布団、カーテン、カーペットも、粗大ごみです。品目ごとの金額は、[長岡市の粗大ごみの出し方](../nagaoka-shi-sodaigomi/)にまとめています。

持ち込める点数と大きさの上限は、持込ページに書かれていません。戸別収集は、1回に5点までで、2人で持てない物は収集できません。スプリング入りのマットレス・ソファー・いすは、戸別収集ができません。処理施設での処理が難しいためと、市は説明しています。持ち込みでの扱いは、書かれていません。[要確認: 粗大ごみの持ち込み点数・寸法・重量の上限と、スプリング入りのマットレス・ソファー・いすの可否（中之島信条クリーンセンター （0256）97-7260）]

## 燃やさないごみの持ち込み方

燃やさないごみは、中之島信条クリーンセンターだけが受け付けます。市の「燃やさないごみ」のページ（2026年3月16日更新）には、次の品目があります。

- 金属・陶磁器・ガラス類
- ゴム・合成皮革製品
- ストーブ・ファンヒーター・小型家電製品（灯油は抜き、乾電池は取り外す）
- プラスチック製品自体が商品となっているもの
- エンジンオイル・ペンキの缶（中身を空にする）
- DVD・CD、ビデオテープ・カセットテープのケース

持ち込みの決まりは、次のとおりです。

- 正しく分別し、中身が見えるようにします。
- 段ボール箱に入れての持ち込みは、禁止です。
- 大きい物は、50cm四方に切ります。
- カーペット、じゅうたん、ブルーシートも、50cm四方に切ります。切れない場合は、粗大ごみに申し込みます。切っていない物は、粉砕する機械に絡まって、故障の原因になります。

ステーション収集では、割れていない蛍光管は、燃やさないごみに出せません。「スプレー缶類・発火物・有害物」として出します。スプレー缶・蛍光管・乾電池の持ち込みの扱いは、持込ページに書かれていません。持ち込む前の電話で、あわせて確かめてください。

## 枝葉・草の持ち込み方

枝葉・草は、月・火・金・土曜の8:30〜16:30に、受け付けます。祝日、振替休日、年末年始は休みです。1月と2月は、持ち込めません。

現行の持込ページには、枝葉・草の寸法と料金が書かれていません。市の令和6年4月版の保存版PDFには、持ち込みの方法として、次の記載があります。令和8年度版のガイドにある、ステーション収集の「枝葉・草」も、同じ寸法です。

| 区分 | 決まり |
|------|------|
| 枝葉 | 1本あたり太さ10cm以内、長さ150cm以内 |
| 草・落ち葉 | 土をしっかり落とす |

業者が剪定・除草した枝葉は、持ち込めません。料金は、電話で確かめてください。

## 料金はいくらですか（計算例つき）

燃やすごみと燃やさないごみは、持ち込み方で料金が変わります。

| 持ち込み方 | 料金 |
|------|------|
| 指定袋に入れて持ち込む | 無料 |
| 指定袋に入れずに持ち込む | 100kgまで300円 |
| 100kgを超えた分 | 10kgあたり30円を加算 |

指定袋を使わず、重さだけで料金が決まる場合の計算例です。

| ごみの重さ | 料金 |
|------|------|
| 100kg | 300円 |
| 150kg | 300円＋30円×5＝450円 |
| 200kg | 300円＋30円×10＝600円 |

10kgに満たない端数の扱いと、支払い方法（現金のみか）は、持込ページに書かれていません。[要確認: 10kg未満の端数の計算方法と、支払い方法（中之島信条クリーンセンター （0256）97-7260）]

家庭菜園用のポリマルチは、例外です。事前に連絡し、燃やさないごみ用の指定袋に入れれば、持ち込めます。農家で使ったものは、持ち込めません。生ごみは、生ごみ用の指定袋に入ったままでは、持ち込めません。燃やすごみ用の指定袋に入れ替えます。

## 中之島信条クリーンセンターのごみ持ち込み、よくある質問

**Q　中之島信条クリーンセンターの受付時間は、何時から何時までですか。**
月曜から土曜の8:30〜16:30です。祝日、振替休日、年末年始は休みです。枝葉・草は、月・火・金・土曜だけです。

**Q　中之島信条クリーンセンターに、粗大ごみは持ち込めますか。**
持ち込めます。長岡市で粗大ごみを受け付けるのは、ここだけです。料金は、戸別収集と同額の200円・600円・1,000円です。処理券シールを貼り、前日までに電話します。

**Q　中之島信条クリーンセンターに、予約は要りますか。**
必要なのは、前日までの電話です。電話で施設の確認を受けてから、持ち込みます。

**Q　中之島信条クリーンセンターで、枝葉は持ち込めますか。**
月・火・金・土曜に持ち込めます。1月と2月は、持ち込めません。
