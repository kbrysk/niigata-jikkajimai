# クリーンセンターかしわざきの持ち込み｜受付日時・料金・持ち込めない物

## 結論：月〜金は16:30まで、土曜と祝日は11:30まで。日曜は休みです

クリーンセンターかしわざき（柏崎市松波4-13-13）は、ごみを自分で運べる柏崎市の処理施設です。持ち込めるのは、燃やすごみ、燃やさないごみ、粗大ごみの3種類です。

受付は、月〜金曜（祝日を除く）が8:30〜16:30、土曜と祝日が8:30〜11:30です。日曜と、12月29日〜1月3日は受け付けません。

いまは新しいごみ処理場の工事中です。受付は「仮設事務所」で行います。受付のあと、屋外にいる係員にごみを渡します。

- 燃やす・燃やさないごみ：分別して、市の指定ごみ袋に入れて持っていきます。
- 粗大ごみ：粗大ごみ処理券（1枚300円）を先に買い、申請書と一緒に出します。
- 処理券と指定ごみ袋は、施設では売っていません。市内のスーパー、コンビニなどで先に買います。
- 家電4品目（テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機、エアコン）、ピアノ、耐火金庫などは持ち込めません。

予約が要るかどうかは、公式ページに書かれていません。不安なときは、電話（0257-23-5170）で確かめます。

この記事は、柏崎市の公式情報だけでまとめました。確認日は2026年10月17日です。

## 受付の日時と休み

市のページ（2026年1月11日更新）に書かれた受付は、次のとおりです。

| 曜日 | 受付時間 |
|------|------|
| 月〜金曜（祝日を除く） | 8:30〜16:30 |
| 土曜、祝日 | 8:30〜11:30 |
| 日曜、12月29日〜1月3日 | 受付なし |

昼休みの記載は、市のページにありません。

市の分別ガイドブックの自己搬入のページには、「土曜・日曜 8:30〜11:30」と並べた表記があります。同じページに「日曜は搬入できません」とも書かれています。この記事は、新しい市のページに従いました。

## 受付の場所と流れ

新しいごみ処理場の工事のため、受付場所と持ち込み方法が変わっています。市のページでは、次の2段階です。

1. クリーンセンター仮設事務所で、受け付けをします。
2. 屋外にいる係員に、ごみを引き渡します。

仮設事務所は、クリーンセンターの敷地内にあります。市の工事のお知らせでは、2025年11月上旬から、現在のごみ処理場の敷地内の仮設事務所で受け付ける、と案内されています。ガイドブックの「事務所の中で受付、お客様用駐車場」という案内は、工事前のものです。

粗大ごみは、処理券と「粗大ごみ処理申請書」を、一緒に事務所へ出します。申請書は、市のホームページからダウンロードできます（PDFとWord）。

## 料金

料金は、ごみの種類と、指定袋を使うかで変わります。

| 種類 | 料金 |
|------|------|
| 燃やすごみ・燃やさないごみ（指定袋に入れる） | 市のページに、持ち込みの料金の記載なし。指定袋の代金がかかる |
| 粗大ごみ | 粗大ごみ処理券 1枚300円。品目ごとの必要枚数分 |
| 燃やす・燃やさないごみ（指定袋に入れない） | ガイドブック（令和2年2月時点）では、搬入量350kg以下が3,150円 |

### 粗大ごみの処理券

処理券は、1枚300円です。品目ごとに、必要な枚数が決まっています。ガイドブックの分別辞典には、たとえば次の例があります。

| 品目 | 処理券の金額 |
|------|------|
| 畳（半畳は1畳分で数える） | 300円 |
| たんす | 900円 |
| ソファー（1人用） | 600円 |
| ソファー（2人用以上） | 900円 |

ほかの品目は、市の「家庭ごみ ごみ分別検索」か、分別辞典で調べます。持ち込める点数に制限はありません。ただし、畳は1日16枚までです。

ガイドブックには、「クリーンセンターでは指定ごみ袋や粗大ごみ処理券を扱っておりません。事前に市内のスーパーマーケット、コンビニエンスストアなどの小売店か柏崎市役所売店で、ご購入ください」とあります。当日、施設では買えません。

指定ごみ袋の価格は、市のページ（2020年2月10日更新）に、大（50リットル）5枚入り350円、中（25リットル）10枚入り350円、などと載っています。

### 指定袋を使わない場合の手数料

ガイドブックには、指定袋に入れない燃やすごみ・燃やさないごみは、次の手数料が必要と書かれています。10kg未満の端数は、10kgに切り上げます。

| 搬入量 | 廃棄物処理手数料 |
|------|------|
| 350kg以下 | 3,150円 |
| 350kgを超える場合 | 3,150円に、350kgを超える重量10kgごとに90円を加算した額 |

たとえば、400kgなら、3,150円＋90円×5＝3,600円です。

この手数料は、令和2年2月時点のガイドブックの金額です。市の現在のページには、載っていません。支払いの方法や場所も、書かれていません。[要確認: 指定袋なしの手数料の現在の額と、支払い方法（環境課 クリーン推進係 0257-23-5170）]

## 持ち込めるもの・持ち込めない物

### 持ち込めるもの

市のページに書かれた、持ち込めるごみは、3種類です。

- 燃やすごみ
- 燃やさないごみ
- 粗大ごみ

資源物は、受付日時や場所が違います。クリーンセンターではなく、資源物リサイクルセンターなどに出します。

### 持ち込めない物

ガイドブックの「市で収集しないもの」のページには、「クリーンセンターで処理できないもの」が書かれています。処理は、受け入れ可能な許可業者か、販売店に頼みます。分別辞典で「収集不可」とされた品目には、次の物があります。

| 区分 | 品目の例 |
|------|------|
| 家電4品目 | テレビ、冷蔵庫・冷凍庫、洗濯機、衣類乾燥機、エアコン |
| 楽器・金庫 | ピアノ、電子ピアノ・オルガン、耐火金庫 |
| 介護・電動の家具 | 介護用ベッド、電動ベッド、電動ソファー、電動車いす |
| 建築・土木の物 | がれき、瓦、コンクリートブロック、セメント、石こうボード、単管 |
| 危険な物 | 消火器、ガスボンベ、石油類（灯油・ガソリン）、エンジンオイル、劇薬 |
| 車・農機具 | タイヤ、草刈り機、芝刈り機、耕運機、除雪機 |
| その他 | 漬物石（自然石）、ドラム缶、チェーンソー、鉄アレイ、つるはし |
| 医療廃棄物 | クリーンセンターでは処理できない。かかりつけの医療機関などに頼む |

ガイドブックの表では、「おもに金属でできたもの」「おもにプラスチック・樹脂でできたもの」「おもに木でできたもの・切り株・木材」「コンクリート・石」「タイヤ」も、許可業者か販売店に頼む区分です。品目が決まらないときは、環境課へ問い合わせるよう、書かれています。

この表は、令和2年2月時点のガイドブックです。最新の分別は、市の「家庭ごみ ごみ分別検索」で確かめます。

家電4品目は、市の家電リサイクルのページ（2026年8月21日更新）で、次の3つの方法が案内されています。買い替えや購入先の店に引き取りを頼む方法、郵便局でリサイクル料金を払って指定引取場所へ自分で持ち込む方法、郵便局でリサイクル料金を払って許可業者に頼む方法です。指定引取場所の一覧は、市のページには載っていません。家電製品協会の検索サイトで調べます。

品目ごとの出し方は、[柏崎市の粗大ごみの出し方](../kashiwazaki-shi-sodaigomi/)にまとめています。

## 予約は要りますか

公式ページに、持ち込みの予約や申込の記載はありません。

粗大ごみの持ち込みで必要なのは、事前の処理券の購入と、当日の処理申請書です。電話での予約は、書かれていません。

## 庭の枝・草は、どこへ持ち込めますか

家庭の庭から出た枝や草は、次の2か所に持ち込めます。

| 持ち込み先 | 内容 |
|------|------|
| 市内のペレット工場（株式会社アール・ケー・イー 木質ペレット工場、柏崎市軽井川931-48） | 月〜金 9:00〜16:00（正午〜13:00は休止）。事前に「せんてい枝・庭の草個人搬入申請書」を書いて、現地の受付に出す |
| クリーンセンターかしわざき | 毎週 火曜・金曜 8:30〜16:30（祝日は11:30まで）。12月〜3月は休止。先に事務所で受け付けをする |

枝は、長さ1m以内、直径5cm以内です。束ねるときは、わらか麻縄を使います。ビニールひもは使えません。庭の草は、土や砂を落としてから持っていきます。田畑や事業から出た枝・草は、対象外です。

クリーンセンターでは、枝・草を入れるコンテナの場所に、車は入れません。駐車場から運びます。台車が用意されています。

## 事業のごみと、新ごみ処理場の工事

事業活動で出る一般廃棄物は、自分でクリーンセンターへ持ち込めます。指定ごみ袋は使えません（ガイドブック）。この記事は、家庭のごみを対象にしています。

市のページ（2025年5月2日更新）では、新ごみ処理場は2029年4月に完成・稼働する予定です。工事の期間中も、燃やすごみ、燃やさないごみ、粗大ごみは、これまでどおり持ち込めます。

資源物の持ち込み先は、2025年11月から、次の3か所です。

- 西本町資源物リサイクルセンター
- 佐藤池資源物リサイクルセンター
- 松波資源物リサイクルステーション

受付日時などは、市の「資源物リサイクルセンター・リサイクルステーション」のページ（2026年4月1日更新）で確かめます。

## 実家の片付けで、量が多いときは

持ち込みは、引越しや大掃除などで大量のごみが出たときの方法として、市が案内しています。量が多いときは、次の順で進めます。

1. 出す物を、燃やすごみ、燃やさないごみ、粗大ごみ、資源物に分けます。
2. 粗大ごみの処理券の枚数を、分別辞典か分別検索で調べます。
3. 処理券と指定袋を、市内の販売所で買います。
4. 申請書を、先に書いておきます。
5. 受付時間内に、仮設事務所へ向かいます。

家電4品目、ピアノ、耐火金庫などは、持ち込めません。車や人手が足りないときは、市の許可を持つ業者に頼む方法があります。許可業者の確認方法は、[柏崎市ほかの許可業者の確認方法](../joetsu-kashiwazaki-shibata-sanjo-kyoka-gyosha/)にあります。自分でやるか頼むかの判断は、[自分で出す？業者に頼む？](../jibun-de-dasu-ka-gyousha-ka/)が材料になります。

## よくある質問

**Q　クリーンセンターかしわざきの受付時間は、何時までですか。**
月〜金曜（祝日を除く）は16:30まで、土曜と祝日は11:30までです。日曜と、12月29日〜1月3日は受け付けません。

**Q　クリーンセンターかしわざきの受付は、どこですか。**
新ごみ処理場の工事のため、いまはクリーンセンター仮設事務所です。受付のあと、屋外にいる係員にごみを引き渡します。

**Q　柏崎市のごみ持ち込みに、予約は要りますか。**
公式ページに、予約の記載はありません。持ち込む前に、環境課（0257-23-5170）へ確認します。

**Q　クリーンセンターかしわざきで、粗大ごみの持ち込みはいくらですか。**
粗大ごみ処理券を、品目ごとの枚数分用意します。1枚300円です。処理券は、市内の販売所で事前に買います。施設では売っていません。

**Q　柏崎市のクリーンセンターに、家電のテレビや冷蔵庫は持ち込めますか。**
持ち込めません。家電4品目は、市では収集・受け入れをしていません。ガイドブックでは、販売店か指定引取場所へ頼む方法が案内されています。
