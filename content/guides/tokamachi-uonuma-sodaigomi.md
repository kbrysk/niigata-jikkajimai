# 十日町市・魚沼市・南魚沼市の粗大ごみの出し方｜豪雪地3市の制度を比較

十日町市には、粗大ごみの戸別収集も処理券もありません。家具を分解して材質別に出すか、エコクリーンセンターへ重量制で持ち込みます。魚沼市と南魚沼市は、予約制の戸別収集です。処理券は小物500円、中物1,000円、大物2,000円で、2市は同額です。

## この記事で分かること

- 十日町市は持ち込み中心、魚沼市と南魚沼市は予約制の戸別収集、という制度の違い
- 実家じまいで出やすい布団、ソファー、仏壇などの扱いと料金
- 各市の持ち込み先、受付時間、市で出せない物

この記事は、各市の公式情報だけでまとめました。確認日は2026年10月3日です。申し込む前に、公式ページで最新の情報を見てください。

## 十日町市

### 申込

粗大ごみとして一括で収集する制度は、公式ページで確認できませんでした。申込も、処理券もありません。

方式は、家具を分解して、材質ごとに分別する形です。燃やすごみ、埋立てごみ、金属類のそれぞれの日に、ごみステーションへ出します。ステーションに出せない物は、自分でエコクリーンセンターへ運びます。

自分で運べない、分解できない場合は、市の許可業者に頼みます。有料です。許可業者は、市のページの一覧表に9業者が載っています。本文は7業者と書かれているため、最新は市に確認します。料金は、各業者に問い合わせるよう案内されています。

### 料金

| 出し方 | 料金 |
|--------|------|
| エコクリーンセンターへ自己搬入（家庭系） | 50kgまで450円。超えると10kgごとに90円を加算 |
| ごみステーション | 市指定ごみ袋（有料） |
| 許可業者 | 業者ごとに異なる |

自己搬入の料金は、令和6年4月1日からの額です。燃やすごみと埋立てごみを同じ車で運ぶときは、種類ごとに計量します。

### 持ち込み

| 項目 | 内容 |
|------|------|
| 施設 | 十日町市エコクリーンセンター |
| 住所 | 十日町市高田町六丁目915番地2 |
| 電話 | 025-752-3924（環境衛生課。課の番号） |
| 受付 | 月〜土 8:45〜17:00。日曜、祝日、12月31日〜1月3日は休み |
| 袋 | 市指定袋は使わず、市販の透明・半透明の袋 |
| 予約 | 公式に記載がありません。[要確認: 自己搬入の予約の要否] |

受け入れるのは、燃やすごみと埋立てごみです。事前に分別します。長さ200cm、幅90cmを超える物は、分解して運びます。家具と寝具は、金属部分を取り除きます。

### 市で出せない物

| 品目 | 扱い |
|------|------|
| 家電4品目 | 市では収集しない |
| ピアノ、オルガン | 購入店か運搬許可業者へ |
| タイヤ | 自動車整備工場か専門業者へ |
| 消火器 | 市の案内する事業者へ相談 |
| 電動アシスト付き自転車 | 再生処理業者へ自己搬入 |
| 120cmを超える金属製品 | 再生処理業者へ自己搬入 |
| 農機具 | 収集しない。購入店へ相談 |
| 事業系ごみ | 市の品目表は家庭ごみが対象 |

分解できないスプリング入りのベッドも、許可業者に頼みます。

## 魚沼市

### 申込

大型ごみは、予約制の戸別収集です。月2回、自宅の玄関先で収集します。家の中には入りません。

| 方法 | 期限 |
|------|------|
| 電話 025-792-9900 | 収集日の前日17時まで |
| FAX 025-792-4220 | 収集日の3日前まで |
| メール haikibutsu@city.uonuma.lg.jp | 収集日の3日前まで |
| 電子申請 | 収集日の3日前まで |

伝える内容は、世帯主の氏名、住所、電話番号、区分ごとの品名と数量です。収集日は、各地区の家庭ごみ収集カレンダーで確認します。大型ごみの案内には、当日に出す時刻の記載がありません。ガイドブックの「ごみ出しのルール」には、ごみは収集日当日の朝8時までに出す、とあります。

### 料金

| 区分 | 目安 | 処理券 |
|------|------|--------|
| 小物 | 縦・横・高さのいずれかが30cm以上100cm未満 | 500円 |
| 中物 | 同じく100cm以上150cm未満 | 1,000円 |
| 大物 | 同じく150cm以上 | 2,000円 |
| 6号袋 | 袋に入る物（15kg程度まで） | 350円 |

処理券は、品物ごとに貼ります。購入先は、市の「指定ごみ袋等取扱店一覧」で確認します。

### 持ち込み

| 項目 | 内容 |
|------|------|
| 施設 | エコプラント魚沼 |
| 住所 | 魚沼市中島707-1 |
| 電話 | 025-792-3055 |
| 受付 | 月〜土（祝日を含む）8:00〜17:00、日曜 8:00〜12:00 |
| 休み | 1月1日〜1月3日 |
| 料金（家庭の大型ごみ） | 10kgごとに250円。指定袋に入れた燃やせるごみ・燃やせないごみは無料 |

持ち込めるのは、本人かその家族です。市の収集運搬許可を持つ業者も運べます。予約の要否は、公式に記載がありません。[要確認: 自家搬入の予約の要否]

市のページ（2025年7月23日更新）には、点検日の記載があります。10月1日〜10月10日は、燃やせないごみと大型ごみの受け入れを休みます。令和8年度の家庭ごみ収集カレンダーにも、同じ10月1日〜10日は燃やせないごみと大型ごみを搬入できない、と書かれています。

### 市で出せない物

肥料・農薬などの薬品類、消火器、タイヤ、バッテリー、廃油、プロパンガスボンベ、耐火性金庫は、収集できません。石、土砂、泥も同じです。家電4品目は、エコプラント魚沼で引き取れません。

2mを超える細長い物は、収集できません。自家搬入のみです。6号袋に入らない農業用マルチシートも、収集できません。

## 南魚沼市

### 申込（六日町・塩沢地域）

| 項目 | 内容 |
|------|------|
| 申込先 | 資源循環推進課 025-782-0339 |
| 受付 | 月〜金 8:30〜17:15（祝日、振替休日、閉庁日を除く） |
| 期限 | 収集日の3日前まで。休日の場合はその前日まで |
| 収集日 | 毎月第2・第4土曜日（祝日も収集） |
| 点数 | 1回の収集で最大10個 |
| キャンセル | 収集日の前日の正午まで |

伝えるのは、住所、氏名、電話番号、品目と数量です。処理券を購入して、1個に1枚貼ります。収集日の朝8:30までに、玄関前に出します。雨や雪の日は、濡れないようシートをかぶせます。

棚やたんすは、中身を出しておきます。中身が残った物は、収集しません。

### 料金（六日町・塩沢地域）

| 区分 | 目安（縦・横・高さの長い辺） | 処理券 |
|------|------------------------------|--------|
| 小物 | 1m未満 | 500円 |
| 中物 | 1m以上1.5m未満 | 1,000円 |
| 大物 | 1.5m以上 | 2,000円 |

カーペットとじゅうたんは、畳数で決まります。6畳までが500円、7畳以上が1,000円です。

10kg以下で、指定袋の口を縛った状態で入る物は、ステーションに出せます。

### 持ち込み

| 項目 | 内容 |
|------|------|
| 施設 | 可燃ごみ処理施設、不燃ごみ処理施設 |

| 電話 | 025-782-0339 |

| 休み | 1月1日〜1月3日 |
| 料金 | 指定袋なしは10kgあたり50円。60cm超の破砕ありは100円 |

粗大ごみの直接搬入は、品物ごとに決まります。公式の料金一覧では、多くの品目が「重量」です。予約の要否は、公式に記載がありません。[要確認: 直接搬入の予約の要否]

### 大和地域

大和地域は、エコプラント魚沼へ予約します。電話は025-792-9900です。収集日の5日前から前日17時までです。持ち込み先も、エコプラント魚沼です。

ただし、大和地域のページは更新が古く、令和3年と令和4年です。申し込む前に、現在の内容を確認します。

### 市で出せない物

自動車と部品、バイク、タイヤ、バッテリー、耐火金庫は、処理できません。ピアノ、消火器、ガスボンベ、塗料、廃油も同じです。

2人で運べない物は、収集しません。2mを超えて破砕機に入らない物も、処理できません。家電4品目は、販売店に頼みます。引き取りがないときは、収集許可業者に問い合わせます。

## 分別で迷いやすい品目のQ&A

**Q1　布団は。**
十日町市は、「燃やす（粗大）」です。自己搬入します。魚沼市と南魚沼市は、どちらも小物で500円です。魚沼市は、毛布やカーテンも大型ごみです。南魚沼市は、直径1m未満に丸めて縛れば、複数枚を1組にできます。

**Q2　スプリング入りのマットレスは。**
十日町市は、スプリングを外します。スプリング部分は金属類、残りは燃やす（粗大）です。分解できないベッドは、許可業者です。魚沼市と南魚沼市は、スプリング入りが大物の2,000円です。スプリングなしは、魚沼市が小物、南魚沼市はサイズで決まります。

**Q3　ソファーは。**
十日町市は、金属部分を外します。それ以外は、長さ200cm以下、幅90cm以下にして、燃やす（粗大）で自己搬入します。魚沼市は中物で、2人掛けを超えると大物です。南魚沼市は、スプリングなしが小物（500円）です。2人掛けは中物（1,000円）、スプリング入りは大物（2,000円）です。

**Q4　仏壇は。**
十日町市は、木製部分が長さ200cm以下、幅90cm以下なら、燃やす（粗大）で自己搬入します。超える場合は収集しません。魚沼市は大型ごみで、サイズ区分で決まります。南魚沼市は、長辺で小物・中物・大物に分かれます。位牌や仏具は、公式の品目表に見つかりませんでした。[要確認: 位牌・仏具の分別]

**Q5　神棚は。**
魚沼市は大型ごみです。サイズ区分で、処理券の額が決まります。十日町市と南魚沼市は、品目表に見つかりませんでした。[要確認: 神棚の分別（十日町市・南魚沼市）]

**Q6　石油ストーブは。**
十日町市は、長さ120cm以下かつ直径50cm以下なら金属類です。燃料タンクを空にし、電池は外します。南魚沼市は小物で500円です。灯油と電池を抜きます。魚沼市は大型ごみで、サイズ区分に従います。

**Q7　物干し台は。**
十日町市は、台座のコンクリート部分が埋立て（粗大）です。2個1組までで、自己搬入します。竿と支柱は金属類です。魚沼市は、中物で2脚1組です。南魚沼市は、小物で2脚1組です。コンクリート付きは除きます。

**Q8　家電4品目は。**
3市とも、市では引き取りません。購入した店か、買い替える店に頼みます。十日町市は、郵便局で家電リサイクル券を買い、長岡市の指定引取場所へ持ち込む方法もあります。事前に電話します。

## 実家をまるごと片付けるときの考え方

十日町市は、分解と材質別の分別が前提です。たんす1つでも、木と金属を分けます。量が多いと、時間も手間もかかります。

魚沼市と南魚沼市は、予約制の戸別収集です。魚沼市は月2回、南魚沼市は月2回の土曜です。1回に出せる数にも上限があります。南魚沼市は10個までです。収集日に合わせて、何回かに分けます。

次のようなときは、市の制度だけでは足りないことがあります。量が多い。家電4品目やピアノがある。冬の積雪で搬出が難しい。遠方で何度も通えない。そのときは、許可業者に見積りを取る方法があります。

見積りの取り方は、[自分で出す？業者に頼む？](../jibun-de-dasu-ka-gyousha-ka/)を見てください。雪の時期の考え方は、[冬の実家じまい](../fuyu-no-jikkajimai-yukioroshi/)にまとめました。
