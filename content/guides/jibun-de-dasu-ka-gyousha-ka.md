# 自分で出す？業者に頼む？新潟の実家片付け、分かれ目の5つの基準

## この記事で分かること

- 自分で出すか、業者に頼むかを決める5つの基準
- 無許可業者のリスクと、一般廃棄物収集運搬の許可の確認方法
- 見積りで確認すべき項目

実家を片付けるとき、「自分で市に出すか、業者に頼むか」で迷う人は多いです。どちらが正解ということはありません。

この記事では、判断の分かれ目を5つに整理します。特定の業者は紹介しません。比較は別の記事で扱います。

## 判断の5つの基準

先に、全体の表です。

| 基準 | 自分で出しやすい | 業者に頼むほうがよい |
|------|------|------|
| 1. 量 | 少ない。市の収集に収まる | 多い。何回も運ぶ必要がある |
| 2. 階段・搬出経路 | 1階中心。車が近くに停められる | 2階以上、急な階段、道が狭い |
| 3. 積雪期 | 雪のない時期 | 雪の時期（足元・搬出路が悪い） |
| 4. 遠方 | 近い。何度も通える | 遠い。帰省の回数が限られる |
| 5. 期限 | 余裕がある | 退去・売却・冬までに終えたい |

ひとつだけで決めず、全体で考えてください。

## 基準1　量はどれくらいまでなら自分で出せる？

市の制度には、量の制限があります。

- 長岡市の粗大ごみの戸別収集は、**1回に収集できるのは5点まで**です。
- 新潟市の自己搬入は、**透明か半透明の90リットル以下の袋**に入れ、燃やすごみ・燃やさないごみ・粗大ごみを分けて持ち込みます。
- 家電4品目（エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機）は、市では処理できません。別の方法が必要です。

何点・何袋あるかを数えて、市のルールの範囲に収まるかを見ます。「何度も繰り返すことになりそう」なら、その時点で業者を検討する目安です。

量が多いかどうかは、感覚だけで判断しないでください。部屋ごとに、収納の中も含めて数えます。実家は、押し入れ、物置、納屋、車庫にも物が入っていることがあります。

## 基準2　階段と搬出経路は、なぜ見る？

市の収集は、**家の前まで出す**のが基本です。長岡市は、一戸建てなら玄関先（高床式なら階段下）の、道路から見える所に出すよう案内しています。集合住宅は1階の入り口付近です。

つまり、家の中から外へ運ぶ作業は、自分でやる必要があります。

- 2階から重いタンスやベッドを降ろせるか
- 階段や廊下の幅は足りるか
- 玄関から道路までの距離はどれくらいか

新潟市も、重いものや量が多い場合は、複数人での搬入を勧めています。人手が足りないなら、業者の搬出を検討しましょう。無理に運んで、けがや家の傷みにつながるのは避けたいところです。

## 基準3　積雪期は、なぜ判断が変わる？

雪の時期は、片付けの条件が悪くなります。

- 玄関先や道路が滑りやすく、運ぶだけで危険が増す
- 収集日の朝に、雪の中で出す必要がある（新潟市は朝8時までに指定の場所へ出す）
- 業者の日程や料金の条件が、雪で変わる場合がある（見積りで確認）

新潟県は、除雪作業事故の防止を呼びかけています。雪下ろしだけでなく、雪の中での作業全般に注意してください。冬の実家じまいと雪対策は、別記事（fuyu-no-jikkajimai-yukioroshi）で説明しています。

可能なら、雪が降る前に搬出まで終える計画にします。

## 基準4　遠方だと、どう変わる？

遠方では、「何度も通えない」ことが最大の条件です。

市の粗大ごみ収集は、申し込みから収集まで、新潟市で3日〜1週間以降、長岡市で数日後です。収集日は平日で、処理券を貼って朝に出す必要があります。持ち込みは、長岡市の場合、平日と土曜の日中（月〜土曜の午前8時30分〜午後4時30分）で、事前の電話が必要です。

交通費と宿泊費、仕事を休む日数を足すと、「自分でやる」が結果的に高くつくことがあります。費用の目安は、別記事（jikkajimai-hiyou-niigata）にまとめています。

帰省を減らす段取りは、別記事（enpou-kara-jikkajimai）が参考になります。

## 基準5　期限があるなら？

期限がある場合は、業者の日程に合わせるほうが確実です。

- 退去・売却・解体の日が決まっている
- 雪が降る前に終えたい
- 相続の手続きなど、ほかの期限と重なっている（相続登記の申請は、取得を知った日から3年以内。相続放棄は、相続の開始を知ったときから3か月以内。専門家に相談してください）

市の収集や持ち込みは、年末・夏休み・引っ越しシーズンに混みます（新潟市）。ぎりぎりの日程は避けてください。

## 無許可の業者には、なぜ注意が必要？

業者に頼むときに、いちばん大事な点です。

環境省は、家庭の廃棄物を、市区町村の許可や委託を受けずに収集する無許可の回収業者を利用しないよう呼びかけています。無許可業者の営業の例として、次が挙げられています。

- 町中を大音量で巡回する
- 空き地で回収する
- チラシを配る
- インターネットで広告する

廃棄物を渡すと、不法投棄や不適正な処理、不適正な管理による火災などにつながるおそれがあります。環境省は、また、高額な料金を請求される事例にも触れています。

長岡市も、「許可なく廃棄物を収集運搬する行為は法律違反」と案内しています。「無料」と告知されながら料金を請求されるトラブルがあることも、市の注意情報にあります。

国民生活センターによると、不用品回収サービスの相談は、2018年度の1,354件から、2021年度の2,231件へ増えています。「安価な定額パックのはずが、作業後に高額な料金を請求された」という相談が例に挙がっています。

## 一般廃棄物収集運搬の許可は、どう確認する？

家庭から出るごみを回収できるのは、**市区町村の「一般廃棄物処理業（収集運搬）の許可」を持つ業者**です。環境省と長岡市は、産業廃棄物処理業の許可や古物商の許可では、家庭の廃棄物は回収できないと明記しています。

確認の手順は、次のとおりです。

1. **市のホームページの一覧で確認する。** 長岡市は「長岡市ごみ収集運搬業許可業者」のページを、新潟市は「一般家庭から排出されるごみを自ら運搬することができないときは」のページ（許可業者の一覧PDF）を設けています。業者名が載っているかを見ます。
2. **許可の対象地域を確認する。** 長岡市の一覧には、「川口地域に限り収集できる業者」と「川口地域を除く市内全域を収集できる業者」の区別があります。実家のある地域に対応しているかを確認します。
3. **許可の種類を、業者に尋ねる。** 「一般廃棄物の収集運搬の許可はありますか」と聞き、市の許可であることを確認します。
4. **ごみの運搬を誰が行うかを尋ねる。** 遺品整理を行う会社の中には、運搬を別の会社が行う場合があります。運搬を行う会社が許可業者か、確認してください。
5. **分からないときは、市の担当課に問い合わせる。** 長岡市は環境事業課（0258-24-2837）、新潟市は環境部の廃棄物対策の担当課（025-226-1407）が案内されています。

一覧に載っていない場合は、依頼する前に、市の担当課へ確認してください。ホームページに「許可あり」と書いてあるだけでは、確認になりません。

なお、市の許可業者の一覧が最新とは限りません。長岡市のページには、令和4年時点の情報という注記があります。電話で、現在も許可が有効か確認するのが安全です。

## 見積りで確認すべき項目は？

国民生活センターは、遺品整理サービスで、「高額な追加料金が発生した」「処分しない予定の遺品が処分された」「高額なキャンセル料を請求された」といった相談が寄せられていると公表しています。次の項目を、見積りの段階で確認し、書面で受け取ってください。

| 確認項目 | 見るポイント |
|------|------|
| 見積書の形式 | 作業内容と費用が明確に出ているか |
| 追加料金 | どんな場合に増えるか（階段、駐車場、量の増加、特殊な品目） |
| キャンセル料 | いつから、いくらかかるか |
| 作業範囲 | 仕分け、搬出、清掃、買取のどこまでか |
| 残す物の扱い | 残す遺品と処分する遺品を、どう区別するか |
| 許可 | 一般廃棄物の収集運搬の許可の有無、運搬する会社 |
| 家電4品目 | リサイクル料金と運搬料金を、どう扱うか |
| 立会い・鍵 | 立会いの要否、鍵の預け方と返却 |
| 当日の変更 | 見積りと違う提案があった場合の扱い |

また、国民生活センターは、次の点も勧めています。

- 複数社から見積りを取る
- 見積りと異なる提案を受けたら、作業前にきっぱり断る。その場での支払いも拒否する
- トラブルが発生したら、消費生活センターに相談する

「トラック積み放題」のプランでは、荷台の囲いの高さまでしか積めないと当日言われた、という相談例も紹介されています。何が含まれるか、積み方の条件まで確認しましょう。

## まとめ　迷ったときの決め方

- 量が少なく、1階で、雪がなく、近くに住んでいる、期限に余裕がある。この条件がそろうなら、**自分で出す**を検討します。
- 量が多い、階段がある、雪の時期、遠方、期限がある。**いくつか当てはまるなら、業者**を検討します。
- 両方を組み合わせる方法もあります。市で出せるものは市に出し、運べないものや家電だけを業者に頼む、という分け方です。
- 業者に頼む場合は、一般廃棄物の収集運搬の許可を、市の一覧と電話で確認します。
