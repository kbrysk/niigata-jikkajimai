# 新潟の実家の片付けは自分で？業者？｜5つの判断基準と不用品回収の許可確認

## 結論：量・階段・雪・遠方・期限の5つで決める

実家の片付けを自分で出すか、業者に頼むかは、5つの基準で決めます。量が少なく、1階で、雪がなく、近くに住み、期限に余裕があれば、自分で出せます。いくつか当てはまらなければ、業者を検討します。

どちらでも、**家庭から出るごみを運べるのは、市の許可を持つ業者か、市の委託を受けた業者だけ**です。「不用品回収」「遺品整理」という名前の業者でも、許可があるとは限りません。

## この記事で分かること

- 自分で出すか、業者に頼むかを決める5つの基準
- 新潟で「不用品回収」を頼む前に知っておく、依頼先の種類と許可
- 無許可業者のリスクと、一般廃棄物収集運搬の許可の確認方法
- 見積りで確認すべき項目

特定の業者は紹介しません。

## 新潟で不用品回収を頼むとき、依頼先は何が違う？

「不用品回収 新潟」で探すと、多くの業者が並びます。ただし、家庭ごみを回収できるかどうかは、名前では分かりません。許可の種類で決まります。

| 依頼先 | 家庭の廃棄物の回収 | 向く場面 |
|---|---|---|
| 市の粗大ごみ収集・持ち込み | できる | 量が少ない。自分で運べる |
| 市の許可業者（一般廃棄物の収集運搬） | できる | 量が多い。運べない。市で出せない物がある |
| 遺品整理業者 | 許可を持つとは限らない | 仕分けから任せたい |
| 不用品回収業者 | 市の許可がなければ、できない | 許可の確認が済んだ場合のみ |
| 買取・リユース店（古物商） | 買取はできるが、ごみの回収はできない | 売れる家具・着物・家電など |

環境省は、産業廃棄物の許可や古物商の許可では、家庭の廃棄物は回収できないと案内しています。口コミやランキングの順位では、許可の有無は分かりません。市の公式一覧で確認します。

市の公式一覧にある許可業者の数は、次のとおりです。

- **新潟市**：36社（2024年3月7日現在）。[新潟市の許可業者一覧](../niigata-shi-kyoka-gyosha/)に整理しています。
- **長岡市**：14社。[長岡市の許可業者一覧](../nagaoka-shi-kyoka-gyosha/)に整理しています。
- **上越市**：18社。[上越市・三条市の粗大ごみの出し方](../joetsu-sanjo-sodaigomi/)で触れています。

売れそうな物は、先に買取を確認すると、処分する量が減ります。長岡市の店は、[長岡市のリサイクルショップ・出張買取](../nagaoka-recycle-shop/)にまとめています。

## 判断の5つの基準

先に、全体の表です。

| 基準 | 自分で出しやすい | 業者に頼むほうがよい |
|------|------|------|
| 1. 量 | 少ない。市の収集に収まる | 多い。何回も運ぶ必要がある |
| 2. 階段・搬出経路 | 1階中心。車が近くに停められる | 2階以上、急な階段、道が狭い |
| 3. 積雪期 | 雪のない時期 | 雪の時期（足元・搬出路が悪い） |
| 4. 遠方 | 近い。何度も通える | 遠い。帰省の回数が限られる |
| 5. 期限 | 余裕がある | 退去・売却・冬までに終えたい |

ひとつだけで決めず、全体で考えてください。

## 基準1　量はどれくらいまでなら自分で出せる？

市の制度には、量の制限があります。

- 長岡市の粗大ごみの戸別収集は、**1回に収集できるのは5点まで**です。
- 新潟市の自己搬入では、**透明か半透明の90リットル以下の袋**に入れて持参します。
- 家電4品目（エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機）は、市では処理できません。別の方法が必要です。

何点・何袋あるかを数えて、市のルールの範囲に収まるかを見ます。「何度も繰り返すことになりそう」なら、その時点で業者を検討する目安です。

量が多いかどうかは、感覚だけで判断しないでください。部屋ごとに、収納の中も含めて数えます。実家は、押し入れ、物置、納屋、車庫にも物が入っていることがあります。

### 自分で出す前に、市で出せない物を確認する

実家の納屋や車庫には、市の収集では出せない物があります。

- **新潟市**：劇薬、農薬、プロパンガスボンベ、バッテリー、消火器、ガソリン、灯油、塗料、バイク、タイヤなど。問い合わせは廃棄物対策課（025-226-1407）です。
- **長岡市**：消火器、バイク、農薬・廃油、建築廃材、タイヤ、金属類、大型プラスチック製品など。問い合わせは環境事業課（0258-24-2837）です。

消火器は、新潟市ではリサイクル窓口（03-5829-6773）が案内先です。長岡市では、消防署は引き取りを行っていません。長岡市は、こうした物を「市のごみ収集運搬業許可業者に依頼するか、品目ごとの窓口に持ち込む」と案内しています。

遺品整理を自分で進める場合も、同じ表のルールに従います。出せない物が混ざると、搬出の日程が崩れます。仕分けの段階で、先に分けておきます。

## 基準2　階段と搬出経路は、なぜ見る？

市の収集は、**家の前まで出す**のが基本です。長岡市は、一戸建てなら玄関先（高床式なら階段下）の、道路から見える所に出すよう案内しています。集合住宅は1階の入り口付近です。

つまり、家の中から外へ運ぶ作業は、自分でやる必要があります。

- 2階から重いタンスやベッドを降ろせるか
- 階段や廊下の幅は足りるか
- 玄関から道路までの距離はどれくらいか

新潟市も、重いものや量が多い場合は、複数人での搬入を勧めています。人手が足りないなら、業者の搬出を検討しましょう。無理に運んで、けがや家の傷みにつながるのは避けたいところです。

## 基準3　積雪期は、なぜ判断が変わる？

雪の時期は、片付けの条件が悪くなります。

- 玄関先や道路が滑りやすく、運ぶだけで危険が増す
- 収集日の朝に、雪の中で出す必要がある（新潟市は朝8時までに指定の場所へ出す）
- 業者の日程や料金の条件が、雪で変わる場合がある（見積りで確認）

新潟県は、除雪作業事故の防止を呼びかけています。雪下ろしだけでなく、雪の中での作業全般に注意してください。冬の実家じまいと雪対策は、[空き家の雪下ろしは誰の責任？新潟の実家の冬対策｜支援制度と費用](../fuyu-no-jikkajimai-yukioroshi/)で説明しています。

可能なら、雪が降る前に搬出まで終える計画にします。

## 基準4　遠方だと、どう変わる？

遠方では、「何度も通えない」ことが最大の条件です。

市の粗大ごみ収集は、申し込みから収集まで、新潟市で3日〜1週間以降、長岡市で数日後から2週間程度かかります。収集日には、処理券を貼って出す必要があります。長岡市の収集日は月〜金曜（祝日・年末年始を除く）です。長岡市の持ち込みは、月〜土曜の午前8時30分〜午後4時30分で、前日までの電話が必要です。

交通費と宿泊費、仕事を休む日数を足すと、「自分でやる」が結果的に高くつくことがあります。費用の目安は、[新潟で実家を片付ける費用の目安｜自分で出す場合と業者に頼む場合](../jikkajimai-hiyou-niigata/)にまとめています。

帰省を減らす段取りは、[遠方・県外から新潟の実家を片付ける段取り](../enpou-kara-jikkajimai/)が参考になります。

## 基準5　期限があるなら？

期限がある場合は、業者の日程に合わせるほうが確実です。

- 退去・売却・解体の日が決まっている
- 雪が降る前に終えたい
- 相続の手続きなど、ほかの期限と重なっている（相続登記の申請は、取得を知った日から3年以内。相続放棄は、相続の開始を知ったときから3か月以内。専門家に相談してください）

新潟市は、自己搬入が年末年始・お盆・引っ越しシーズン・連休の翌日・土曜日に混雑すると案内しています。ぎりぎりの日程は避けてください。

業者に頼む費用の一部に、補助がある市もあります。上越市の空き家活用補助金は、家財の搬出・処分費の2分の1で、上限10万円です。空き家の売却や県外からの移住に関わる場合が対象で、業者との契約前に申請が必要です。長岡市の公式ページでは、所有者向けの家財処分補助は確認できませんでした。詳しくは[上越市・新潟市の空き家バンク](../joetsu-niigata-akiya-bank/)にあります。

## 無許可の業者には、なぜ注意が必要？

業者に頼むときに、いちばん大事な点です。

環境省は、家庭の廃棄物を、市区町村の許可や委託を受けずに収集する無許可の回収業者を利用しないよう呼びかけています。無許可業者の営業の例として、次が挙げられています。

- 町中を大音量で巡回する
- 空き地で回収する
- チラシを配る
- インターネットで広告する

廃棄物を渡すと、不法投棄や不適正な処理、不適正な管理による火災などにつながるおそれがあります。環境省は、また、高額な料金を請求される事例にも触れています。

長岡市も、「許可なく廃棄物を収集運搬する行為は法律違反」と案内しています。「無料」と告知されながら料金を請求されるトラブルがあることも、市の注意情報にあります。

国民生活センターによると、不用品回収サービスの相談は増えています。2018年度は1,354件、2021年度は2,231件です。「安価な定額パックのはずが、作業後に高額な料金を請求された」という相談が例に挙がっています。

## 一般廃棄物収集運搬の許可は、どう確認する？

家庭から出るごみを回収できるのは、**市区町村の「一般廃棄物処理業（収集運搬）の許可」を持つ業者**です。環境省と長岡市は、産業廃棄物処理業の許可や古物商の許可では、家庭の廃棄物は回収できないと明記しています。

確認の手順は、次のとおりです。

1. **市のホームページの一覧で確認する。** 長岡市は「長岡市ごみ収集運搬業許可業者」のページを設けています。新潟市は「一般家庭から排出されるごみを自ら運搬することができないときは」のページに、許可業者の一覧PDFがあります。業者名が載っているかを見ます。
2. **許可の対象地域を確認する。** 長岡市の一覧には、「川口地域に限り収集できる業者」と「川口地域を除く市内全域を収集できる業者」の区別があります。実家のある地域に対応しているかを確認します。
3. **許可の種類を、業者に尋ねる。** 「一般廃棄物の収集運搬の許可はありますか」と聞き、市の許可であることを確認します。
4. **ごみの運搬を誰が行うかを尋ねる。** 遺品整理の会社が自社で運搬するのか、別の会社に任せるのかを尋ねます。運搬を行う会社が許可業者か、確認してください。
5. **分からないときは、市の担当課に問い合わせる。** 長岡市は環境事業課（0258-24-2837）、新潟市は廃棄物対策課（025-226-1407）です。

一覧に載っていない場合は、依頼する前に、市の担当課へ確認してください。ホームページに「許可あり」と書いてあるだけでは、確認になりません。

なお、市の許可業者の一覧が最新とは限りません。長岡市のページは2025年4月1日の更新ですが、令和4年4月現在という注記もあります。電話で、現在も許可が有効か確認するのが安全です。新潟市の一覧は、2024年3月7日現在です。

## 見積りで確認すべき項目は？

国民生活センターは、遺品整理サービスの相談事例を公表しています。見積りの2倍の請求、処分しないよう頼んだ物の処分、高額なキャンセル料などです。次の項目を、見積りの段階で確認し、書面で受け取ってください。

| 確認項目 | 見るポイント |
|------|------|
| 見積書の形式 | 作業内容と費用が明確に出ているか |
| 追加料金 | どんな場合に増えるか（階段、駐車場、量の増加、特殊な品目） |
| キャンセル料 | いつから、いくらかかるか |
| 作業範囲 | 仕分け、搬出、清掃、買取のどこまでか |
| 残す物の扱い | 残す遺品と処分する遺品を、どう区別するか |
| 許可 | 一般廃棄物の収集運搬の許可の有無、運搬する会社 |
| 家電4品目 | リサイクル料金と運搬料金を、どう扱うか |
| 立会い・鍵 | 立会いの要否、鍵の預け方と返却 |
| 当日の変更 | 見積りと違う提案があった場合の扱い |

また、国民生活センターは、次の点も勧めています。

- 複数社から見積りを取る
- 見積りと異なる提案を受けたら、作業前にきっぱり断る。その場での支払いも拒否する
- トラブルが発生したら、消費生活センターに相談する

「トラック積み放題」のプランでは、荷台の囲いの高さまでしか積めないと当日言われた、という相談例も紹介されています。何が含まれるか、積み方の条件まで確認しましょう。

## まとめ　迷ったときの決め方

- 量が少なく、1階で、雪がなく、近くに住んでいる、期限に余裕がある。この条件がそろうなら、**自分で出す**を検討します。
- 量が多い、階段がある、雪の時期、遠方、期限がある。**いくつか当てはまるなら、業者**を検討します。
- 両方を組み合わせる方法もあります。市で出せるものは市に出し、運べないものや家電だけを業者に頼む、という分け方です。
- 業者に頼む場合は、一般廃棄物の収集運搬の許可を、市の一覧と電話で確認します。

## よくある質問

### 実家の片付けは、自分でできますか？

量が少なく、1階中心で、雪のない時期なら可能です。市の粗大ごみ収集と持ち込みを使います。量が多い、階段が急、遠方などの場合は、業者を検討します。

### 遺品整理は、自分でやるのと業者に頼むのと、どちらがよいですか？

どちらが正解ということはありません。量、搬出経路、積雪期、遠方、期限の5つで考えます。市で出せるものは市に出し、運べないものだけ業者に頼む方法もあります。

### 不用品回収業者は、新潟市や長岡市の許可がなくても家庭ごみを回収できますか？

できません。家庭の廃棄物は、市区町村の許可を持つ業者か、市の委託を受けた業者が回収します。環境省は、産業廃棄物の許可や古物商の許可では回収できないと案内しています。

### 新潟で、許可を持つ業者はどこで確認できますか？

市の公式ページの一覧で確認します。長岡市は「長岡市ごみ収集運搬業許可業者」のページです。新潟市は、ごみを自ら運搬できないときの案内ページに一覧があります。一覧にない場合は、市の担当課に確認します。

### 「無料回収」をうたう業者は、安全ですか？

長岡市は、無料と告知されながら、あとで料金を請求されるトラブルがあると注意しています。無料かどうかより、許可の有無と見積りの内容を確認します。

### 見積りは、何社から取ればよいですか？

国民生活センターは、複数社から見積りを取ることを勧めています。見積書は、作業内容と費用が分かる書面で受け取ります。

### 家電4品目は、業者に頼めますか？

エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機は、リサイクル料金と運搬料金が必要です。見積りの段階で、どう扱うかを確認します。
