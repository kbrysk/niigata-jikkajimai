# 燕・弥彦環境センター（燕市吉田吉栄）への持ち込み｜受付時間・料金・持ち込めない物

## 結論：粗大ごみは予約不要。平日13:00〜17:00と土曜9:00〜12:00です

燕市と弥彦村のごみ処理施設は、燕・弥彦総合事務組合が運営しています。ごみの焼却場は「環境センター」で、燕市吉田吉栄777番地にあります。電話は0256-93-4704です。

- **粗大ごみ**：平日（月〜金）の13:00〜17:00と、土曜の9:00〜12:00に持ち込めます。予約は要りません。日曜・祝日・年末年始は休みです。
- **料金（粗大ごみ）**：粗大ごみシールを貼ります。300円・500円・1,000円の3種類で、品物ごとに決まっています。シールは環境センターの窓口でも買えます。現金のみで、カードやスマホ決済は使えません。
- **点数**：環境センターでシールを買うときは、原則1回5点までです。
- **持ち物**：燕市・弥彦村に住んでいることが分かる免許証などです。
- **可燃ごみ**：日曜・祝日も受け入れています。指定袋に入っていない家庭ごみは、10kgごとに60円です。
- **燃やさないごみ**：環境センターではなく、クリーンセンター舘野が受け入れます。
- **持ち込めない物**：燕市・弥彦村以外のごみ、事業所の粗大ごみ、分別されていない混載物、家電リサイクル対象品目です。

この記事は、組合と燕市・弥彦村の公式情報だけでまとめました。内容は2026年10月17日の確認時点です。持ち込む前に、公式ページで最新の情報を見てください。

この記事で分かること

- 環境センターの受付日時（ごみの種類ごと・曜日ごと）
- 粗大ごみの持ち込み条件、搬入の手順、シールの買える場所
- 可燃ごみ・せん定枝の持ち込みと、燃やさないごみの持ち込み先
- 持ち込めない物
- 年末年始の日程（昨年の例）
- 実家の片付けで持ち込むときの手順

## ごみの種類ごとの受付日時

組合の「環境センターの搬入日程表」には、受付時間が8:30〜17:00とあります。粗大ごみだけは、時間が短くなります。更新日は、ページに記載がありません。

| 区分 | 月〜金 | 土曜 | 日曜・祝日 |
|------|------|------|------|
| 可燃ごみ | 受け入れ | 受け入れ（午前・午後） | 受け入れ |
| 粗大ごみ（シール販売を含む） | 13:00〜17:00 | 9:00〜12:00 | 休み |
| 資源ごみ（新聞・雑誌・段ボールを除く） | 受け入れ | 受け入れ | 休み |
| せん定枝 | 受け入れ | 受け入れ | 休み |

日程表の注意書きには、「土曜午後、日曜、祝日は可燃ごみのみ」とあります。土曜の粗大ごみ・資源ごみ・せん定枝は、午前だけです。

新聞・雑誌・段ボールは、可燃ごみのサイズに切れば、可燃ごみとして出せます。

分別されていないごみは、受け入れできません。

## 粗大ごみの持ち込み

### 条件

2023年10月2日から、環境センターで粗大ごみの持ち込みを受け付けています（組合のお知らせ、2023年8月25日掲載）。個別収集の予約が取りにくい、すぐに処分したい、という理由で直接持ち込む人が増えたためと説明されています。

| 項目 | 内容 |
|------|------|
| 受付 | 月〜金 13:00〜17:00、土 9:00〜12:00（祝日・年末年始を除く） |
| 予約 | 不要 |
| 点数 | 原則として1回の持ち込みにつき5点まで |
| 料金 | 粗大ごみシール（300円・500円・1,000円）。搬入する粗大ごみの種類で金額が変わる |
| 支払い | 現金のみ。カード・スマホ決済は使えない |
| 持ち込める人 | 燕市・弥彦村に住む家庭の排出者 |
| 持ち物 | 燕市・弥彦村に住んでいることが確認できる免許証など |
| 代理人 | 排出者本人が持ち込めないときは、代理人が持ち込める。事前に環境センターへ連絡する |

燕市役所の生活環境課で、先に粗大ごみシールを買って持ち込む場合は、何点でも持ち込めます。環境センターでシールを買って処分する場合が、5点までです（広報つばめ2025年12月1日号の年末年始の案内にある注意書き）。シールを買うときは、身分証の提示が必要です。

### 搬入の手順

組合のお知らせ（2023年8月25日掲載）に、図と写真で載っています。

1. 正門から入ります。入口は対面交通です。場内は徐行します。
2. 計量台に車を停めたまま、車から降りて、窓口で受付をします。シールを持っていないときは、窓口でシールを買い、その場で粗大ごみに貼ります。
3. 受付が終わったら、車に乗ったままプラットホームへ移動します。
4. プラットホーム内に入ります。係員の指示に従います。粗大ごみは、原則として、持ち込んだ人が降ろします。
5. 降ろしたら、出口から出て、右に曲がり、正門から出ます。

場内では、一時停止や目視での確認など、安全に気をつけます。プラットホームに入るときは、周りの安全を確かめます。

### 持ち込めない物

次の物は、受け入れできません。

- 燕市・弥彦村以外（他の市町村）のごみ
- 事業所の粗大ごみ
- 分別されていない混載物

搬入日程表には、土曜の9:00〜12:00は事業所の受け入れができない、とも書かれています。

### シールの料金と買える場所

シールは、300円・500円・1,000円の3種類です。品物ごとに、どのシールを貼るかが決まっています。決まりは、組合の「粗大ごみシールの取扱いに関する要綱」の別表（品目別単価表）にあります。

別表の例です。ふとんは1枚300円、たんす（高さ90cm未満）は500円、たんす（90cm以上）は1,000円、ベッド（マットレス除く）は1,000円、畳は1枚1,000円です。別表にない物は、組合の管理者が決めます。大人2人で車に積めない物は、対象になりません。

主な品目の料金は、[燕市の粗大ごみの出し方](../tsubame-shi-sodaigomi/)にまとめています。

シールを売っている場所は、次のとおりです。

| 場所 | 日時 |
|------|------|
| 環境センター | 平日 13:00〜17:00、土 9:00〜12:00（現金のみ） |
| 燕市役所 生活環境課（2階14番窓口） | 平日 8:30〜17:15（祝日・年末年始を除く） |
| 弥彦村役場 産業部 防災むらづくり課（電話0256-94-1022） | 月〜金（祝日と12月29日〜1月3日を除く） |

弥彦村のページには、販売時間が「午後8時30分〜午後5時」と書かれています。同じページの末尾の開庁時間は「午前8時30分〜午後5時15分」なので、「午前」の書き間違いと思われます。弥彦村役場で買うときは、念のため、防災むらづくり課（0256-94-1022）に時間を聞いてください。

## 可燃ごみ・せん定枝・資源ごみの持ち込み

### 可燃ごみ

環境センター（焼却場）が受け入れます。日曜・祝日も、可燃ごみは受け入れています。

| 区分 | 手数料（消費税込み） |
|------|------|
| 持ち込みの可燃ごみ（指定袋に入っていない家庭ごみ、事業所のごみ） | 10kgごとに60円 |
| せん定枝 | 10kgごとに100円 |

組合指定のごみ袋に入れた家庭ごみは、従来どおり手数料がかかりません（組合の「環境センターからお知らせ」、2014年4月1日の改定）。精算は現金です。

金額は、燕市の広報つばめ2025年12月1日号の年末年始の案内でも、可燃ごみ10kgごとに60円、せん定枝10kgごとに100円となっています。

### せん定枝

組合のお知らせ（2023年10月2日掲載）の内容です。

- 受入時間：月〜金 8:30〜17:00、土 9:00〜12:00
- 料金：10kgごとに100円
- 長さ：1.5m以下。太さの制限はありません。自分で降ろせる大きさに限ります。
- 持ち物：燕市・弥彦村に住んでいることを確認できる免許証など
- 花や実が付いた枝は、そのままでは持ち込めません。花・実を取り除いて、可燃ごみとして出します。
- 束ねるときは、わら縄を使います。ビニールひもで束ねると、現地で外されます。

燕市には、「燕市せん定枝リサイクル施設」もあります。燕市民に限られます（燕市吉田本町694-8、電話0256-93-6830。組合のガイドブック29ページ）。市のページ（2026年6月2日更新）が案内しています。

### 燃やさないごみ（クリーンセンター舘野）

燃やさないごみは、環境センターではなく、最終処分場の「クリーンセンター舘野」が受け入れます。

| 項目 | 内容 |
|------|------|
| 所在地 | 燕市舘野109番地1（組合の施設紹介は「舘野字西109番地1」） |
| 電話 | 0256-66-1310 |
| 受付 | 月〜土 8:30〜17:00。土曜午後、日曜、祝日は休み |
| 支払い | 不燃ごみ指定袋、または現金 |

搬入日程表で、舘野の受け入れ区分として載っているのは、不燃ごみだけです。粗大ごみは、環境センターへ持ち込みます。

### 資源ごみ

新聞・雑誌・段ボールを除く資源ごみは、環境センターが月〜土に受け入れます。新聞・雑誌・段ボールは、有限会社鍋藤（燕市吉田法花堂2237-1、電話0256-93-3996）が受け入れます（燕市のページ、組合のガイドブック29ページ）。

## 持ち込めない物・市外の施設への持ち込み

燕市のページ（2026年6月2日更新）には、「燕市の家庭ごみは、基本的に市外のごみ処理場へ持ち込めない」と案内があります。

環境センターで受け入れできない物は、次のとおりです。

- 家電リサイクル対象品目：環境センターでは受け入れできません。組合のお知らせは、事業所から出た物も受け入れ不可としています。この掲載は2009年のものです。
- スプレー缶・ガスボンベ・使い捨てライター：使い切ってから出します。残ったガスが、ごみ処理場や収集車の火災の原因になっています。
- 事業所のごみ：家庭用の指定袋やごみステーションには出せません。事業者が自分の責任で処理します。

### ガイドブックで「処理できません」の物

組合のガイドブック（「ごみ・リサイクル・ガイドブック」、2021年3月発行）の品目別一覧表（30〜39ページ）には、「処理できません」の区分があります。販売店などに引き取りを頼むか、専門の処理業者に頼む、と注意書きがあります。農業に伴う資材は、農協などに頼むよう書かれています。

実家の片付けで出やすい物では、次の品目が「処理できません」です。

| 区分 | 品目 |
|------|------|
| 仏事・庭 | 仏壇、庭石、石灯籠、灰 |
| 建築・住宅設備 | 建築廃材、コンクリート・コンクリートブロック、れんが、柱、便器、浴槽、温水器（太陽熱温水器を含む）、ビニールハウス、井戸用ポンプ・モーター |
| 車・バイク | オートバイ（バイク）、エンジン、エンジンオイル、タイヤ、バッテリー |
| 自然物・油類 | 石・砂利・土・砂、灯油・ガソリン・オイル類 |
| 金庫・電池・その他 | 耐火金庫、ボタン電池・二次電池、ドラム缶、パレット、ビール・酒ケース、医療系廃棄物 |
| 農業用 | 農機具、農業用肥料袋、農業用マルチシート、農薬、苗箱 |

上の表は、品目別一覧表の「処理できません」のうち、主な物です。すべてではありません。ガイドブックは2021年3月発行の版なので、最新の区分は、燕市の「ごみの出し方検索」か、環境センターで確認します。

家電4品目の出し方は、[新潟の家電4品目の出し方](../kaden4hinmoku-niigata/)にまとめています。

## 休みと年末年始

日曜・祝日は、粗大ごみ・資源ごみ・せん定枝が休みです。可燃ごみは、日曜・祝日も受け入れます。

年末年始の日程は、毎年変わります。搬入日程表には、広報またはホームページで確認するよう書かれています。2026年末〜2027年始の日程は、まだ確認できていません。燕市の広報つばめ12月1日号で案内される見込みです。[要確認: 2026年末〜2027年始の受付日（広報つばめ12月1日号、または環境センター 0256-93-4704）]

参考に、昨年（2025年末〜2026年始）の案内です（広報つばめ2025年12月1日号、市のPDF）。

| 区分 | 受け入れた日 |
|------|------|
| 可燃ごみ（8:30〜17:00） | 12月23日〜31日（31日は12:00まで）、1月4日・5日 |
| 粗大ごみ（シール販売・持ち込み） | 12月23日〜26日、1月5日は13:00〜17:00。12月27日（土）は9:00〜12:00 |
| 資源ごみ（家庭ごみ） | 12月23日〜27日、1月5日（8:30〜17:00） |
| せん定枝 | 12月23日〜27日、1月5日（8:30〜17:00。12月27日は12:00まで） |
| 不燃ごみ（クリーンセンター舘野） | 12月23日〜27日、1月5日（8:30〜17:00。12月27日は12:00まで） |

この年のごみ収集は、1月1日〜4日が休みでした。曜日の並びが毎年違うため、今年も同じとは限りません。

組合の「環境センターからお知らせ」ページには、能登半島地震の影響で、ごみ焼却場2施設のうち1施設が停止している、という掲載が日付なしで残っています。2025年末の案内では、可燃ごみの持ち込みは通常どおり案内されています。

## 実家の片付けで持ち込むときの手順

条件は、排出者が燕市・弥彦村に住んでいることです。実家の片付けが当たるかどうかや、遠方に住む家族が実家の家財を持ち込む場合の扱いは、公式ページに記載がありません。[要確認: 実家の片付けでの持ち込み。排出者が市外・県外に住む場合の扱い（環境センター 0256-93-4704）]

次の順で進めます。

1. 出す物をリストにします。品目、大きさ、数量を書きます。
2. 家電4品目や仏壇など、受け入れできない物を外します。
3. 粗大ごみは、数えます。環境センターでシールを買うときは、原則1回5点までです。
4. 免許証などを用意します。代理人が行くときは、事前に環境センターへ連絡します。
5. 燃やさないごみがあるときは、クリーンセンター舘野を使います。
6. 粗大ごみは、平日13:00〜17:00か、土曜9:00〜12:00に運びます。窓口でシールを買って、その場で貼ります。

量が多いときや、運び出せないときは、燕市の許可業者に頼む方法があります。自分で運ぶか業者に頼むかの考え方は、[自分で出す？業者に頼む？](../jibun-de-dasu-ka-gyousha-ka/)が判断の材料になります。家財が多い家の考え方は、[新潟の実家がゴミ屋敷だったとき](../gomiyashiki-jikka-katazuke-niigata/)にあります。

個別収集の申込先や、品目別の料金は、[燕市の粗大ごみの出し方](../tsubame-shi-sodaigomi/)で説明しています。この記事では、重ねて書きません。

## 燕・弥彦環境センター、よくある質問

**Q　燕・弥彦の環境センターは、粗大ごみの持ち込みに予約が要りますか。**
予約は不要です。受付は、平日13:00〜17:00と土曜9:00〜12:00です。代理人が持ち込むときだけ、事前に環境センターへ連絡します。

**Q　環境センターの粗大ごみは、いくらですか。**
粗大ごみシールで払います。300円・500円・1,000円の3種類で、品物ごとに決まっています。支払いは現金のみです。

**Q　環境センターに、日曜日や祝日は持ち込めますか。**
粗大ごみ・資源ごみ・せん定枝は、休みです。可燃ごみは、日曜・祝日も受け入れています。

**Q　環境センターへ持ち込むとき、何が要りますか。**
燕市・弥彦村に住んでいることが分かる免許証などです。シールは、窓口で買えます（現金のみ）。

**Q　燕市のごみを、ほかの市の施設に持ち込めますか。**
燕市のページに、燕市の家庭ごみは、基本的に市外のごみ処理場へ持ち込めない、と書かれています。

**Q　環境センターで持ち込めない物は何ですか。**
他の市町村のごみ、事業所の粗大ごみ、分別されていない混載物、家電リサイクル対象品目です。燃やさないごみは、クリーンセンター舘野へ持ち込みます。
