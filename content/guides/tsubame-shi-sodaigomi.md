# 燕市の粗大ごみの出し方｜申込・料金・持ち込み・市で出せない物

燕市の粗大ごみは、地区の収集業者へ電話で申し込みます。品目ごとに、300円・500円・1,000円のシールを貼って出します。自分で運ぶなら、環境センターへ予約なしで持ち込めます。原則1回5点までです。

## この記事で分かること

- 燕市の粗大ごみの申し込み先と、粗大ごみシールの使い方
- 実家じまいで出やすい品目の料金（公式の品目別単価表より）
- 環境センターへ自分で持ち込む方法と、市で出せない物

実家を片付けると、たんすや布団、ベッドなどが一度に出ます。公式情報だけでまとめました。内容は2026年10月2日の確認時点です。申し込む前に、公式ページで最新の情報を見てください。

## 料金の仕組みと品目別料金

粗大ごみシールは、300円（小）・500円（中）・1,000円（大）の3種です。消費税込みです。品目ごとの単価に合わせて、シールを貼ります。

市のページに載っているシールの販売場所は、次の2か所です。

- 燕市役所 生活環境課（平日 8:30〜17:15）
- 環境センター（平日 13:00〜17:00、土 9:00〜12:00。現金のみ）

品目別の単価は、燕・弥彦総合事務組合の要綱の別表にあります。159品目です。次の表は、その中から家財に多い物を選びました。

|------|------|
| ふとん（1枚） | 300円 |
| カーペット（6畳未満／6畳以上） | 300円／500円 |
| 畳（1枚） | 1,000円 |
| たんす（高さ90cm未満／90cm以上） | 500円／1,000円 |
| 各種棚類 | 1,000円 |
| 机（備付け本棚除く） | 1,000円 |
| テーブル（1辺1m未満／1m以上） | 500円／1,000円 |
| いす（1脚） | 300円 |
| 応接用いす（1人用／2人用以上） | 500円／1,000円 |
| ベッド（マットレス除く） | 1,000円 |
| マットレス（スプリングなし／スプリング入り） | 500円／1,000円 |

別表にない物は、形状・大きさ・重さを見て、その都度、組合の管理者が決めます。大人2人で無理なく車に積めない物は、対象外です。

## 収集日と出し方

燕市には、粗大ごみの定期の収集曜日がありません。収集業者に電話して、日程を決めます。

出し方は、シールを貼って家の前に出す形です。出す時間や場所の細かい決まりは、公式ページに記載がありません。[要確認: 出す時間・場所の指定]

2023年の組合の発表では、「個別収集の予約が取れない」ケースが増えたため、持ち込みの受け入れを広げたとあります。

## 自分で持ち込む場合

2023年10月2日から、環境センターで粗大ごみの持ち込みを受け付けています。シールも、その場で買えます。

| 項目 | 内容 |
|------|------|
| 施設 | 燕・弥彦総合事務組合 環境センター（ごみ処理場） |
| 住所 | 燕市吉田吉栄777 |
| 電話 | 0256-93-4704 |
| 受付 | 月〜金 13:00〜17:00、土 9:00〜12:00（祝日・年末年始を除く） |
| 料金 | 粗大ごみシール（300円・500円・1,000円）。現金のみ。カード・スマホ決済は不可 |
| 点数 | 原則1回の持ち込みにつき5点まで |
| 事前連絡 | 予約は不要です |
| 持ち物 | 燕市・弥彦村在住を確認できる免許証など |

次の点に気をつけます。

- 燕市・弥彦村以外のごみは、持ち込めません。
- 事業所の粗大ごみは、受け入れできません。
- 分別されていない混載物は、受け入れできません。
- 代理の人も持ち込めます。事前に環境センターへ連絡します。

燃やすごみは、環境センター（焼却場）で受け付けます。組合の搬入日程表では、受付は8:30〜17:00で、土曜の午後、日曜、祝日も可燃ごみは受け入れです。燃やさないごみは、クリーンセンター舘野（燕市舘野109-1、0256-66-1310）が、月〜土曜の午前に受け付けます。支払いは、不燃ごみ指定袋か現金です。分別していないごみは、受け入れできません。なお、クリーンセンター舘野は不燃ごみの処分場で、粗大ごみは受け入れていません。市のページには、燕市の家庭のごみは、基本的に市外の処理場へ持ち込めない、とあります。

## 市で出せない物

組合のガイドブックでは、次の物は、ごみステーションにも出せないとされています。販売店や専門業者に頼みます。

| 区分 | 品目 |
|------|------|
| 家電4品目 | テレビ、エアコン、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機 |
| 容積や重量が大きい物 | ピアノ、自動車、バイク（原付を含む）、船舶、耐火金庫、温水器、石灯籠、庭石、石塀、墓石、物置、プレハブ |
| 危険な物 | 火薬、各種ボンベ、消火器、バッテリー、エンジンオイル |
| 処理が困難な物 | 廃タイヤ、ホイール、自動車部品、便器 |
| 農業・事業用 | 農業用機械、農業用ビニール、事業系ごみ |

このガイドブックは発行年の記載がありません。市のページに載っているガイドブックは、2021年3月発行の1版だけです。

### 家電4品目の出し方

方法は2つです。

1. 購入した店、または買い替える店に引き取りを頼みます。
2. 買い替えがない、購入店が分からないときは、許可業者に引き取りを頼みます。

リサイクル料金は、家電リサイクル券センター（0120-319640）で確認できます。市の「家電リサイクル法について」（2024年4月1日更新）は、指定引取場所を載せていません。引き取りは、販売店か、市の収集運搬許可業者へ頼む案内です。許可業者は、ツバメロジス（燕市大関353、0256-63-4663）と吉田環境衛生公社（燕市吉田本町694-1、0256-93-2693）です。事前に連絡して料金を確認します。

## 分別で迷いやすい品目のQ&A

料金は、組合の要綱の別表（品目別単価表）によります。

**Q1　布団はいくらですか。**
1枚300円です。

**Q2　カーペットや畳は。**
カーペットは、6畳未満が300円、6畳以上が500円です。畳は1枚1,000円です。

**Q3　ベッドやマットレスは出せますか。**
出せます。ベッド（マットレス除く）は1,000円です。マットレスは、スプリングなしが500円、スプリング入りが1,000円です。

**Q4　ソファーは。**
別表に「ソファー」の品目はありません。組合のガイドブックには、粗大ごみの例としてソファーが載っています。料金の区分は、公式に記載がありません。「応接用いす」は、1人用500円、2人用以上1,000円です。[要確認: ソファーの料金区分]

**Q5　食器棚、仏壇、神棚は。**
別表に、仏壇と神棚の品目はありません。組合のガイドブックの分別一覧では、仏壇と神棚は「処理できません」です。食器棚は、ガイドブックの粗大ごみの例に載っていますが、別表に名前での記載はありません。「各種棚類」は1,000円です。[要確認: 食器棚の料金区分]。別表にない物は、管理者が決めます。申込先の業者に確認します。

**Q6　ストーブや電子レンジは。**
別表では、ストーブが300円、ファンヒーターと電子レンジが500円です。一方、ガイドブックには、指定袋に入る物は不燃ごみに出す案内もあります。どちらになるかは、市の「ごみの出し方検索」で確認します。[要確認: ストーブ・電子レンジの区分]

**Q7　5点より多いときは。**
環境センターへの持ち込みは、原則1回5点までです。個別収集の上限は、公式に記載がありません。[要確認: 個別収集の点数]

## 実家をまるごと片付けるときの考え方

出し方は、業者へ電話して収集してもらう方法と、環境センターへ持ち込む方法の2つです。持ち込みは、平日の13時以降か土曜の午前に、現地へ行く必要があります。

家電4品目、ピアノ、耐火金庫、物置などは、組合では処理できません。これらがまとまってある場合は、市の制度だけでは足りないことがあります。

次のようなときは、市の許可業者に見積りを取る方法があります。量が多い、市で扱わない物が多い、遠方で何度も通えない、冬で搬出が難しい。見積りの取り方は、[自分で出す？業者に頼む？](../jibun-de-dasu-ka-gyousha-ka/)を見てください。
