# ソファ・ベッド・タンスの捨て方（新潟市・長岡市）｜大型家具の料金、分解の可否、搬出が難しいとき

## 結論：大型家具は粗大ごみです。長岡市はスプリング入りを収集しません

ソファとベッドは、新潟市がどちらも500円です。タンスは、大きさで300円か500円です。長岡市は、ソファが200円か600円、ベッドが600円か1,000円、タンスが600円か1,000円です。長岡市は、スプリング入りのソファとベッドを収集しません。

この記事は、新潟市と長岡市の公式情報だけでまとめました。内容は2026年10月3日の確認時点です。

### この記事で分かること

- ソファ、ベッド、タンスの料金と、大きさの測り方
- 分解してよいか、2人で運べないときはどうするか
- 申込、持ち込み、よくある間違い

## 新潟市・長岡市の早見表

| 項目 | 新潟市 | 長岡市 |
|------|------|------|
| ソファー | 500円 | スプリングなし：1人掛け200円、2人掛け以上600円 |
| ベッド | 500円（シングル〜キング同額。2段ベッドは2台分） | スプリングなし：シングル600円、セミダブル以上1,000円 |
| タンス | 幅・奥行・高さの合計2.5m未満300円、2.5m以上500円 | 長辺と高さで2区分。600円か1,000円（プラ製・籐製で1人で持てる物は200円） |
| スプリング入り | スプリング式マットレスは500円で収集。ソファーは料金表にスプリングの区分なし | 収集不可（許可業者へ） |
| 申込 | 粗大ごみ受付センター。ネット・チャットボット・LINE・電話 | ネット・FAX・電話（事前申込制） |

料金は、新潟市が2025年6月4日更新の料金一覧、長岡市が令和7年2月1日現在の品目一覧によります。

## 新潟市の大型家具の出し方

新潟市は、申込制の戸別収集です。収集日は、申込後3日から1週間以降が通常です。申込が多いと、さらに延びます。

### 料金の一覧

| 品目 | 料金 |
|------|------|
| ソファー | 500円 |
| ソファーベッド | 500円 |
| ベッド | 500円 |
| 電動機能付きベッド | 500円 |
| たんす（幅・奥行・高さの合計2.5m未満） | 300円 |
| たんす（同2.5m以上） | 500円 |
| 食器棚・本棚（合計2m未満） | 200円 |
| 食器棚・本棚（合計2m以上2.5m未満） | 300円 |
| 食器棚・本棚（合計2.5m以上） | 500円 |

マットレスは、ベッドと別に申し込みます。2段ベッドは、2台分の手数料です。

大きさの区分は、幅・奥行・高さの3辺の合計です。申込の前に、3辺を測っておきます。

### 申込から排出まで

1. ネット、チャットボット、LINE、電話のどれかで申し込みます。電話は025-290-5353です。
2. 申込時にわかった金額の処理券を、小売店や区役所などで買います。
3. 処理券に氏名か受付番号を書き、品物ごとに貼ります。
4. 収集日の午前8時までに、申込時に指定した場所へ出します。

粗大ごみの対象は、大人2人で持ち上げられるものです。作業員は、住宅の中に入りません。家の中から指定の場所まで、自分で運び出します。

チャットボットは、画像を送って品目を調べられます。一部の品目は、ネットで申し込めません。

## 長岡市の大型家具の出し方

長岡市は、事前申込制の戸別収集です。収集は月〜金で、受付の数日後です。時間は8時30分から夕方までで、指定できません。混雑時は、受付後2週間程度かかります。

### 料金の一覧

| 品目 | 料金 |
|------|------|
| ソファー（スプリングなし・1人掛け） | 200円 |
| ソファー（スプリングなし・2人掛け以上） | 600円 |
| ベッド（スプリングなし・シングル） | 600円 |
| ベッド（スプリングなし・セミダブル以上） | 1,000円 |
| ソファーベッド（スプリングなし） | 600円 |
| リクライニングベッド（簡易なパイプベッド・シングル） | 600円 |
| 二段ベッド | 1,000円 |
| たんす（長辺90cm以下かつ長辺と高さの合計180cm以下・1人で持てない） | 600円 |
| たんす（長辺2m以下・長辺と高さの合計180cm超） | 1,000円 |
| タンス（プラ製・籐製・1人でも持てる） | 200円 |
| 食器棚（上のたんすと同じ2区分） | 600円か1,000円 |
| 本棚（同じ2区分） | 200円か600円 |
| 鏡台（ドレッサー） | 600円 |

料金は、200円の処理券シールを1枚・3枚・5枚貼って支払います。たんすなどは、申込時に縦・横・高さを伝えます。大きさで料金の区分が決まるためです。

### 長岡市で収集できない家具

次の物は、市では収集しません。

- スプリング入りのソファー、ベッド、マットレス、イス
- 介護用ベッド、介護用や大型モーター付きのリクライニングベッド
- 2人で持てない物

スプリング入りと介護用ベッドは、市の品目一覧で収集不可とされています。市のごみ収集運搬業許可業者に頼みます。

### 申込から排出まで

1. ネット（24時間）、FAX（0258-25-0064）、電話（0258-25-0053）で申し込みます。
2. 品目と大きさ、数量を伝え、金額と収集日の案内を受けます。
3. 処理券シールを買い、金額の分だけ貼ります。
4. 収集日の8時30分までに、玄関先の道路から見える所へ出します。集合住宅は、1階の入口付近です。

家屋の中には、入りません。処理券シールを貼って玄関先に出してあれば、留守でも収集します。

## 分解してよいか

分解した家具の扱いは、公式ページにほとんど書かれていません。確認できたことを、市ごとに整理します。

| 項目 | 新潟市 | 長岡市 |
|------|------|------|
| 分解した場合の扱い | [要確認: 分解した場合の扱い] | [要確認: 分解した場合の扱い] |
| 部材の寸法 | 記載なし | 板類は厚さ3cm・幅90cm・長さ2m以内。角材は太さ10cm・長さ2m以内 |
| 指定袋に入る大きさ | 硬い物などでなければ、燃やすごみ・燃やさないごみ | 記載なし |

新潟市の公式Q&Aは、次のように答えています。指定袋に入る大きさで、火災・破裂の原因、材質の硬いもの、広げると大きくなるものでなければ、粗大ごみではありません。

板や金属の部材が「材質の硬いもの」に当たるかは、記載がありません。[要確認: 分解した部材の区分]

長岡市の寸法は、板類と角材の出し方の案内です。分解した家具の部材にも使えるかは、記載がありません。[要確認: 分解した家具の部材の数え方と料金]

分解で料金が安くなるとは限りません。部材の数え方の記載がないためです。分解する前に、受付窓口へ聞くのが確実です。

## 搬出が難しいときの考え方

粗大ごみは、2人で持てる物が対象です。どちらの市も、作業員は家の中に入りません。階段が急な家、2階の部屋、積雪期は、搬出がむずかしくなります。

| 方法 | 内容 |
|------|------|
| 家族や近所の人と運ぶ | 2人で持てる物は、市の収集に出せる |
| 市の施設に持ち込む | 新潟市は10kgまでごとに100円。長岡市は前日までに電話 |
| 許可業者に頼む | 市の許可を持つ業者が、家の中から運び出す |

新潟市は、自分で運べないときの案内ページに、許可業者の一覧を載せています。長岡市は、市のごみ収集運搬業許可業者への依頼を案内しています。

雪の時期の排出場所の扱いは、公式に記載がありません。[要確認: 積雪時の排出場所]

## よくある間違い

- **長岡市で、スプリング入りのソファを申し込む。** 収集されません。許可業者に頼みます。
- **新潟市で、ベッドの申込にマットレスが入っていると思う。** マットレスは別に申し込みます。
- **たんすの大きさを測らずに申し込む。** 長岡市は、縦・横・高さが料金区分の判定に必要です。
- **家の中や部屋の前に置いておく。** 作業員は、家の中に入りません。
- **処理券を貼らずに出す。** 貼っていないと収集されません。
- **分解した部材を、そのまま出す。** 部材の扱いは、公式に記載がありません。先に窓口へ確認します。

## まとめて片付けるときの考え方

実家では、ソファ、ベッド、タンス、食器棚が同時に出ます。長岡市の1回5点という上限に、すぐ達します。

1. 家具を、品目・大きさ・スプリングの有無でリストにします。
2. 市で出せない物と、2人で運べない物を分けます。
3. 残りを、市の収集に回数を分けて申し込みます。
4. 運べない物と、市で出せない物は、許可業者の見積りを取ります。

見積りでは、運搬費、処分費、作業費が分かれているかを聞きます。階段、搬出経路、積雪期の追加条件も確認します。自分で出す場合との比較は、[自分で出す？業者に頼む？](../jibun-de-dasu-ka-gyousha-ka/)にあります。

売れる家具は、リユースも選べます。長岡市の売り方は、[長岡市のリサイクルショップ・出張買取](../nagaoka-recycle-shop/)で整理しています。

新潟市の資源再生センター（エコープラザ）は、2024年3月31日に閉館しました。まだ使える家具の展示提供事業も終了しています。古い案内に注意します。

## よくある質問

**Q　新潟市のソファは、いくらですか。**
500円です。ソファーベッドも500円です。

**Q　長岡市のソファは、いくらですか。**
スプリングなしで、1人掛けが200円、2人掛け以上が600円です。スプリング入りは収集しません。

**Q　新潟市のタンスは、どう測りますか。**
幅・奥行・高さの合計です。2.5m未満が300円、2.5m以上が500円です。

**Q　長岡市のタンスは、どう測りますか。**
長辺と高さを測ります。長辺90cm以下かつ長辺と高さの合計180cm以下が600円です。長辺2m以下で180cmを超えると1,000円です。

**Q　介護用ベッドは、市で出せますか。**
長岡市は、品目一覧で収集不可です。市の許可業者に頼みます。新潟市の料金一覧には、電動機能付きベッドが500円で載っています。介護用かどうかは、受付で確認します。

**Q　2人で持てない家具は、どうしますか。**
長岡市は、収集できません。新潟市の対象は、大人2人で持ち上げられる物です。許可業者への依頼を検討します。

**Q　粗大ごみの料金は、変わりますか。**
新潟日報は、2026年2月18日に長岡市の改定案を報じました。2027年7月に、400〜2,000円にする案です。市の公式ページには載っていません。[要確認: 市の公式発表と施行日]
