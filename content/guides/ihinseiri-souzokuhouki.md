# 相続放棄をするなら遺品整理に注意｜処分すると「単純承認」になる場合の一般論と、先に相談する窓口

## 結論：放棄の可能性があるなら、物の処分より先に専門家へ相談します

相続放棄を考えているなら、遺品整理の前に確認が必要です。民法921条は、相続人が相続財産の全部または一部を処分したとき、単純承認したものとみなすと定めています。承認は撤回できないため（民法919条1項）、単純承認になると、放棄は難しくなります。どの行為が処分にあたるかは、公式ページに一覧がありません。断定はできません。放棄の期限は、相続の開始を知った時から3か月です。新潟では、法テラス、弁護士会、司法書士会の窓口で相談できます。

この記事は一般論です。個別の事情は、弁護士や司法書士に確認してください。内容は2026年10月3日の確認時点です。

この記事で分かること

- 相続放棄の基本と、単純承認とみなされる場合（民法921条）の一般論
- 遺品整理の前にやってよいこと、相談まで待つこと
- 新潟の法テラス・弁護士会・司法書士会の相談窓口

## 早見表：相続放棄の基本

| 項目 | 内容 |
|------|------|
| 相続人の選択肢 | 単純承認、相続放棄、限定承認の3つ |
| 期限 | 自己のために相続の開始があったことを知った時から3か月以内 |
| 申述先 | 亡くなった人の最後の住所地の家庭裁判所 |
| 費用 | 収入印紙800円（申述人1人）と、連絡用の郵便切手 |
| 判断できないとき | 期間を延ばす申立てができます |
| 単純承認とみなされる場合 | 相続財産の処分、期間内に放棄しなかったときなど（民法921条） |

## 相続放棄とは

### 3つの選択肢

裁判所の案内によると、相続人は次の3つのうち、どれかを選べます。

- 単純承認：土地などの権利も、借金などの義務も、すべて引き継ぎます。
- 相続放棄：権利も義務も、一切引き継ぎません。
- 限定承認：得た財産の範囲で、借金などを引き継ぎます。

放棄と限定承認は、家庭裁判所に申述して行います。何もしなかった場合も、単純承認とみなされます（民法921条2号）。

### 期限は3か月です

期限は、自己のために相続の開始があったことを知った時から3か月以内です（民法915条）。

財産の状況が分からず、期間内に判断できない場合は、期間を延ばす申立てができます。財産を調べても、承認か放棄かを決められない場合が対象です。申立ても、3か月以内に行います。費用は、収入印紙800円（相続人1人）と郵便切手です。

裁判所のQ&Aには、相続財産が全くないと信じる相当な理由があるときの記載もあります。その場合は、財産の存在を認識したときから3か月以内に申述すれば、受理されることもあります。ただし、この判断は個別の事情によります。

## 民法921条：処分すると単純承認とみなされる場合

### 条文の内容

民法921条は、次の場合に、相続人は単純承認をしたものとみなすと定めています。

1. 相続人が、相続財産の全部または一部を処分したとき
2. 相続人が、3か月の期間内に、限定承認や相続の放棄をしなかったとき
3. 限定承認や放棄の後でも、相続財産を隠したり、私的に消費したりしたとき

1号には、例外があります。保存行為と、短期の賃貸は、処分に含まれません。

### 「処分」にあたる行為は、公式ページに一覧がありません

裁判所の案内ページには、単純承認の基本の説明があります。一方で、どの行為が処分にあたるかの具体例は、確認できませんでした。

個別の事情で判断が分かれる可能性があります。そのため、断定はできません。遺品整理では、次のような行為を、相談まで保留するのが安全側です。

| 行為の種類 | 考え方（一般論） |
|------|------|
| 売る、譲る、あげる | 処分にあたるかが問題になりえます |
| 壊す、捨てる | 価値のある物は、問題になりえます |
| 預貯金の引き出し、解約 | 処分や消費が問題になりえます |
| 名義の変更、契約の解除 | 相談してから行います |
| 使う、消費する | 3号の「私に消費」が問題になりえます |
| 調べる、記録する | 民法915条2項が、調査を認めています |
| 保存行為 | 921条1号のただし書で例外とされています |

何が保存行為にあたるかは、個別に判断されます。公式ページに範囲の説明は見当たりません。専門家に確認してください。

### 調査と処分は別です

民法915条2項は、承認や放棄をする前に、相続財産の調査ができると定めています。遺品の中から、財産や借金の手がかりを探すことは、調査として必要です。

調べるときは、物を動かしすぎないようにします。写真で記録を残し、見つけた書類は箱に集めて保管します。

## 遺品整理の前に、やってよいこと・待つこと

### 先にやってよいこと（調査・保管・記録）

- 見つけた物の写真を撮り、一覧を作ります。
- 通帳、契約書、督促状、郵便物は、捨てずに保管します。
- 遺言書は、開封せずに、家庭裁判所へ検認を請求します。
- 家族や他の相続人に、放棄を考えていることを伝えます。
- 相談窓口を予約し、期限を確認します。

### 相談まで待つこと

- 家財や不用品を、業者へ依頼して処分すること
- 粗大ごみや家電を、まとめて出すこと
- 預貯金の引き出し、解約、名義変更
- 賃貸住宅の解約、不動産や車の売却
- 形見分けとして、価値のある物を渡すこと

遺品整理を業者に頼む前にも、相談が必要です。業者への依頼は、処分に近い行為だからです。業者の選び方は、[新潟市で遺品整理を頼むとき](../ihinseiri-niigata-shi-gyosha-erabikata/)にまとめています。

### 自分が放棄すると、次の順位の人に影響が出ます

放棄をすると、次の順位の人が相続人になる場合があります。東京家庭裁判所の案内には、先の順位の人の放棄が受理されていないと、次の順位の人は申述できないと書かれています。

親族の間で、放棄を考えていることを共有しておきます。

法テラスの無料相談は、1つの問題につき3回まで、1回30分です。利用には、収入・資産の基準があります。詳しい基準は、予約時に確認します。

司法書士会の案内には、本人が申請する書類の作成について、助言や確認は相談の対象外とあります。電話相談で受けられる範囲を、先に確認してください。

新潟市の福祉総合相談センターにも、弁護士の法律相談がある心配ごと相談所があります。予約制で、火〜土の9:00〜16:00に受け付けています（025-243-4369）。

### 相談に持っていく物

- 亡くなった人の氏名、亡くなった日、最後の住所
- 亡くなったことを知った日
- 見つけた借金や契約の書類、督促状の写し
- すでに処分した物があれば、その内容
- 相続人になる親族の一覧

## 申述の手続き

申述先は、亡くなった人の最後の住所地を管轄する家庭裁判所です。どの裁判所にあたるかは、裁判所の一覧ページで確認します。

必要書類は、申述書、亡くなった人の住民票除票などです。相続人の順位に応じた戸籍謄本も必要です。詳しい書類は、裁判所の案内ページで確認してください。

## よくある質問

**Q　遺品整理を始める前に、相続放棄は考えるべきですか。**
放棄の可能性があるなら、処分の前に考えます。財産を処分すると、単純承認とみなされる場合があります（民法921条）。迷うときは、窓口に先に相談してください。

**Q　どこまでの片付けなら、処分にならないのですか。**
公式ページには、処分にあたる行為の一覧がありません。個別の事情で判断が分かれる可能性があるため、断定はできません。片付けの前に、弁護士や司法書士に確認してください。

**Q　ごみを出すだけでも、問題になりますか。**
ごみの内容によります。価値のある物の廃棄は、問題になりえます。何を出すかを決める前に、相談してください。

**Q　3か月を過ぎたら、もう放棄できませんか。**
3か月以内に判断できないときは、期間を延ばす申立てができます。期限が過ぎた場合は、個別の事情で扱いが変わる可能性があります。早めに専門家へ相談してください。

**Q　弁護士と司法書士は、どちらに相談すればよいですか。**
一概には言えません。司法書士会の総合相談センターは、電話相談が無料です。まず内容を整理したいときの入口になります。争いがある場合などは、弁護士会の窓口が選択肢です。

**Q　放棄をしたあとの実家の管理は、どうなりますか。**
民法940条は、放棄の時に相続財産を現に占有していた人に、保存の義務を定めています。次の人へ引き渡すまで、自分の財産と同じ注意で保存します。実家に住んでいたり、鍵を預かっていたりする場合が問題になりえます。個別の事情で変わるため、弁護士や司法書士に確認してください。
