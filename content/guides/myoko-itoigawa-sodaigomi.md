# 妙高市・糸魚川市の粗大ごみの出し方｜処理券制と重量制の違い

妙高市は、年2回、5月と10月に、有料の戸別収集をします。品目ごとの処理券を貼ります。たんすは、1m未満で600円です。糸魚川市は、戸別収集の記載がありません。清掃センターへ自分で運びます。料金は重量制で、30kg以下は1日1回に限り無料です。

## この記事で分かること

- 妙高市は品目別の処理券、糸魚川市は重量制の持ち込み、という違い
- 実家じまいで出やすい家具や寝具の扱いと料金
- 持ち込み先、受付時間、市で出せない物

2市は、仕組みがまったく違います。この記事は、両市の公式情報だけでまとめました。確認日は2026年10月3日です。申し込む前に、公式ページで最新の情報を見てください。

## 妙高市

### 申込

粗大ごみの戸別収集は、集積所に出せない大型のごみを、施設へ直接運べない世帯向けのサービスです。有料です。

| 項目 | 内容 |
|------|------|
| 収集時期 | 年2回（5月・10月） |
| 申込先 | 市指定の収集業者 (有)川村商店 0255-72-9422（電話・FAX） |
| 期限 | 収集日の2週間前から、3日前まで |
| 処理券の購入 | 市役所、各支所、取扱店 |
| 出し方 | 収集日の朝8時までに、処理券を貼って玄関先へ |
| 留守 | 留守でも収集する。家の中には入らない |
| 集合住宅 | 1階の入口に出す |

大人2人で、車に積み込める範囲の物に限ります。

申込先の対象地域は、公式ページで「市内全地域」の後に、一部の地区が除かれています。表記が不明瞭です。除かれた地区の申込先は、確認できません。[要確認: 川村商店の対象外地区の申込先]

処理券の取扱店は、コンビニ、ドラッグストア、ホームセンター、スーパー、農協などです。地域別の一覧が、市のページにあります。

|------|--------|
| ふとん | 300円 |
| 毛布 | 300円 |
| 畳（1畳／半畳） | 900円／600円 |
| タンス（最長辺1m未満／1m以上） | 600円／1,200円 |
| 食器棚（最長辺1m未満／1m以上） | 600円／1,200円 |
| 机（木製／金属製） | 600円／900円 |
| ソファー（1人用／2〜3人用） | 900円／1,200円 |
| ベッドマット（スプリングなし） | 600円 |
| ベッドの枠（木製／金属製） | 900円／1,200円 |

一覧にない物は、環境生活課へ確認します。一覧には、そう書かれています。

ふとんなどの可燃物は、裁断して指定ごみ袋に入れば、集積所に出せます。1m×40cm×40cm程度で、15kg以内の金属や大型プラスチック製品も、集積所に出せます。

### 持ち込み

| 項目 | あらい再資源センター | 妙高クリーンセンター |
|------|---------------------|----------------------|
| 対象 | 金属類、資源物、埋立てごみ | 燃やせるごみ |
| 住所 | 妙高市梨木7 | 妙高市大字高柳931番地1 |
| 電話 | 0255-72-6841 | [要確認: 妙高クリーンセンターの電話番号] |
| 受付（平日） | 8:45〜16:30（12〜13時を除く） | 8:45〜16:30（12〜13時を除く） |
| 受付（土曜・日曜） | 休日受付は8:45〜11:45（指定日のみ） | 土曜 8:45〜11:45 |
| 家庭系の料金 | 10kgあたり75円 | 10kgあたり90円 |

妙高クリーンセンターが受け入れる物は、ふとん、たたみ、波板、たんす、木製家具、カーペットなどです。大きい物は、長さ3m、幅1m、厚さ70cm程度以下に切ります。

あらい再資源センターは、自転車、トタン板、金属製家具などの金属類を受け入れます。

表の料金は、市の施設ページの現行の記載です。あらい再資源センターは「料金の変更はありません」とあります。妙高クリーンセンターの手数料は、2023年4月1日に改定されました。

### 市で出せない物

戸別収集に出せない物は、タイヤ、消火器、バッテリー、農機具、ガスボンベ、耐火金庫、断熱保温材、医療廃棄物などです。

家電4品目は、運搬のみです。リサイクル券と、処理手数料が要ります。あらい再資源センターや許可業者へ持ち込む方法があります。指定引取場所は、上越市に2か所あります。

## 糸魚川市

### 申込

戸別収集の記載は、公式ページで確認できませんでした。粗大ごみの申込制度は、ありません。

集積所に出せない大型や大量のごみは、自分で施設へ持ち込みます。自分で運べないときは、市の許可業者に頼みます。有償です。

### 料金

清掃センターへの持ち込みは、重量制です。家庭ごみの手数料は、次のとおりです。

| 重量 | 破砕なし | 破砕あり |
|------|----------|----------|
| 30kg以下 | 1日1回に限り無料。2回目以降は1回1,000円 | 1日1回に限り無料。2回目以降は1回1,500円 |
| 30kg超〜500kg | 1,000円 | 1,500円 |
| 500kg超 | 1,000円に、超えた分を100kgにつき300円加算 | 1,500円に、超えた分を100kgにつき450円加算 |

ふとん、カーペット、木くずなどで、長さ30cmを超える物は、破砕が必要です。破砕ありの料金になります。破砕の設備を使うと、ごみ量の50％の額が加算されます。

### 持ち込み

| 項目 | 内容 |
|------|------|
| 施設 | 糸魚川市清掃センター |
| 住所 | 糸魚川市大字須沢2051-2 |
| 電話 | 025-552-1324（センター）、025-552-1511（衛生施設係） |
| 受付 | 平日 8:30〜16:30 |
| 休み | 土曜、日曜、祝日、12月31日〜1月3日 |
| 例外 | 祝日が燃やせるごみの収集日なら、搬入できる |
| 予約 | 公式に記載がありません。[要確認: 持ち込みの予約の要否] |

持ち込めるのは、燃やせるごみと燃やせないごみです。事業系の燃やせないごみは、持ち込めません。必ず分別します。金属部分は、なるべく取り除きます。

搬入の基準は、次のとおりです。

| 区分 | 基準 |
|------|------|
| 燃やせるごみ | 長さ180cm以下、太さ20cm以下 |
| 燃やせないごみ | 長さ100cm以下 |

日曜日にも、持ち込める日があります。毎月第3日曜日です。7月、8月、1月、2月を除きます。受付は、9:00〜12:00と13:00〜15:00です。年8回です。手数料は、燃やせないごみが無料です。ただし、特殊な物と大型の物は有料です。燃やせるごみは、30kg以下が1日1回に限り無料です。

### 許可業者

市の許可業者は、ごみの量と種類によって、料金が各社で違います。市の料金表はありません。

市のサイトには、許可業者1社が作った、不用品処理の参考費用の一覧が載っています。市の手数料ではありません。実際の価格は、大きさなどで変わる、と書かれています。依頼の方法は、公式ページで確認できません。[要確認: 許可業者への依頼の申込方法]

### 市で出せない物

市では、次の物を収集しません。販売店か、市の許可業者に相談します。

- 家電リサイクル対象品（テレビ、エアコン、冷蔵庫、洗濯機など）
- タイヤ、パソコン、バイク、農機具、魚網
- 薬品、消火器、農薬、爆発物、医療系器具
- 大型電化製品（本体が1mを超える物）
- 粗大ごみ、引っ越しや掃除で出る多量のごみ
- 石綿を含んだ製品（珪藻土製品など）

## 分別で迷いやすい品目のQ&A

**Q1　布団は。**
妙高市は、戸別収集で300円です。品目一覧では、燃やせるごみです。40cm角以内に切って袋に入れます。羽毛布団は、集積所に出せません。粗大ごみ回収か、クリーンセンターへ運びます。糸魚川市は、収集しません。清掃センターへ直接運びます。30kgを超えると有料です。

**Q2　マットレスは。**
妙高市は、スプリングなしが600円です。スプリング入りは、手数料の一覧にありません。ごみ品目検索の一覧では、許可業者へ、とされています。 糸魚川市は、スプリング入りが許可業者です。スプリングなしは、清掃センターへ運びます。

**Q3　ソファーは。**
妙高市は、1人用が900円、2〜3人用が1,200円です。糸魚川市は、収集しません。市の許可業者に頼みます。有償です。

**Q4　たんすは。**
妙高市は、最長辺1m未満が600円、1m以上が1,200円です。糸魚川市は、木製なら、金属部分を取り除きます。長さ30cm以下にして、燃やせるごみに出します。できなければ、清掃センターへ運びます。金属製の机は、許可業者です。

**Q5　畳は。**
妙高市は、1畳900円、半畳600円です。品目一覧では、粗大ごみ回収かクリーンセンターへ、とされています。糸魚川市は、収集しません。清掃センターへ直接運びます。

**Q6　石油ストーブは。**
妙高市は、ストーブが600円です。糸魚川市は、金物類・小型家電です。燃料を抜いて出します。電池は、拠点回収へ出します。

**Q7　物干し台は。**
妙高市は、物干し支柱が1本300円です。糸魚川市は、コンクリート付きの物干し台を収集しません。許可業者に頼みます。物干し竿は、1mを超えると許可業者です。

**Q8　仏壇と神棚は。**
2市とも、仏壇と神棚は、取得した範囲の公式ページで見つかりませんでした。[要確認: 仏壇・神棚の分別（妙高市・糸魚川市）]

## 実家をまるごと片付けるときの考え方

妙高市は、収集が年2回です。5月と10月に合わせる必要があります。申込は、2週間前から3日前までです。品目ごとに処理券を買うため、数が多いと手間がかかります。

糸魚川市は、申込がありません。ただし、車と人手を用意して、平日の日中に運びます。長さや太さの基準もあります。ソファー、ベッド、ふとんなどは、清掃センターか許可業者です。

どちらの市も、家電4品目は、市の収集や処理では出せません。

次のようなときは、市の制度だけでは足りないことがあります。量が多い。収集の時期に間に合わない。雪の時期で搬出が難しい。遠方で通えない。そのときは、許可業者に見積りを取る方法があります。

見積りの取り方は、[自分で出す？業者に頼む？](../jibun-de-dasu-ka-gyousha-ka/)を見てください。雪の時期の考え方は、[冬の実家じまい](../fuyu-no-jikkajimai-yukioroshi/)にまとめました。
