# 実家じまいに全部でいくらかかる？新潟の費用を、公開数字で積み上げる

## 結論：総額は家ごとに違います。決め手は「売値」「3,000万円控除」「解体するか」の3つです

新潟の実家じまいに、全部でいくらかかるのか。この記事は、公式と公開されている数字だけで積み上げました。計算例の金額は、売却1,000万円などの仮定です。読者の家の総額ではありません。

総額を動かすのは、次の3つです。

- **売却価格。** 仲介手数料と税金が、売値に連動します。
- **3,000万円特別控除が使えるか。** 仮定の例では、税金が約185万円から0円まで変わります。
- **解体するか。** 解体費は公的な相場がなく、見積りで決まります。

仮定の例は、売却1,000万円、固定資産税評価額800万円、取得費は不明、家付きで売るケースです。公開数字だけの費用は、約62.5万円になります。仲介手数料は法律の上限で計算しました。実際は、これより下がることがあります。この約62.5万円に、司法書士報酬、戸籍の手数料、測量費、解体費は入っていません。

税金は、同じ仮定で、控除が使えれば0円、使えなければ約184.8万円です。売らずに持ち続ける場合は、固定資産税と電気の基本料だけで、仮の評価額で年に約4.6万円です。雪下ろしや水道は別です。

築45年の木造2階建てのように、昭和56年5月31日の前後に建てた家は、控除が使えるかが分かれ目です。自分の家に当てはめる手順は、「自分の場合の計算の手順」の章にあります。

この記事で分かること

- 片付け、仏壇、解体、登記、売却、税金の項目ごとの公開数字
- 3つのケース（家付きで売る、解体して売る、持ち続ける）の積み上げ
- 3,000万円控除が使えるかのチェック表
- 自分の家の総額を出す手順と、手元に残るお金の計算式
- 費用を減らす順番

片付けの費用だけを詳しく知りたい方は、[新潟で実家を片付ける費用の目安](../jikkajimai-hiyou-niigata/)と[片付け業者の費用（新潟）](../jikkajimai-gyosha-hiyou-niigata/)を先に読んでください。この記事は、全工程の総額に絞っています。

## この記事の前提（仮の数字です）

実家の数字は、家ごとに違います。次の仮定で、計算例を作りました。

| 項目 | 仮定 | 理由 |
|---|---|---|
| 家の広さ | 3LDK相当の木造 | 業者の公開料金が載る最大の間取りです。4LDK以上は公開料金を確認できません |
| 固定資産税評価額 | 土地600万円（200平方メートル以下）、建物200万円。合計800万円 | 登録免許税と固定資産税の計算に使う仮の額です |
| 売却価格 | 1,000万円 | 仲介手数料と税金の計算に使う仮の額です。実際は査定で決まります |
| 取得費 | 不明（概算の5％を使う） | 先祖から受け継いだ家では、取得費が分からないことが多いためです |
| 所有期間 | 5年超（長期） | 相続した不動産は、亡くなった方が取得した日から数えます |
| 家財 | 家電4品目を各1台、仏壇1台 | 実家にある品の一例です |
| 3,000万円控除 | 使える場合と使えない場合を、両方計算します | 築年や名義で、使えるかが分かれるためです |

売却価格1,000万円は、新潟の実家の相場を示すものではありません。計算の仕組みを見せるための仮の額です。

## 項目ごとの数字

### 片付け・遺品整理

業者の公開料金は、当サイトが県内の公開料金を集計した値です。3LDKは、19社で最小158,000円〜、中央値180,000円〜、最大230,000円〜でした。いずれも「〜円」の基本料金で、総額ではありません。集計の方法は、[片付け業者の費用（新潟）](../jikkajimai-gyosha-hiyou-niigata/)にあります。4LDK以上の家は、公開料金がありません。複数社に同じ条件で見積りを頼みます。

市に出す場合の手数料は、次のとおりです。たんす2点、ベッド、ソファー、布団3枚などの計12点を出す計算例で、新潟市は2,800円、長岡市は4,000円です。長岡市の戸別収集は、1回5点までです。手数料は200円、600円、1,000円の3段階で、12点なら3回に分ける計算です。ただし、搬出の人手、車の手配、帰省の交通費は、この金額に入っていません。

家電4品目（エアコン、テレビ、冷蔵庫、洗濯機）は、市の粗大ごみに出せません。リサイクル料金は、メーカーで違います。家電リサイクル券センターの主要メーカー表では、洗濯機が2,530円、テレビ（16型以上）が2,970円、冷蔵庫（171リットル以上）が4,730円です。エアコンは、日立・シャープ・三菱電機が990円、パナソニック・東芝・ダイキンが550円です。

各1台の合計は、エアコンが990円なら11,220円、550円なら10,780円です。長岡市の公式ページは「令和5年10月現在」の表記ですが、金額は現行の料金表と同じでした。

収集運搬料金は、リサイクル料金とは別にかかります。長岡市のページにも、家電リサイクル券センターのページにも、額は載っていません。額は、購入した店、または長岡市の許可業者の見積りで決まります。自分で指定引取場所に持ち込む方法もあります。場所と手順は、長岡市のページにあります。詳しくは、[家電4品目の処分（新潟）](../kaden4hinmoku-niigata/)にあります。

### 仏壇

長岡市では、仏壇は粗大ごみです。長辺90cm以下で1人で持てない物は600円、長辺90cm超で2人で持てる物は1,000円です。品目一覧の備考に、「供養はしない」と書かれています。

新潟市は、料金一覧に仏壇の品名がありません。同じ一覧に、幅・奥行・高さの合計で100円から500円とする「その他」の区分があります。仏壇がこの区分に当たるかは、一覧から確定できません。粗大ごみ受付センターに、品名と寸法を伝えて確かめてください。[要確認: 新潟市の仏壇の料金区分（新潟市粗大ごみ受付センターで、品名と寸法を伝えて確認）]

閉眼供養の費用は、公式の数字がありません。寺ごとに違います。菩提寺がある場合は、菩提寺に直接聞きます。詳しくは、[仏壇・神棚・位牌の処分](../butsudan-kamidana-shobun-niigata/)にあります。

### 解体

解体費の公的な相場は、確認できていません。国は、補助金を計算するときの除却工事費の上限を、1平方メートルあたり木造36,000円、非木造51,000円と定めています（令和8年度）。これは補助の計算上の上限で、実際の解体費の相場ではありません。この記事では、解体費の計算に使いません。

解体費は、次の順で見積りを取ります。

- 新潟県が公開している解体工事業の登録名簿で、登録番号か建設業の許可番号を確かめます。請負金額が500万円未満の解体は登録、500万円以上は建設業の許可が必要です。
- 同じ条件で複数社に見積りを頼み、内訳で比べます。内訳の読み方は、[新潟で実家を解体する費用の考え方](../kaitai-hiyou-niigata/)にあります。
- 見積りに、アスベストの事前調査費と、建物滅失登記の費用が入っているか確かめます。

アスベスト（石綿）は、建物を解体する前の事前調査が必要です。環境省の案内では、調査をするのは元請業者か自主施工者です。厚生労働省の労働局の案内では、令和5年10月1日以後に着工する工事から、建築物は「建築物石綿含有建材調査者」が調べます。解体する部分の床面積の合計が80平方メートル以上なら、結果を報告します。調査費の額は、公式の数字がありません。見積書に、調査費の行があるか確かめます。

建物滅失登記は、解体から1か月以内に申請します（不動産登記法第57条）。正当な理由なく怠ると、10万円以下の過料の対象です（同法第164条）。添付するのは、解体した業者が作る建物滅失証明書です。法務局の申請書の記載例には、登録免許税や手数料を書く欄がありません。国税庁の登録免許税の税額表にも、滅失登記の項目がありません。「非課税」と明記した公式ページは、確認できませんでした。[要確認: 建物滅失登記の登録免許税が非課税と明記した公式文書（管轄の法務局）] 土地家屋調査士に頼む場合の報酬は、日本土地家屋調査士会連合会の2022年度アンケートで、設例（木造2階建と物置の滅失）の全国平均が48,098円（税抜）、中央値が47,500円でした。事務所ごとに自由に決める報酬です。実際は見積りで確かめます。

解体には、市の補助が使える場合があります。上限額は、次の表のとおりです。

| 市 | 補助率・上限 | 主な条件・受付 |
|---|---|---|
| 上越市 | 2分の1・50万円 | 特定空き家等は低所得世帯が対象。ふつうの空き家は、跡地を10年以上、地域活性化に使うことが条件 |
| 三条市 | 5分の4・50万円 | 特定空家等。令和8年度は募集中で、先着順 |
| 柏崎市 | 2分の1・50万円（居住誘導区域内65万円） | 特定空家等・不良住宅 |
| 燕市 | 2分の1・30万円 | 特定空き家等。市内事業者に30万円以上で発注。受付は令和8年12月28日まで |
| 小千谷市 | 5分の1・50万円（市外業者は25万円） | 解体のみの場合。空き家バンクへの登録後、おおむね1年が経った空き家など |
| 佐渡市 | 木造は2分の1以内・80万円 | 補助額が15万円未満なら交付なし。跡地が建替え目的でないこと |
| 新潟市 | 3分の1・50万円 | 未接道地の空き家など。令和8年度分の受付は終了 |
| 十日町市 | 区域内は50％・30万円、区域外は20万円 | 令和8年度分の受付は終了 |
| 長岡市 | 個人向けは確認できず | 町内会など地域団体向けの制度のみ（補助率5分の4・上限160万円） |

多くの制度は、特定空家等などが対象です。ふつうの空き家は、対象外のことがあります。どの市も、契約や着工の前に申請します。県内30市町村の一覧は、[実家じまいに使える補助金](../jikkajimai-hojokin-niigata/)にあります。

### 相続登記

相続登記の登録免許税は、不動産の価額の0.4％です（国税庁、法務局）。価額は、固定資産税の課税明細書の「価格」（評価額）です。「課税標準額」ではありません。土地と建物の評価額を合わせて、1,000円未満を切り捨てます。税額は、100円未満を切り捨てます。評価額800万円なら32,000円です。評価額が500万円なら20,000円、1,000万円なら40,000円になります。

土地の価額が100万円以下なら、登録免許税はかかりません。相続登記をしないまま相続人が亡くなった場合の免税措置もあります。どちらも期限は2027年3月31日までです。申請書に根拠の条文を書かないと、免税を受けられません。

戸籍は、出生から死亡までの分を集めます。長岡市の手数料は、戸籍謄本450円、除籍謄本750円（改製原戸籍謄本も750円）です。通数は家ごとに違うため、合計には入れていません。

司法書士報酬は、各司法書士が自由に決めます（日本司法書士会連合会、法務局）。連合会の報酬アンケート（2024年3月実施）には、設例があります。土地1筆と建物1棟、評価額の合計1,000万円、戸籍5通を請求、相続人3名のうち1名が単独で相続する場合です。この設例の平均は74,888円（回答1,109件）でした。登録免許税や戸籍の実費は、含まれません。家の条件が違えば、額も変わります。複数の事務所に同じ条件で見積りを頼みます。自分で申請すれば、報酬は不要です。手順は、[相続登記の義務化と新潟の法務局・相談窓口](../souzoku-touki-niigata-houmukyoku/)にあります。

### 売却にかかる費用

仲介手数料には、法律で決まる上限があります。国土交通省のページによると、物件価格に応じた料率を足し合わせます（税込）。

- 200万円以下の部分：5.5％
- 200万円超400万円以下の部分：4.4％
- 400万円超の部分：3.3％

400万円を超える場合は、「価格×3.3％＋6.6万円」で出せます。価格ごとの上限は、次の表のとおりです。

| 売却価格 | 仲介手数料の上限（税込） |
|---|---|
| 300万円 | 15.4万円（特例で最大33万円） |
| 500万円 | 23.1万円（特例で最大33万円） |
| 800万円 | 33.0万円 |
| 1,000万円 | 39.6万円 |
| 1,500万円 | 56.1万円 |

2024年7月1日から、800万円以下の「低廉な空家等」の売買には、特例があります。上限が、30万円×1.1倍＝33万円（税込）まで引き上げられました。たとえば300万円の売却なら、33万円は価格の11％です。価格が低い家ほど、手数料の負担割合が大きくなりやすい仕組みです。

国土交通省は、媒介契約を結ぶときに、上限額の範囲内で報酬額をあらかじめ合意しておくことが重要としています。特例を使うかどうかと、実際の額は、媒介契約書の報酬欄で契約の前に確かめます。手数料は上限であって、決まった額ではありません。

売買契約書の印紙税は、軽減措置があります（2027年3月31日までに作成する契約書）。100万円超500万円以下は1,000円、500万円超1,000万円以下は5,000円、1,000万円超5,000万円以下は10,000円です。負担の分け方は、契約で決まります。

測量費は、売る土地の境界が確定していない場合に必要になります。公的な相場はありません。日本土地家屋調査士会連合会の2022年度アンケートに、設例があります。宅地180平方メートルの売買のため地積更正登記をし、隣接地6筆と筆界を確認する場合です。全国平均は390,316円、中央値は372,584円でした（いずれも税抜、実費は別）。境界の状況で大きく変わります。実際は、土地家屋調査士の見積りで確かめます。

耐震基準を満たして売る場合の、耐震基準適合証明書の取得費は、公式の相場がありません。建築士事務所などに、見積りを頼みます。長岡市の確認書の申請には、この証明書が必要になる売り方があります。

### 税金

売って利益が出ると、譲渡所得として税金がかかります。計算式は次のとおりです。

> 譲渡価額 −（取得費＋譲渡費用）− 特別控除額 ＝ 課税される所得

長期（所有期間5年超）の税率は、所得税15％、復興特別所得税（所得税額の2.1％）、住民税5％です。合計で20.315％です。5年超かどうかは、売った年の1月1日の時点で判定します。相続した家は、亡くなった方が取得した日から数えます。

取得費が分からないとき、または実際の取得費が譲渡価額の5％より少ないときは、譲渡価額の5％を取得費にできます。購入時の契約書などで実額が分かり、5％より大きいときは、実額を使えます。建物は、所有期間中の減価償却相当額を引いて計算します。

譲渡費用には、仲介手数料、測量費、契約書の印紙代、建物を取り壊して土地を売るときの取壊し費用が入ります。

家財の処分費や遺品整理費が譲渡費用に入るかは、国税庁のページに記載がありません。この記事の計算には入れていません。[要確認: 家財処分費の扱い（所轄の税務署または税理士）]

相続税を払った場合は、相続税の一部を取得費に加算する特例があります（国税庁 No.3267）。空き家の3,000万円控除は、相続財産の取得費の特例を受けていないことが要件の一つです。どちらが有利かは、税務署か税理士に確認してください。

相続税の基礎控除は「3,000万円＋600万円×法定相続人の数」です（国税庁）。財産の合計が基礎控除を超えない場合は、相続税はかかりません。この記事の積み上げには入れていません。

#### 3,000万円控除が使えるかのチェック表

相続した空き家には、3,000万円の特別控除があります（国税庁 No.3306）。次の表に、すべて当てはまる必要があります。

| 確認すること | 条件 | 確かめる書類・窓口 |
|---|---|---|
| 売る人 | 相続または遺贈で、家屋と敷地を取得した相続人です。親御さんが元気なうちに売る場合は、この特例ではありません（別の特例は国税庁 No.3302） | 戸籍、登記事項証明書 |
| 建築時期 | 昭和56年5月31日以前に建築されています。築45年は、2026年から数えて1981年（昭和56年）ごろです。5月31日の前か後かで結果が変わります | 登記事項証明書の新築年月日、建築確認の資料 |
| 建物の登記 | 区分所有建物の登記がされていません | 登記事項証明書 |
| 住んでいた人 | 相続の開始の直前に、亡くなった方以外に住んでいた人がいません。老人ホームなどに入所していた場合は、別の要件があります（国税庁 No.3307）。[親が施設に入ったあとの実家](../oya-shisetsu-nyusho-jikka/)も読んでください | 国税庁 No.3306・3307 |
| 相続後の使い方 | 相続の時から売るときまで、事業、貸付け、居住に使っていません | 自分で確認 |
| 売る時期 | 相続開始から3年を経過する日の属する年の12月31日までに売ります。かつ、令和9年（2027年）12月31日までです | 亡くなった日が分かる戸籍 |
| 売却代金 | 1億円以下です。分割して売った分も、合算して判定します | 売買契約書 |
| 売る相手 | 親子、夫婦など特別の関係がある人ではありません | 自分で確認 |
| 相続人の数 | 相続人が3人以上のときは、令和6年1月1日以後の譲渡で、控除は2,000万円までです | 戸籍 |
| 売り方 | 下の3つのどれかです | 下記 |

売り方は、次の3つのどれかです。

- 家屋を、耐震基準を満たした状態で売ります（家屋と敷地、または家屋のみ）。
- 家屋を全部取り壊してから、敷地を売ります。取壊し後、売るまで、敷地は建物などの敷地に使いません。
- そのまま売り、売った翌年の2月15日までに、耐震基準を満たすか、家屋を全部取り壊します（令和6年1月1日以後の譲渡）。長岡市のページには、この売り方は買主の協力が必要とあります。

手続きは、次の順です。売ったあとに、長岡市の都市政策課で「被相続人居住用家屋等確認書」の交付を受けます。手数料は不要で、交付まで2週間程度です（窓口持参か郵送）。この確認書などを、確定申告書に添えて税務署に出します。

## ケース別の積み上げ

仮定は、前の章のとおりです。売却価格は比較しやすいよう、ケースAとBで同じ1,000万円にしました。実際は、家付きと更地で売れる額が変わります。

### ケースA：片付けて、家付きで売る

| 項目 | 金額 | 計算 |
|---|---|---|
| 片付け（業者、3LDK） | 180,000円 | 中央値。範囲は158,000円〜230,000円 |
| 家電4品目のリサイクル料金 | 11,220円 | 各1台、エアコンが990円の場合。収集運搬料金は別 |
| 仏壇（長岡市の粗大ごみ） | 1,000円 | 上限の区分。供養の費用は別 |
| 相続登記の登録免許税 | 32,000円 | 評価額800万円×0.4％ |
| 仲介手数料（上限） | 396,000円 | 1,000万円×3.3％＋6.6万円 |
| 売買契約書の印紙税 | 5,000円 | 軽減後の税額 |
| 公開数字だけの小計 | 625,220円 | 片付けの範囲で603,220円〜675,220円 |

公開数字に載らない費用が、別にあります。司法書士報酬、戸籍の手数料、収集運搬料金、閉眼供養、測量費、耐震診断や改修の費用です。額の見方は、前の章に書きました。

税金は、次のとおりです。

| 区分 | 譲渡所得 | 税額 |
|---|---|---|
| 3,000万円控除が使えない | 9,099,000円 | 約184.8万円 |
| 3,000万円控除が使える | 0円（控除で消える） | 0円 |

譲渡所得は、「1,000万円−（取得費50万円＋仲介手数料39.6万円＋印紙税0.5万円）」で、909.9万円です。税額は、20.315％をかけた値です。

### ケースB：片付けて、解体して、更地で売る

| 項目 | 金額 | 計算 |
|---|---|---|
| ケースAと同じ項目の小計 | 625,220円 | 片付け、家電、仏壇、登記、仲介手数料、印紙税 |
| 解体費 | X円（見積り） | 公的な相場なし。登録業者の見積りで決める |
| アスベスト事前調査費 | 見積りで確認 | 公式の額なし。見積書に調査費の行があるか確かめる |
| 建物滅失登記の費用 | 見積りで確認 | 調査士に頼む場合の報酬は、全国平均48,098円（税抜、設例） |
| 解体の補助金（使える場合） | マイナス（市により上限30万〜80万円） | 上の表のとおり。着工前に申請 |
| 公開数字だけの小計 | 625,220円＋X円 | 補助金を引く前 |

解体費を、Xとします。解体費は、売却するときの譲渡費用です。3,000万円控除が使えない場合は、課税される所得が減ります。税額は、次のとおり変わります。

| 区分 | 譲渡所得 | 税額 |
|---|---|---|
| 3,000万円控除が使えない | 9,099,000円−X円 | （9,099,000円−X円）×20.315％ |
| 3,000万円控除が使える | 0円 | 0円 |

控除が使えない場合、解体費1万円につき、税金が約2,000円減ります。逆に、控除が使えて税額がもともと0円なら、解体費は税金の面では何も軽くしません。

更地にして売る方法は、控除の要件も変わります。家屋をすべて取り壊してから敷地を売る場合は、取壊し後に敷地が建物などの敷地として使われていないことが条件です。

解体して1月1日の時点で住宅がなくなると、土地の住宅用地特例が外れます。固定資産税が上がる場合があります。売却が1月1日をまたぐと、その年の税額に関わります。仕組みは、[空き家の固定資産税は本当に6倍になる？](../akiya-koteishisanzei-6bai/)にあります。

### ケースC：片付けて、空き家のまま持ち続ける

売らずに持つ場合は、毎年かかる費用の積み上げです。相続登記の登録免許税32,000円は、最初に一度だけかかります。持ち続けても、相続登記の申請は義務です。

| 項目 | 年額 | 計算 |
|---|---|---|
| 固定資産税（土地） | 14,000円 | 評価額600万円×6分の1×1.4％。住宅用地特例あり |
| 固定資産税（建物） | 28,000円 | 評価額200万円×1.4％ |
| 電気の基本料（残す場合の下限） | 約4,300円 | 従量電灯Bの最低月額358円95銭（税込）×12か月 |
| 公開数字だけの年額 | 約46,300円 | 5年で約23.2万円、10年で約46.3万円 |
| 都市計画税（市街化区域の場合のみ） | 8,000円 | 土地600万円×3分の1×0.2％＋建物200万円×0.2％。上の年額には入れていません |
| 雪下ろし、庭木、水道、火災保険、帰省・見回りの交通費 | 公式の金額なし | 地元の業者などの見積り、自分の回数×運賃で足す |

固定資産税は、負担調整措置を含まない、仕組みを見るための計算です。税率の1.4％は、総務省の標準税率です。200平方メートルを超える土地の部分は、課税標準が3分の1になります。都市計画税は、長岡市のページで、市街化区域内の土地と家屋が対象、税率0.2％です。このページの最終更新は2017年です。税率と対象は、毎年の納税通知書で確かめてください。東北電力の同じ料金ページは、2026年11月1日の託送料金の変更で、基本料金と電力量料金を見直すと案内しています。電気の額は、現行の最低月額で計算しました。

住宅用地特例が外れる場合（市の勧告を受けたとき、または家を解体したとき）は、土地の税が6倍になります。14,000円が84,000円になり、年額は約116,300円です。

冬の雪下ろしは、公的な料金の相場がありません。参考になる数字は、上越市が災害救助法の適用時に決める上限だけです。人力除雪は1人1時間4,000円で、3人が3時間働くと36,000円（4,000円×9時間）です。これは災害時の上限で計算した算数で、ふつうの冬の相場ではありません。空き家は、市の助成の対象外のことが多いです。見積りは、同じ条件で複数の業者に頼みます。[冬の実家じまいと雪対策](../fuyu-no-jikkajimai-yukioroshi/)も読んでください。

持ち続けるコストは、年に数万円で小さく見えます。ただし、隠れたコストが2つあります。

- 3,000万円控除の期限があります。令和9年12月31日までと、相続開始から3年を経過する年の12月31日までの、どちらか早いほうです。
- 勧告を受けると、固定資産税が上がります。雪で周りに被害が出ると、所有者が責任を問われる場合があります。

## 手元に残るお金の考え方

売ったあとに手元に残るお金は、次の式で出ます。

> 手元に残るお金 ＝ 売却代金 −（片付け・登記・仲介手数料などの費用）− 解体費 − 税金

ケースAとBの計算例は、次のとおりです。売却価格は1,000万円と仮定しています。

| ケース | 3,000万円控除が使える | 3,000万円控除が使えない |
|---|---|---|
| A（家付きで売る） | 約937.5万円 | 約752.6万円 |
| B（解体して更地で売る） | 約937.5万円−X円 | 約752.6万円−（X円×0.797） |

控除が使える場合と使えない場合で、約185万円の差があります。この差は、解体費や片付けの工夫では埋まりません。控除が使えるかどうかを、最初に確かめるのが、総額を考える近道です。

控除が使えない場合のケースBは、解体費の約2割を税金が肩代わりします。それでも、解体費をかけて売れる額が上がるとは限りません。解体する前に、買取や仲介の査定を取り、家付きと更地の売却価格を比べてください。[新潟の空き家を買い取ってもらうには](../akiya-kaitori-niigata/)に、買取と仲介の違いがあります。

売却価格が低い家は、費用が売却代金を上回ることがあります。その場合は、「売って手元に残す」ではなく、「持ち続ける費用を止める」が目的になります。費用の負担者の決め方は、[実家じまいのお金がないとき](../jikkajimai-okane-ga-nai/)にあります。

## 自分の場合の計算の手順

東京などの遠方に住み、長岡市の築45年の木造2階建てを「片付けて売る」か「解体して土地を売る」かで迷っている方を想定した手順です。自分の家の数字を、上から順に入れます。右端の列は、前の章の仮定の例です。

### 手順1：3つの書類を集める

- **登記事項証明書（法務局）。** 建物の新築年月日、名義、区分所有でないことを見ます。
- **固定資産税の課税明細書。** 長岡市では、毎年4月の納税通知書に付きます。土地と建物の「価格」（評価額）を見ます。なくしたときは、資産評価等証明書を請求します（1枚300円、窓口か郵送）。
- **購入時の売買契約書、建築の契約書。** 取得費の実額が分かるかを見ます。なければ、売値の5％です。

### 手順2：3,000万円控除が使えるかを判定する

前の章のチェック表を、上から順に確かめます。1つでも外れたら、「控除が使えない」の列で計算します。築45年は昭和56年ごろです。新築年月日が昭和56年5月31日以前かどうかが、最初の分かれ目です。

### 手順3：売値の幅を決める

家付きの査定額と、更地の査定額を、同じ条件で複数の不動産会社から取ります。査定が出るまでは、低・中・高の3通りで計算します。

### 手順4：費用を計算する

| 項目 | 計算式 | 仮定の例 |
|---|---|---|
| 仲介手数料 | 売値が400万円超なら、売値×3.3％＋6.6万円。800万円以下は上限33万円 | 39.6万円 |
| 印紙税 | 500万円以下1,000円、1,000万円以下5,000円、5,000万円以下10,000円 | 5,000円 |
| 相続登記の登録免許税 | 土地と建物の評価額の合計（1,000円未満切り捨て）×0.4％。土地が100万円以下なら土地分は免税（2027年3月31日まで） | 32,000円 |
| 司法書士報酬 | 見積り。自分で申請すれば不要 | 小計に入れない |
| 片付け | 業者の見積り＋市の粗大ごみ手数料＋家電のリサイクル料金と収集運搬料金 | 180,000円＋1,000円＋11,220円 |
| 解体するなら（X） | 解体費＋アスベスト調査費＋滅失登記の費用−補助金 | X円 |
| 測量 | 境界が未確定のとき、調査士の見積り | 小計に入れない |

### 手順5：税金を計算する

> 課税される所得 ＝ 売値 −（取得費＋仲介手数料＋印紙税＋測量費＋解体費）− 特別控除
> 税額 ＝ 課税される所得 × 20.315％（所得がマイナスなら0円）

取得費は、売値の5％です。実額が分かり、5％より大きいときは、実額を使います。解体費は、解体して土地を売るときだけ入れます。特別控除は、使えるときだけ入れます（最高3,000万円。相続人が3人以上なら2,000万円）。

控除なしで、取得費を5％としたときの税額の早見表です。売値の幅を決めたら、近い行を見てください。解体費と測量費は入れていません。

| 売値 | 仲介手数料 | 印紙税 | 取得費（5％） | 課税される所得 | 税額（約） |
|---|---|---|---|---|---|
| 500万円 | 33.0万円（特例の上限） | 0.1万円 | 25.0万円 | 441.9万円 | 89.8万円 |
| 800万円 | 33.0万円 | 0.5万円 | 40.0万円 | 726.5万円 | 147.6万円 |
| 1,000万円 | 39.6万円 | 0.5万円 | 50.0万円 | 909.9万円 | 184.8万円 |
| 1,500万円 | 56.1万円 | 1.0万円 | 75.0万円 | 1,367.9万円 | 277.9万円 |
| 2,000万円 | 72.6万円 | 1.0万円 | 100.0万円 | 1,826.4万円 | 371.0万円 |
| 3,000万円 | 105.6万円 | 1.0万円 | 150.0万円 | 2,743.4万円 | 557.3万円 |

控除が使えるときは、課税される所得から3,000万円を引きます。控除が3,000万円なら、表のどの行でも所得が控除額より小さく、税額は0円です。相続人が3人以上で控除が2,000万円のときは、売値3,000万円の行だけ、差額の743.4万円に課税されます。税額は約151.0万円です。

### 手順6：手元に残るお金を、家付きと更地で比べる

> 家付き（A）＝ 売値A −（片付け・登記・仲介手数料・印紙税）− 税金A
> 更地（B）＝ 売値B −（片付け・登記・仲介手数料・印紙税）− 解体費X − 税金B

BがAより多いかどうかが、解体を選ぶ目安です。控除が使えて税金が0円の場合、解体費Xは、そのまま手元から出ていきます。

### 手順7：持ち続ける場合の年額を出す

> 固定資産税 ＝ 土地の評価額×6分の1×1.4％（200平方メートルまで）＋建物の評価額×1.4％
> ＋ 電気の基本料 ＋ 雪下ろしなどの見積り ＋ 帰省・見回りの交通費

200平方メートルを超える土地の部分は、6分の1ではなく3分の1にします。市街化区域なら、都市計画税も足します。年額に年数をかけて、売る場合の費用と比べます。

### 手順8：期限を確かめる

- 相続開始（亡くなった日）から3年を経過する日の属する年の12月31日までに売る（控除を使う場合）。
- 令和9年（2027年）12月31日までに売る（控除を使う場合）。
- 解体したら、1か月以内に建物滅失登記を申請する。
- 売ったあと、長岡市で確認書をもらい、確定申告書に添える。

## 費用を減らす順番

次の順番で進めると、無駄な出費が減ります。

1. **まず、3,000万円控除が使えるかを確認する。** 税金の差が、いちばん大きいためです。期限は、令和9年12月31日までと、相続開始から3年を経過する年の12月31日です。登記事項証明書で建築年月日を確かめ、税務署か税理士に確認します。
2. **残す物と処分する物を分け、売れる物を探す。** 量が減ると、どの方法でも安くなります。遺品の買取は、[遺品の買取（新潟）](../ihin-kaitori-niigata/)にあります。
3. **市の粗大ごみと持ち込みを使う。** 12点で2,800円から4,000円です。新潟市の持ち込みは、10キロごとに100円です。詳しくは、[新潟市の粗大ごみの出し方](../niigata-shi-sodaigomi/)と[長岡市の粗大ごみの出し方](../nagaoka-shi-sodaigomi/)にあります。
4. **補助金を、契約の前に申請する。** 上越市は、家財の処分費の2分の1（上限10万円）です。新潟市西蒲区は、2分の1（上限20万円）です。どちらも空き家バンクへの登録が関わります。解体の補助は、上の表のとおりです。
5. **運べない物と量の多い分だけ、業者に頼む。** 範囲を絞ると、料金が下がることがあります。複数社から、同じ条件で見積りを取ります。
6. **仲介手数料を、契約の前に確認する。** 上限であって、決まった額ではありません。
7. **相続登記は、自分で申請できないか検討する。** 司法書士報酬がなくなります。登録免許税は、自分で申請しても必要です。

## 実家じまいの総額に関する、よくある質問

### 実家じまいは、全部でいくらかかりますか。

家ごとに違います。総額は、売却価格、3,000万円控除が使えるか、解体するかで大きく変わります。仮定の例（売却価格1,000万円、評価額800万円）では、家付きで売るケースの公開数字の費用が約62.5万円（仲介手数料は上限）です。解体するなら、解体費が加わります。税金は、控除が使えれば0円、使えなければ約185万円です。自分の家の額は、「自分の場合の計算の手順」で出せます。

### 家付きで売るのと、解体して売るのでは、どちらが手元に残りますか。

手元に残る額を、両方の式で計算して比べます。式は「売値−費用−解体費−税金」です。解体費は、公的な相場がありません。登録業者の見積りで決めます。控除が使えない場合は、解体費の約2割を、税金の減少で取り戻せます。控除が使えて税金が0円の場合は、解体費がそのまま出ていきます。市の補助が使えれば、上限30万〜80万円（市により違う）が戻ります。

### 実家を売ると、税金はいくらかかりますか。

長期の税率は、合計20.315％です。売却価格1,000万円、取得費が不明の例では、控除が使えないと約184.8万円です。相続した空き家で、昭和56年5月31日以前の建築などの要件を満たせば、最高3,000万円が引かれ、0円になる場合があります。要件は、本文のチェック表で確かめます。

### 築45年の実家は、3,000万円控除が使えますか。

新築年月日で決まります。築45年は、2026年から数えて昭和56年（1981年）ごろです。昭和56年5月31日以前に建築された家が対象です。登記事項証明書で、新築年月日を確かめます。ほかに、相続した相続人が売ること、売る時期、売り方の条件があります。使えるかの最終判断は、税務署か税理士に確認してください。

### 売らずに持っているだけだと、毎年いくらかかりますか。

仮の評価額（土地600万円、建物200万円）で、固定資産税が42,000円、電気の基本料が約4,300円で、年に約46,300円です。市街化区域なら、都市計画税が加わります。雪下ろし、水道、火災保険、帰省の交通費は、公式の金額がありません。勧告を受けるか、家を壊すと、固定資産税が上がります。

## 片付けの見積もりを取る前に

片付けの費用は、現地の量で決まります。公開料金は目安で、実際の見積りとは違います。片付けの見積もりは、[無料で見積もり相談](../../mitsumori/)から依頼できます。
