# 柏崎市の粗大ごみ処理券の買い方｜取扱所・値段・貼り方・払い戻し

## 結論：1枚300円で、市内の取扱所と市役所売店で買います

柏崎市の粗大ごみ処理券は、1枚300円です。市内のスーパーやコンビニなどの小売店と、柏崎市役所売店で売っています。

取扱所の一覧は、市のページにあります。地区別に、店名・住所・電話番号が載っています。令和8年8月28日現在の一覧です。

品物ごとに、貼る枚数が決まっています。1枚の品物も、2枚、3枚の品物もあります。

払い戻しは、できません。令和2年2月発行の市の案内に、そう書かれています。買う前に、金額を確かめます。

この記事は、柏崎市の公式情報だけでまとめました。内容は2026年10月17日の確認時点です。買う前に、公式ページで最新の情報を見てください。

## 処理券は、どこで買えますか

市の「指定ごみ袋・粗大ごみ処理券などの取扱所と価格」のページが、取扱所の一覧への入口です。粗大ごみ処理券は1枚300円（税込み）と書かれています。

一覧のページは、地区別になっています。見出しは、次の22です。

| 区分 | 見出し |
|------|------|
| 市内の地区（21） | 荒浜、大洲、北鯖石、北条、剣野、高田、高浜、高柳、田尻、中央、中鯖石、中通、西中通、西山、野田、半田、比角、枇杷島、松波、南鯖石、米山 |
| 市外 | 刈羽村 |

表の列は、取扱所名・住所・電話番号です。

自分の住所に近い地区の表で、店を探します。

### どんな店がありますか

市のガイドブックは、「スーパーマーケット、コンビニエンスストアなどの小売店や柏崎市役所売店で取り扱っています」と案内しています。

一覧には、コンビニ、ドラッグストア、スーパー、ホームセンター、酒店などの商店が載っています。

例として、「中央」地区の表から、種類ごとに店を挙げます。一覧に載っている店です。

| 種類 | 「中央」地区の一覧にある店の例 |
|------|------|
| 市の売店 | 柏崎市役所売店（日石町2番1号、0257-41-6801） |
| コンビニ | セブンイレブン柏崎新花町店、デイリーヤマザキ柏崎駅前1丁目店、ローソン柏崎学校町店 |
| ドラッグストア | ウエルシア柏崎錦町店、クスリのアオキ新花町店、ツルハドラッグ柏崎駅前店 |
| スーパー | ウオロク桜木店 |
| 商店 | 猪爪酒店、三條屋金物店、渡辺米店 |

目印は、店先の看板です。ガイドブックに、「指定ごみ袋・粗大ごみ処理券 取扱所」と書かれた看板の絵があります。

一覧は、取扱所名・住所・電話番号の3列です。処理券を扱うかどうかを、店ごとに分ける列は見当たりません。一覧に載る店が、すべて処理券を扱うかどうかは、書かれていません。[要確認: 一覧のすべての店で処理券を買えるか（柏崎市 環境課 クリーン推進係 0257-23-5170）]

柏崎市役所売店の販売時間は、一覧に書かれていません。[要確認: 柏崎市役所売店の販売時間（柏崎市 環境課）]

## いつ買えばよいですか

柏崎市の粗大ごみは、電話で申し込む月1回の戸別収集です。市の案内（令和2年2月発行）では、次の順になっています。

1. クリーンセンターかしわざきへ、電話で申し込みます。0257-23-5170です。
2. 電話で、係員が収集日、粗大ごみの処理金額、処理券の必要枚数を知らせます。
3. その枚数の処理券を、取扱所で買います。
4. 収集日の朝8時までに、申し込んだ品物に処理券を貼って、指定した場所に出します。

買った処理券には、必ず氏名を書きます。アパートの人は、部屋番号も書きます。

申込の期限、収集日、1回5点までの決まりは、[柏崎市の粗大ごみの出し方](../kashiwazaki-shi-sodaigomi/)にまとめています。

申込をしていない粗大ごみは、処理券が貼られていても収集されません。収集日と時間の指定はできません。この2点も、令和2年2月発行の案内の記載です。現在も同じかどうかは、市のページで確かめられていません。[要確認: 申込なしの粗大ごみの扱い、収集日・時間の指定が現在も同じか]

## 処理券の枚数と値段の考え方

処理券は、1枚300円です。品物ごとに、貼る枚数が決まっています。

| 貼る枚数 | 金額 |
|------|------|
| 1枚 | 300円 |
| 2枚 | 600円 |
| 3枚 | 900円 |

品物ごとの枚数は、市の分別ガイドブックの分別辞典にあります。「家庭ごみ ごみ分別検索」のページでも調べられます。辞典に載っていない品物は、クリーンセンターかしわざきへ問い合わせます。

主な品目の枚数の例は、[柏崎市の粗大ごみの出し方](../kashiwazaki-shi-sodaigomi/)に載せています。

## 清掃センターへ持ち込むときの処理券

クリーンセンターかしわざきへ自分で持ち込む場合も、処理券が要ります。

市のページには、次のとおり書かれています。市内の販売所で必要な枚数を買い、粗大ごみ処理申請書と一緒に、クリーンセンターの事務所へ出します。

持ち込む前に、取扱所で処理券を買っておきます。

クリーンセンターかしわざき（松波4-13-13）の受付は、月曜日から金曜日（祝日を除く）が午前8時30分から午後4時30分です。土曜日と祝日は、午前8時30分から午前11時30分です。日曜日と、12月29日から1月3日は受け付けていません。持ち込む点数に制限はありません。

受付場所や持ち込み方法は、[柏崎市の粗大ごみの出し方](../kashiwazaki-shi-sodaigomi/)にもあります。

## 余った処理券は、払い戻しできますか

払い戻しは、できません。令和2年2月発行の市の案内に、「粗大ごみ処理券の払い戻しはできません。必ず申し込み時の金額を確認してから、購入してください」とあります。

この案内は、現在のページでは確認できていません。[要確認: 払い戻し不可が現在も同じか（柏崎市 環境課 クリーン推進係）]

処理券の有効期限は、公式ページに記載がありません。余った券を、別の品物に使えるかどうかも、書かれていません。[要確認: 処理券の有効期限と、余った券の使い道（柏崎市 環境課 クリーン推進係）]

買いすぎを避けるには、申し込みの電話で、必要な枚数を聞いてから買います。
