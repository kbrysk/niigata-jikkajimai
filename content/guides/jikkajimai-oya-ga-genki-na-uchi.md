# 親が元気なうちに始める実家じまい｜生前整理の進め方と、新潟で使える窓口

親が元気なうちの実家じまいは、片付けより先に、親がどうしたいかを聞くことから始めます。次に、書類と連絡先を一覧にし、持ち物を4つに分け、住まいのエンディングノートに書き出します。親の了解なしに処分しないでください。

## 5つのステップ（早見表）

| ステップ | やること | ポイント |
|---|---|---|
| 1 | 親の意思を聞く | 住まい・持ち物・万一のときの3つを聞く |
| 2 | 書類と連絡先を一覧にする | 暗証番号は書かず、保管場所だけ残す |
| 3 | 持ち物を4つに仕分ける | 写真や手紙は最後に、親と一緒に |
| 4 | 住まいのエンディングノートを書く | 親が自分で、書ける所から書く |
| 5 | 住まいの将来を家族で考える | 売る・貸す・壊す・住み続けるを比べる |

## この記事で分かること

- 親が元気なうちに始める、実家じまいの進め方
- 持ち物の仕分け基準と、書類・連絡先の整理の仕方
- 新潟県・長岡市が案内している「住まいのエンディングノート」
- 長岡市・新潟市の、見守りと相談の窓口

実家じまいは、親が亡くなってから始めると、急ぐ作業になります。親が元気なうちなら、親の意思を聞きながら、時間をかけて進められます。

結論から言います。**先に決めるのは「何を捨てるか」ではなく、「親がどうしたいか」です。** 片付けは、そのあとです。

この記事の進め方の部分は、一般的な考え方です。制度や数字は、公的機関のページにあるものだけを使っています。税や法律の個別判断は、専門家に相談してください。

## 生前整理と、亡くなったあとの実家じまいの違い

一般的な違いは、次のとおりです。

| | 親が元気なうち | 親が亡くなったあと |
|---|---|---|
| 決める人 | 親本人 | 相続人の全員 |
| 家の物 | 親のもの | 相続の対象 |
| 進め方 | 親の意思を聞きながら、時間をかける | 相続の手続きと並行して進める |

## なぜ「元気なうち」なのか

親が亡くなったあとは、手続きに期限や条件が出てきます。公的機関のページにある例です。

- **相続登記**は、2024年4月1日から義務化されました。不動産を相続で取得したと知った日から3年以内に、申請します（法務省）。
- **遺言書**は、封印されているものを、勝手に開けられません。家庭裁判所で、相続人などの立会いのもとで開封する手続き（検認）があります（裁判所）。
- **相続人が複数**の場合、遺産の分け方は全員の話し合いで決めます。まとまらないときは、家庭裁判所の調停があります（裁判所）。

親が元気なうちにだけできることもあります。

- **任意後見制度**は、本人が判断能力のある段階で、公証人の面前で契約を結ぶ制度です（法務省）。
- **自筆証書遺言書保管制度**は、自筆の遺言書を法務局が保管します。この制度を使うと、家庭裁判所の検認が不要になります（法務省）。

どちらも本人の意思が前提です。使うかどうかは、親自身が決めます。司法書士や公証役場、法務局に、相談できます。

## 1. 親の意思を聞く

最初の話し合いが、いちばん難しい部分です。ポイントは、次のとおりです。

**「片付けて」と言わない。** 「家をどうしたいか」「困ったときはどうしたいか」と、親の考えを聞きます。親にとって、家は思い出の場所です。片付けを迫られると、拒みたくなります。

**聞く内容を、3つに分ける。**

1. **住まい**：この先も住み続けたいか。子の近くや施設に移る可能性は
2. **持ち物**：残したい物、誰かに譲りたい物は
3. **万一のとき**：病気や介護が必要になったら、どうしたいか

**一度で決めない。** 帰省のたびに、1つだけ聞きます。答えが変わっても、構いません。

**きょうだいにも共有する。** 親の意向を、全員が同じように知っておくと、あとで揉めにくくなります。

**親の了解なしに、処分しない。** 元気なうちは、家の物は親のものです。

## 2. 書類と連絡先を見える化する

次に、親の持っている書類と連絡先を、一覧にします。亡くなったあとに「どこにあるか分からない」となると、探すのに時間がかかります。

一覧に入れる項目の例です。

| 分類 | 項目の例 |
|---|---|
| お金 | 預貯金の口座、保険、借入、ローン |
| 年金・医療 | 年金の種類、健康保険、介護保険、かかりつけ医、服用中の薬 |
| 不動産 | 登記の名義、固定資産税の納税通知書、土地・建物の権利に関する書類 |
| 契約 | 電気・ガス・水道、携帯電話、インターネット、新聞、サブスク |
| 連絡先 | 親戚、友人、近所の人、菩提寺、緊急の連絡先 |
| 遺言・意向 | 遺言書の有無と保管場所、希望する葬儀や供養 |

**暗証番号やパスワードは、書き込まず、保管場所だけ**にするのが安全です。

**不動産は、名義を確認します。** 登記の名義が、すでに亡くなった祖父母のままの場合があります。法務省のページによると、2024年4月1日より前に相続した不動産も、2027年3月31日までに登記が必要です。名義の整理は、司法書士に相談できます。

年金を受けている人が亡くなったときは、届出が必要です。日本年金機構のページによると、提出が遅れると、受け取りすぎた年金を後から返す場合があります。必要な手続きを、一覧に書いておくと、残された家族が動きやすくなります。

## 3. 持ち物を仕分ける

仕分けは、次の4つに分けます。

| 分類 | 内容 | 進め方 |
|---|---|---|
| 残す | 親が今も使う物、大切な物 | 親が決める |
| 譲る・売る | 家族や知人に譲る物、売れる物 | 家族に希望を聞く |
| 手放す | 使っていない物、壊れた物 | 親の了解を取ってから出す |
| まだ決めない | 迷う物 | 箱にまとめ、期限を決めて見直す |

**順番が大事です。**

1. 明らかなごみから（古い食品、壊れた物）
2. 使わない家具・家電
3. 衣類、食器、本
4. 写真、手紙、思い出の品（**最後に、親と一緒に**）

**写真や手紙は、急がない。** 手が止まりやすい分類です。親の気持ちを優先して、最後に回します。

**出し方は、市の制度を使います。** 新潟市の粗大ごみは、品目ごとに100円〜500円です。長岡市は、200円〜1,000円です。料金は、各市の記事にまとめています。

- [新潟市の粗大ごみの出し方｜料金一覧・申込方法・持ち込み先](../niigata-shi-sodaigomi/)
- [長岡市の粗大ごみの出し方｜申込・料金・持ち込み先・分別Q&A](../nagaoka-shi-sodaigomi/)

**「無料回収」の業者には注意**が必要です。家庭のごみの収集運搬には、市町村の許可が必要です。環境省は、許可のない回収業者を使わないよう呼びかけています。業者に頼む場合の分かれ目は、[自分で出す？業者に頼む？新潟の実家片付け、分かれ目の5つの基準](../jibun-de-dasu-ka-gyousha-ka/) をご覧ください。

家電リサイクル法の対象の4品目（エアコン、テレビ、冷蔵庫、洗濯機・衣類乾燥機）は、市の粗大ごみでは出せません。新潟市のページによると、販売店の引き取りか、指定の引き取り場所への持ち込みになります。

## 4. 住まいのエンディングノートを書く

エンディングノートは、自分の考えを、家族に伝えるためのノートです。

**住まいについては、公的機関が作ったノートがあります。**

| 提供元 | 内容 |
|---|---|
| 新潟県 | 「住まいのエンディングノート」。全国空き家対策推進協議会が作成。県のホームページからPDFをダウンロードできる（2024年10月8日更新） |
| 長岡市 | 市が作成した簡易版のPDF。より詳しく書ける国土交通省版も案内している |
| 新潟市 | 「住まいのエンディングノート」を作成し、各区役所や公民館などで配布していると案内。市のサイトには令和8年度版（全15ページ、2026年4月1日更新）のPDFがある。 |

目的は、住まいの将来を早いうちに整理して、家族に伝えることです。長岡市は、放置空き家の発生を防ぐために、建物や土地の所有状況、将来の活用方法などを書いてもらう、と説明しています。

新潟県のノートの内容は、次の2つです。

1. 所有者や家族の状況と、不動産情報の整理
2. 住まいの将来の選択肢（売る・貸す・所有する）と、相続の手続き

**書き方のコツ**です（一般論）。

- **書ける所から書く。** 最初から、全部を埋めない。
- **親が自分で書く。** 子が代筆すると、親の意思でなくなる。
- **家族みんなで見る。** 書いたことを、きょうだいにも伝える。
- **暗証番号は書かない。**

**エンディングノートは、遺言とは別のものです。** 財産の分け方を確実にしたい場合は、遺言の制度を使います。司法書士や公証役場、法務局に相談できます。

## 5. 住まいの将来を決める

親の意思を聞いたら、実家の将来を、家族で考えます。

| 選択肢 | 向く場合 | 読む記事 |
|---|---|---|
| 住み続ける | 親が住み続けたい。当面は住める | 冬の雪対策や見守りの準備を進める |
| 売る・貸す | 将来、誰も住まない | [新潟の実家が空き家になったら](../akiya-uru-kasu-kowasu/) |
| 空き家バンクに登録 | 売る・貸すを考えている | [長岡市の空き家バンク](../nagaoka-akiya-bank/) |
| 壊す | 老朽化が進んでいる | [市町村の補助金一覧](../jikkajimai-hojokin-niigata/)を確認（着工前の申請） |

新潟では、**冬の雪**も計画に入れます。親が高齢になると、屋根の雪下ろしは大きな危険になります。新潟県のページによると、令和6年度の除雪作業による人的被害は137件でした。死亡事故の多くは、一人作業中に起きています。詳しくは、[冬の実家じまいと雪対策](../fuyu-no-jikkajimai-yukioroshi/) をご覧ください。

## 親が話を聞いてくれないとき

- **期限を切らない。** 「今年中に」と迫らない。
- **目的を変える。** 「片付け」でなく、「冬の安全」「万一のときの連絡先」を話題にする。
- **第三者を入れる。** 地域包括支援センターなど、公的な窓口に一緒に相談する。
- **一部だけ進める。** 書類の一覧だけでも、作る。

## よくある質問

### 親が元気なうちに実家じまいを始める意味は何ですか？

親の意思を聞きながら、時間をかけて進められることです。亡くなったあとは、相続登記の期限や、相続人全員の話し合いなど、動かせない手続きが出てきます。

### 親が片付けを嫌がるときは、どうしますか？

期限を切らず、目的を変えます。「片付け」ではなく、「冬の安全」や「万一のときの連絡先」を話題にします。地域包括支援センターなど、公的な窓口へ一緒に相談する方法もあります。

### 住まいのエンディングノートは、どこで手に入りますか？

新潟県と長岡市は、ホームページからPDFを入手できます。新潟市は、各区役所や公民館などで配布していると案内しています。

### エンディングノートがあれば、遺言は要りませんか？

別のものです。財産の分け方を確実にしたい場合は、遺言の制度を使います。司法書士や公証役場、法務局に相談できます。

### 遺言書を法務局に預けることはできますか？

自筆証書遺言書保管制度があります。法務局が保管し、家庭裁判所の検認が不要になります。使うかどうかは、親自身が決めます。

### 実家の名義が、祖父母のままだったらどうしますか？

2024年4月1日より前に相続した不動産も、2027年3月31日までに相続登記が必要です。名義の整理は、司法書士に相談できます。

### 遠方に住む親の見守りは、どうすればよいですか？

長岡市の「安心連絡システム」と、新潟市の「あんしん連絡システム」があります。対象や費用の条件があります。市の窓口へ確認してください。
