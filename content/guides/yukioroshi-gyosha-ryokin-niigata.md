# 新潟の雪下ろし・除雪を頼むときの料金と、業者・依頼先の探し方

## 結論：公的な料金の目安は見当たりません。公表されている単価は「上限」と「助成額」です

新潟県と各市町村の公式ページでは、屋根の雪下ろしの料金相場は見つかりませんでした。業者の料金表を公式に載せている自治体も、確認できていません。

公的に読める金額は、次の3種類です。

- 上越市が災害救助法の適用時に決める、見積りの上限単価（人力除雪は1人1時間4,000円、税込）
- 市町村が出す助成の上限額（長岡市の屋根除雪は1回24,300円まで、など）
- 魚沼市の除雪援助で、対象世帯が払う利用者負担（作業員1人1時間500円）

どれも、ふだんの業者料金の相場ではありません。料金は、複数の事業者から書面の見積りを取って比べます。

頼み先は、市町村の除雪相談窓口、シルバー人材センター、地域の建設業者、社会福祉協議会などです。助成は、いま住んでいる世帯向けが中心です。空き家の場合は [空き家の雪下ろし、誰に頼む？費用は？](../akiya-yukioroshi-hiyou-gyosha-niigata/) を先に読んでください。

この記事は、県・市町村・国の機関・シルバー人材センター・社会福祉協議会の公式ページだけで書いています。業者のサイトや比較サイトの料金は使っていません。業者の推薦もしません。公式で確認できなかったことは「[要確認]」と書きます。

## 雪下ろしの料金：公的に確認できた単価と助成額

公式ページに載っている金額は、2種類に分かれます。どちらも「上限」「負担額」「助成」の金額です。業者の料金の相場ではありません。

### 災害救助法の適用時に、上越市が定める見積りの上限

次の表は、上越市の単価表の金額です。災害救助法による除雪費助成で、見積りを出す側が守る上限です。業者の料金の相場ではありません。

| 項目 | 上限額（税込） |
|---|---|
| 人力除雪 | 1人1時間あたり4,000円 |
| バックホウ（運転手付き） | 平積0.08㎥級で8,690円から、0.80㎥級で16,170円まで（1時間あたり）。移送料は機種と距離で、見積りで決める |
| ダンプトラック（運転手付き） | 2t積で8,140円から、12t積で16,060円まで（1時間あたり） |
| 小型除雪車（ガソリン式、運転手付き） | 4kW級で13,200円から、22kW級で27,610円まで（1時間あたり）。移送料は片道8,140円 |

単価表のほかに、ディーゼル式の小型除雪車と除雪ドーザの区分もあります。[要確認: 単価表の年度（PDFに記載なし）。最新の単価は市に確認してください]

これは、国の救助法が適用された大雪のときの単価です。ふつうの冬の依頼に当てはまるかは、分かりません。同市のページによると、災害時の助成は母屋の屋根雪と玄関前が対象です。

次の表は、世帯向けの援助や助成の金額です。「対象世帯が払う額」や「助成の上限」で、業者の料金の相場ではありません。

| 項目 | 金額 | 何の金額か |
|---|---|---|
| 魚沼市 屋根雪等の除雪 | 作業員1人1時間あたり500円 | 除雪援助の対象世帯が払う利用者負担。市の補助は、一冬で32〜48時間まで（地域で違う）。超えた分は全額自己負担 |
| 長岡市 屋根の除雪 | 1回24,300円まで（令和8年度） | 要援護世帯への助成の上限。年3回（積雪の多い地域は4回） |

| 見附市社会福祉協議会 | 1回10,000円（年2回） | 70歳以上の一人暮らしや高齢者のみの要援護世帯。課税収入の制限あり |
| 上越市シルバー人材センター 玄関前除雪 | 2,300円から（単位の記載なし） | センターの料金表（令和8年4月1日現在）。屋根の雪下ろしの記載なし |

どの金額も、年度で変わります。申込の前に、市の窓口か公式ページで最新を確認してください。

### 上限単価で計算してみる

人力除雪で3人が3時間働くと、延べ9時間です。上越市の上限4,000円で計算すると、36,000円です（4,000円×9）。

これは、災害時の上限で計算した算数です。実際の見積りがこの額になるとは限りません。

重機やダンプを使うときは、別に時間単価と移送料がかかります。見積りで、人力か重機か、排雪まで含むかを分けて確認してください。

## 料金が変わる要素

公式ページが挙げている要素です。

- **屋根の形状・面積、作業時間、排雪方法**：関川村のページは、費用はこれらで異なると案内しています
- **場所、条件、積雪状況、業者**：加茂市のページは、これらにより料金は異なると案内しています
- **人力か重機か**：上越市の単価表は、人力、バックホウ、ダンプ、小型除雪車で単価を分けています。移送料は別に決めます
- **重機が入るか**：国民生活センターは、重機が入るかなど、別料金の有無を確認するよう助言しています

屋根の高さや軒の出、安全対策の手間は、一般に作業の難しさに関わります。ただし、料金への影響は公式ページに書かれていません。

| 民生委員（助成の申込先） | 長岡市の協力業者名簿は、民生委員にだけ配られる。上越市と見附市社協の助成も、民生委員を通じて申し込む | 一般の方は名簿を見られない（長岡市） |

## 雪下ろしの助成：使えるか、どこで確認するか

助成は、市民税が非課税か均等割のみの高齢者世帯などが対象の制度が中心です。対象は、いま、その家に住んでいる世帯です。

30市町村の対象世帯の条件、助成額、期限、空き家が対象かどうかは、[新潟県30市町村の雪下ろし・除雪支援一覧](../yukioroshi-shien-niigata-30/) にまとめています。同記事では、助成を確認できた20市町村のうち14が、居住や生活の本拠を条件にしています（確認日は2026年10月3日）。

新潟市は、西区の除雪助成が団体向けです。市全域の個人向け助成は、同記事の調査では確認できませんでした。

助成額は、業者の料金の全額をまかなう保証がありません。上の表の金額は、あくまで上限です。

## 安全：屋根に上がる前に知っておくこと

新潟県は、令和6年度の雪下ろし等の除雪作業による人的被害は137件と案内しています。死亡事故の多くは、一人での作業中に起きています。事故の多くは、屋根やハシゴからの転落が原因です。

県は、2人以上で作業し、ハシゴを固定し、ヘルメットや命綱などの安全対策をするよう求めています。長岡市は、無理をせず、必要に応じて専門業者へ依頼するよう案内しています。

慣れていない方が、帰省のついでに屋根に上がるのは避けてください。業者に頼む判断は、命を守る判断でもあります。注意点の詳細は、[空き家の雪下ろしは誰の責任？新潟の実家の冬対策](../fuyu-no-jikkajimai-yukioroshi/) にあります。

### 命綱アンカーの設置補助

命綱固定アンカーの設置を、特別豪雪地帯のある市町村が支援するとき、県が費用の一部を市町村に補助します（新潟県の案内）。令和8年度は、16市町村が補助制度を実施しています。

補助率や上限、対象となる住宅は、市町村で違います。対象を、居住している住宅に限る市町村もあります。一覧は [新潟県30市町村の雪下ろし・除雪支援一覧](../yukioroshi-shien-niigata-30/) にあります。

アンカーがある屋根は、業者も作業しやすくなります。十日町市の作業費補助も、取付設備のある住宅が対象です。

## 頼むタイミング：積雪の目安と、予約の時期

新潟県は、雪下ろしの時期の目安を、木造住宅で屋内建具の開閉がスムーズでなくなったときと示しています。雨が降ると雪が重くなり、見た目より重いことがあります。積雪表示板がある建物は、その設計積雪量が目安です。

遠方からは、建具の開閉を確認できません。近所の方や親族に、様子を聞く方法を決めておくと安心です。目安の詳細は、[空き家の雪下ろしは誰の責任？新潟の実家の冬対策](../fuyu-no-jikkajimai-yukioroshi/) にあります。

### 予約が埋まる時期

予約が埋まる時期を示す公式の資料は、見つかりませんでした。[要確認: 予約が埋まりやすい時期（公式な統計や案内は確認できず）]

公式ページから分かることは、次の3つです。

- 関川村のページは、降雪量によって依頼が業者に集中すると、すぐに対応できない可能性があると案内しています
- 加茂市のページは、各事業所が道路の除雪作業等も行っているため、すぐには対応できない場合があると案内しています
- 助成や補助には、期限があります。長岡市の助成登録は12月9日、十日町市の作業費補助は12月25日です（いずれも令和8年度）

雪が積もってから探すと、断られることもあります。雪の前に、見積りを取って、頼む先を決めておくのが安全です。

## 県外に住む家族が頼むときの段取り

雪が降る前に進める順番です。次の順番は、公式ページの内容をもとにした当サイトの整理です。

1. **まず、親の家の状況を整理する**。住んでいる家か、空き家か。助成は、住んでいる世帯向けが中心です。空き家なら、[空き家の雪下ろし、誰に頼む？費用は？](../akiya-yukioroshi-hiyou-gyosha-niigata/) を読みます
2. **市町村の除雪相談窓口に、状況を伝える**。県の一覧（令和7年度）に課名と電話があります。助成の対象か、民生委員への連絡が要るかを確認します。[要確認: 県外在住の親族が、助成を代理で申請できるか]
3. **事業者から、書面の見積りを取る**。作業内容、料金体系、重機の別料金を確認します。作業が終わらなかったときと、設備を壊したときの対応も聞きます（国民生活センターの案内）
4. **事前の打ち合わせを済ませる**。上越市は、助成の依頼の前に、方法と費用を打ち合わせるよう案内しています
5. **立ち会える人を決める**。国民生活センターは、事業者とやり取りするときや作業のとき、家族や周りの人に立ち会ってもらうよう勧めています。近所の方や親族に頼みます
6. **契約書と領収書を保管し、作業日時を記録する**。助成を申請するときにも使います。三条市社協は、領収書の写しの提出を求めています

県外にいると、屋根の雪の重さを自分では確認できません。雪の前の段取りは、[遠方・県外から新潟の実家を片付ける段取り](../enpou-kara-jikkajimai/) にもあります。冬の前の点検は、[空き家の冬支度チェックリスト（新潟版）](../akiya-fuyu-kanri-checklist/) にあります。

## 見積り・契約のトラブルを避ける

国民生活センターは、2024年12月5日に、除雪・排雪サービスの注意を公表しています。事例は、自宅横の除排雪と車庫の屋根の雪下ろしを頼んだ70歳代の方の相談です。現地で「全部で約7万円」と言われて依頼し、2日間の作業後に「約12万円」と言われました。

同センターの、トラブルを避けるための助言を整理します。

| 確認すること | 内容 |
|---|---|
| 作業内容を分ける | 「雪下ろし」「除雪」「排雪」のどれを頼むのかを、見積りに書いてもらう |
| 料金体系 | 料金の決まり方を確認し、書面でもらう |
| 別料金 | 重機が入るかなど、別料金が発生するか |
| 終わらなかったとき | 作業が完了できなかった場合の対応 |
| 破損したとき | 作業で自宅の設備が壊れた場合の対応 |
| 書面と記録 | 契約書・領収書を保管し、作業に来た日付などを記録する |
| 立ち会い | 一人で対応せず、家族や周りの人に立ち会ってもらう |
| 事前の情報収集 | 急な大雪の前に、サービスの内容と料金の情報を集めておく |

困ったときは、消費者ホットライン188か、お住まいの自治体の消費生活センター等に相談できます。

## よくある疑問

### 雪下ろしの料金は、いくらですか？

公的な相場は、確認できませんでした。公式に分かる金額は、上越市が災害救助法の適用時に定める人力除雪の上限（1人1時間4,000円、税込）などです。通常の料金ではありません。複数の事業者から、書面の見積りを取ってください。

### 雪下ろしの業者や代行は、どう探せばよいですか？

県は、市町村の除雪相談窓口の一覧を公開しています。燕市は、建設業協同組合が受ける相談窓口を設けています。上越市、関川村、加茂市は、事業所や受託業者の一覧を公開しています。シルバー人材センターは、玄関前の除雪が中心で、屋根に対応するかは、センターごとに違います。依頼前に、そのセンターへ確認してください。

### 雪下ろしの費用に、助成は使えますか？

市民税が非課税か均等割のみの、高齢者世帯などが対象の制度が中心です。長岡市は屋根1回24,300円まで、上越市は1世帯126,000円まで（通常期）です。空き家には使えないことが多いので、窓口で状況を伝えて確認してください。

### 雪下ろしを頼むのは、いつがよいですか？

雪が積もる前に、見積りと依頼先を決めておくのが安全です。県の目安は、木造住宅で、屋内の建具の開閉がスムーズでなくなったときです。降雪が多いと、依頼が集中して、すぐに対応できないことがあります（関川村）。

### 見積りより高い額を請求されたら、どうすればよいですか？

国民生活センターは、約7万円と言われた作業で約12万円を請求された事例を公表しています。困ったときは、消費者ホットライン188か、自治体の消費生活センターに相談できます。作業の前に、書面の見積りと、別料金の有無を確認しておくことが大切です。
