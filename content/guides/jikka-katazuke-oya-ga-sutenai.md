# 実家の片付けで親が捨てない・怒るとき｜本人の意思を尊重して進める段取りと、公的な相談先

## 結論：物は親のものです。親が決める形で、小さく進めます

親が物を捨てない理由は、ひとつに決められません。本人に聞かないと分かりません。家族が代わりに捨てると、親が怒って、話が止まることがあります。進め方の基本は、物の持ち主である親が決める形にすることです。範囲を小さくし、迷う物は保留にします。怒ったら、その日は止めて構いません。親の判断力や安全面が心配なときは、地域包括支援センターに相談できます。新潟市と長岡市の窓口は、後半で案内します。

この記事は、心理学的な原因を断定するものではありません。公式情報と一般的な進め方を整理しています。内容は2026年10月3日の確認時点です。

この記事で分かること

- 親が捨てないときの、本人の意思を尊重した進め方
- 親が怒ったときの対応と、中断してよい目安
- 新潟市・長岡市の地域包括支援センターなど、公的な相談先

## 早見表：状況と相談先

| 状況 | まず頼れる窓口 |
|------|------|
| 物が多く、通路や階段が危ない | 地域包括支援センター |
| 物忘れや判断力が心配 | 地域包括支援センター |
| 見知らぬ業者が来て、物を買い取られた | 消費者ホットライン188 |
| 重い物を出せない | 新潟市のごみ出し支援事業など |
| 離れて暮らしていて安否が心配 | 市の見守りや安心連絡システム |
| 金銭管理や契約が心配 | 新潟市の成年後見支援センターなど |

## 親が捨てない理由は、本人に聞いて分かります

### 理由を決めつけません

「もったいないから」「思い出があるから」と、家族が理由を決めると、親は反発することがあります。理由は人によって違います。聞いてみないと分かりません。

聞くときは、責める言い方を避けます。次のような聞き方があります。言い方の例です。

- 「この棚で、いちばん大事な物はどれ？」
- 「困っていることはある？ 探し物とか、掃除とか」
- 「この家で、これから先も使いたい物を教えて」

答えが返ってこなくても、急がないでください。答えが出るまで、日をあけて構いません。

### 片付けの目的を、親と共有します

目的が「家族が楽になる」だけだと、親は自分が否定されたと感じるかもしれません。目的を、親の困りごとに合わせます。

- 転びやすい場所をなくして、安全に暮らす
- 探し物を減らして、生活を楽にする
- 将来、家族が困らないように、書類の場所を決める

親が元気なうちの話し方は、[親が元気なうちに始める実家じまい](../jikkajimai-oya-ga-genki-na-uchi/)にまとめています。

## 本人の意思を尊重して進める段取り

次の順番は、一般的な進め方の一例です。親の様子に合わせて、変えてください。

### 1　小さい範囲から始めます

家全体は、最初から手をつけません。引き出し1つ、玄関の靴箱、洗面所の棚など、1か所を選びます。親が「ここならいい」と言った場所から始めます。

安全に関わる場所を先にする方法もあります。通路、階段、暖房器具の周りです。転倒やけがにつながりやすい場所と考えられます。

### 2　親が「残す」「迷う」「手放す」を決めます

物を3つに分けます。決めるのは親です。家族は、運ぶ、拭く、袋に入れる、といった手伝いを担当します。

- 残す：今も使う物、大事な物
- 迷う：決められない物。保留にします
- 手放す：親が自分で「いらない」と決めた物

「迷う」の箱は、期限を決めずに置いても構いません。次回の帰省で、もう一度見ます。

### 3　出す手間は、家族が引き受けます

親が手放すと決めた物は、家族が市のルールで出します。粗大ごみの申込、処理券、持ち込みなどです。手間が減ると、親の「決める」負担が軽くなります。

新潟市と長岡市の出し方は、[新潟市の粗大ごみの出し方](../niigata-shi-sodaigomi/)と[長岡市の粗大ごみの出し方](../nagaoka-shi-sodaigomi/)にあります。

### 4　勝手に捨てません

親が見ていない間に捨てるのは、避けます。信頼を失うと、その後の片付けが進みにくくなります。

法的な面でも、注意があります。相続が絡む物、権利証、通帳、契約書は、本人が元気なうちに場所を確認します。[実家じまいでやってはいけない7つのこと](../jikkajimai-yattewaikenai/)も参考にしてください。

### 5　1回の作業を短くします

長時間続けると、親も家族も疲れます。帰省のたびに、1か所ずつ進めます。

## 親が怒ったときの対応

### その日は、中断して構いません

親が怒ったときは、片付けを止めます。説得を続けても、状況が悪くなる可能性があります。

- 「分かった。今日はここまでにしよう」と、作業を止めます。
- 話題を変えて、お茶を飲むなど、気持ちを落ち着かせます。
- 後日、別の形で話し直します。

### 別の人から話してもらう方法もあります

家族が話すと衝突する場合は、第三者に入ってもらう方法があります。きょうだい、親しい親戚、かかりつけ医、地域包括支援センターの職員などです。ただし、本人の意思に反して、第三者が物を処分することは避けます。

### 怒りやすくなった、物忘れが増えたと感じるとき

以前と様子が違うと感じたときは、地域包括支援センターに相談できます。同じ物を何度も買う、置き場所を忘れる、といった変化です。認知機能や身体機能の低下についての相談を受け付けています。

## 公的な相談先

### 地域包括支援センター（新潟市）

新潟市には、30の地域包括支援センターがあります。それぞれが、1つまたは複数の中学校区を担当します。保健師、主任ケアマネジャー、社会福祉士などが配置されています。

相談できる内容は、介護保険サービスの利用方法、認知機能や身体機能の低下への不安などです。高齢者虐待や成年後見制度などの権利擁護も扱います。

担当するセンターは、新潟市の一覧ページで探せます。問い合わせ先は、福祉部 地域包括ケア推進課です（025-226-1281）。

### 地域包括支援センター（長岡市）

長岡市には、11か所の地域包括支援センターがあります。高齢者に関する公的な相談窓口です。

高齢者の相談に応じ、希望すれば訪問もします。消費者被害や虐待の相談、介護保険や認知症に関する相談も受け付けています。

担当地区別の一覧は、長岡市のページにあります。全体の問い合わせ先は、長寿はつらつ課 高齢者基幹包括支援センターです（0258-89-7440）。

### 見守りと安否確認のサービス

離れて暮らす親の安否が心配なときの制度です。対象や費用は、市の公式ページで確認してください。

| 市 | 制度 | 内容 |
|------|------|------|
| 新潟市 | 高齢者等あんしん見守りネットワーク | 地域の住民や事業者が異変に気づいたとき、地域包括支援センターに連絡し、支援につなげます |
| 新潟市 | あんしん連絡システム | 24時間体制の受信センターに通報できる装置を貸与します。月額は0円・550円・1,100円です |
| 長岡市 | 安心連絡システム | 65歳以上のひとり暮らしの高齢者等が対象です。月額は500円・1,500円で、生活保護世帯は無料です |

新潟市のあんしん連絡システムは、要介護状態や慢性疾患のある人、65歳以上のみの世帯などが対象です。申込は、区役所、地域保健福祉センター、地域包括支援センターで受け付けています。

新潟市の見守りの案内には、異変に気づくポイントがあります。新聞や郵便物がたまっている、しばらく顔を見ていない、などです。

### 判断力が心配なとき

新潟市の福祉総合相談センターには、「あんしんサポート新潟」と「成年後見支援センター」があります。認知症や障がい等で判断能力が十分でない人の、福祉サービス利用の援助や金銭管理を支援します。契約や財産管理の相談も受けています。

### 重い物を出せないとき

新潟市には、高齢者・障がい者などのごみ出しが困難な世帯を対象にした「ごみ出し支援事業」があります。自治会などの団体が実施し、実施していない地域もあります。問い合わせ先は、廃棄物対策課（025-226-1407）です。詳しくは、[新潟市の粗大ごみの出し方](../niigata-shi-sodaigomi/)にあります。

長岡市のごみ出し支援は、今回の確認では見つかりませんでした。地域包括支援センターに聞いてください。

## 実家の片付けで、気をつけたい訪問業者

親が1人でいる実家に、突然業者が来ることがあります。消費者庁は、訪問購入に注意するよう呼びかけています。訪問購入とは、業者が家を訪ねて、貴金属やブランド品などを買い取るものです。

消費者庁の案内の要点は、次の3つです。

- 突然訪問してきた購入業者は、家に上げません。突然の訪問による買取りは、法律で禁止されています。
- 買取りを希望しない物は、見せません。
- 契約書面をよく確認します。書面を受け取ってから8日間は、物品を手元に残しておけます。

消費者庁の資料には、不要品の買取りと聞いていたのに、アクセサリーを強引に買い取られた事例があります。困ったときは、消費者ホットライン188に相談できます。お近くの消費生活相談窓口につながります。

親には、「知らない人が来たら、家に上げないで」と、事前に伝えておく方法があります。

## 家族や専門家に頼る線引き

| 状況 | 動き方 |
|------|------|
| 親は拒否していないが、家族が遠方にいる | 帰省の日に1か所ずつ進めます |
| 親は拒否するが、生活に危険は少ない | 無理に進めず、見守りを続けます |
| 物の山で、転倒や火の元が心配 | 地域包括支援センターに相談します |
| 判断力の低下が疑われる | 地域包括支援センターや成年後見支援センターに相談します |
| 親が了承し、量が多い | 許可のある業者への相談も選べます |

業者に頼むときの考え方は、[自分で出す？業者に頼む？](../jibun-de-dasu-ka-gyousha-ka/)にまとめています。全体の手順は、[新潟の実家じまいの手順](../jikkajimai-tejun-niigata/)を見てください。

## よくある質問

**Q　親が「まだ使う」と言って、何も捨てません。どうすればよいですか。**
理由を決めつけず、「いちばん大事な物はどれ？」と聞いてみます。範囲を小さくし、親が決める形にします。急ぐ必要がなければ、日をあけて続けます。

**Q　親が怒ったら、あきらめるしかありませんか。**
その日は中断して構いません。後日、別の形で話し直す方法があります。きょうだいや、地域包括支援センターなど、第三者に入ってもらう方法もあります。

**Q　親に黙って、不要そうな物を捨ててもよいですか。**
避けてください。物は親の持ち物です。親が手放すと決めた物だけ、家族が出す形にします。

**Q　新潟市の地域包括支援センターは、どこに相談すればよいですか。**
親が住んでいる地域を担当するセンターです。新潟市のページに、センター名と担当地域の一覧があります。分からない場合は、地域包括ケア推進課（025-226-1281）に問い合わせます。

**Q　長岡市の地域包括支援センターは、どこですか。**
長岡市内に11か所あり、担当地区ごとに分かれています。一覧は、長岡市のページにあります。全体の窓口は、長寿はつらつ課 高齢者基幹包括支援センター（0258-89-7440）です。

**Q　親が見知らぬ業者に、物を買い取られていました。**
消費者ホットライン188に相談できます。消費者庁の案内では、契約書面を受け取ってから8日間は、物品を手元に残しておけます。
