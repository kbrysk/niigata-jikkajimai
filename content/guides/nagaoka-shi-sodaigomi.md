# 長岡市の粗大ごみの出し方｜料金・申込・持ち込み・分別

## 結論：長岡市の粗大ごみは、事前申込で1回5点までです

長岡市の粗大ごみは、先に申し込みます。ネットとFAXは24時間です。料金は200円・600円・1,000円の3段階で、200円の処理券シールを1・3・5枚貼ります。持ち込めるのは中之島信条クリーンセンターだけで、前日までの電話が要ります。

実家を片付けると、たんすや布団、仏壇などが一度に出ます。この記事は、長岡市の公式情報だけでまとめました。内容は2026年10月2日の確認時点です。申し込む前に、公式ページで最新の情報を見てください。

- 申込方法と、処理券シールの使い方
- 実家じまいで出やすい品目の料金一覧と、2027年7月の改定報道

## 申し込み方法

粗大ごみは戸別収集です。事前に申し込みます。

| 方法 | 受付 |
|------|------|
| インターネット（電子申請） | 年中24時間 |
| FAX | 0258-25-0064。年中24時間 |
| 電話 | 0258-25-0053。月〜金 8:30〜17:00 |

ネットとFAXの受付後は、確認の連絡があります。メールやFAXを受け取れるようにしておきます。休日に申し込んだ場合、確認の連絡は休み明けです。

電話は、週明けにつながりにくくなります。つながらないときは、時間をおいてかけます。

申込時には、次の6つを伝えます。住所、氏名、電話またはFAX番号、品目、大きさ（縦・横・高さ）、数量です。

**1回に収集できるのは5点までです。**

受付のときに、品目ごとの金額と収集日が知らされます。品目一覧にない物の申込方法は、公式ページに記載がありません。[要確認: 品目一覧にない物の申込方法]

## 粗大ごみの手数料改定の報道（2027年7月案）

新潟日報は、2026年2月18日に次のように報じました。長岡市は、2027年7月に粗大ごみの処理手数料を改定する方針です。現行の200〜1,000円を、400〜2,000円に引き上げる案です。

布団や毛布など、出る量が多い物は引き上げ幅を抑えます。布団は、現行の1枚200円から2枚以内400円になる案です。

この内容は、市の公式ページには載っていません。市の粗大ごみのページ（2026年3月31日更新）は、現行の3段階だけを案内しています。[要確認: 市の公式発表と施行日]

この記事の料金表は、現行の金額です。改定が決まった場合は、公式ページの金額に従ってください。

## 収集日と出し方

収集日は、月〜金曜（祝日・振替休日・年末年始は除く）です。収集は8:30から夕方までで、時間の指定はできません。受付の数日後になります。混雑時は、受付後2週間程度かかります。引っ越しシーズンは、さらに遅れます。

出し方は次のとおりです。処理券シールを粗大ごみごとに貼ります。収集当日の8:30までに出します。

- 一戸建ては、玄関先の道路から見える所に出します。高床式の家は、階段下です。
- 集合住宅は、1階の入口付近に出します。処理券に収集日を書きます。
- 雨に濡れても大丈夫です。
- 留守でも収集します。家屋の中には入りません。

「粗大ごみがあれば収集に行きます」といった勧誘の電話は、市の収集とは関係がありません。

板類は、厚さ3cm・幅90cm・長さ2m以内に切ります。角材や丸棒は、太さ10cm・長さ2m以内に切ります。

## 自分で持ち込む場合

原則は、粗大ごみは戸別収集です。持ち込みができるのは、引っ越しなどでやむを得ず多量のごみが出たときに限られます。

| 項目 | 内容 |
|------|------|
| 施設 | 中之島信条クリーンセンター |
| 住所 | 長岡市中条新田1080-2 |
| 電話 | 0256-97-7260 |
| 受付 | 月〜土 8:30〜16:30（祝日・振替休日・年末年始は除く） |
| 料金 | 戸別収集と同額（200円・600円・1,000円） |
| 持ち方 | 処理券シールを貼って持ち込みます |
| 事前連絡 | 前日までに電話し、施設の確認を受けてから持ち込みます |

粗大ごみを受け入れる施設は、ここだけです。寿クリーンセンター（寿3-6-1）は、燃やすごみのみです。古い情報には「鳥越クリーンセンター」とあるものがありますが、市の現行ページに載る施設は、この2つです。

持ち込む前に、連絡して金額を確認するよう案内されています。

粗大ごみ以外のごみの持ち込み（指定袋なら無料、袋を使わない場合の重量料金）、寿クリーンセンターとの使い分け、持ち込めない物、年末年始の扱いは、別記事[長岡市のごみ持ち込み（自己搬入）](../nagaoka-shi-gomi-mochikomi/)にまとめています。

### 家電4品目の出し方

方法は2つあります。

1. 購入した家電販売店、または市のごみ収集運搬許可業者に収集を依頼します。収集運搬料金が別にかかります。
2. 指定引取場所へ自分で持ち込みます。郵便局で家電リサイクル券を買い、持ち込む前に連絡します。

指定引取場所は次のとおりです。

- （株）豊和商事（新組町2474-1、0258-24-6322）
- 日本通運（株）長岡指定取引所（要町1-4-44、0258-36-4400）。受付は9時〜16時（正午〜13時は除く）。祝祭日は休みです。土曜は問い合わせが必要です。

リサイクル料金は、主なメーカーで、エアコン990円、洗濯機・衣類乾燥機2,530円です。テレビは15型以下1,870円、16型以上2,970円です。冷蔵庫は170L以下3,740円、171L以上4,730円です。メーカーで異なります。

## 長岡市のごみ分別の基本（指定袋と収集日）

長岡市は、ごみと資源物を分けて出します。市の「ごみと資源物の分け方と出し方（保存版）」（2026年5月7日更新）にある区分は、次のとおりです。

- 燃やすごみ、生ごみ、燃やさないごみ、粗大ごみ
- プラスチック容器包装材、びん・缶・ペットボトル
- スプレー缶類・発火物・有害物、枝葉・草
- 新聞、雑誌・チラシ、段ボール、古着・古布

迷ったときは、市の「ごみの分け方出し方検索システム」で調べられます。収集日は、ごみカレンダーで確認します。

### 燃やすごみと燃やさないごみ

| 区分 | 収集 | 出し方 | 実家で出やすい物の例 |
|------|------|------|------|
| 燃やすごみ | 週1回 | 指定袋に入れ、収集日の8:30までに出す | 破れた衣類、汚れた紙、生ごみ |
| 燃やさないごみ | 月2回 | 同上。包丁や鏡は紙で包み「キケン」「ワレモノ」と書く | 食器、ガラス、小型の家電、ストーブ |

破れていない衣類は、古着・古布の収集日に出します。布団は、50cm四方に切るか、粗大ごみにします。

粗大ごみ処理券は、200円券だけが売られています。100円券は製造が中止され、在庫のみです。

## 分別で迷いやすい品目のQ&A

品目一覧（令和7年2月1日現在）と、ごみ分別表（令和6年4月作成のPDF）に基づきます。分別表は、市の保存版ページ（2026年5月7日更新）にも、令和6年4月版が載っています。

**Q1　布団は粗大ごみですか。**
1枚200円の粗大ごみです。50cm四方に切れば、燃やすごみに出せます。切らずに指定袋で出すと、処理施設の故障の原因になります。

**Q2　カーペットは。**
6畳未満は200円、6畳以上は600円です。50cm四方に切れば、燃やさないごみに出せます。

**Q3　毛布は。**
破れや汚れがなければ、古着・古布の収集日に出せます。粗大ごみなら、3枚以内で200円です。

**Q4　物干し台は。**
プラスチック製は2個以内で200円です。コンクリート製は、収集できません。許可業者へ依頼します。

**Q5　スプリング入りのマットレスは。**
収集できません。ソファー、ベッド、イスも同じです。市のごみ収集運搬業許可業者に頼みます。

**Q6　仏壇は。**
粗大ごみです。長辺90cm以下は600円、90cm超は1,000円です。備考欄に「供養はしない」とあります。指定袋に入るものは、燃やすごみです。

**Q7　神棚は。**
200円の粗大ごみです。指定袋に入れば、燃やすごみになります。

**Q8　ストーブの灯油は。**
灯油は抜き、電池は外します。指定袋に入るものは燃やさないごみです。入らないものは粗大ごみです。まき・ダルマストーブとオイルヒーターは、収集できません。

**Q9　灯油が残っているポリタンクは。**
灯油は、市では収集できません。販売店または取扱店に問い合わせます。ポリタンクは燃やさないごみです。大型のホームタンクは、許可業者へ頼みます。

**Q10　家電4品目やパソコンは。**
どちらも市では収集できません。上の案内に従います。

## 長岡市の実家で出すときの順番

長岡市は、1回の収集が5点までです。品物が多い実家は、申込を分けます。混雑時は、受付から収集まで2週間程度かかります。

1. 出す物を、品目と大きさでリストにします。たんす、食器棚などは、縦・横・高さを測ります。
2. 市で出せない物を分けます。スプリング入りの寝具、ピアノ、耐火金庫、家電4品目です。
3. 収集できる物を、5点ずつネットかFAXで申し込みます。確認の連絡を待ちます。
4. 200円の処理券シールを買い、金額の分だけ貼ります。
5. 収集日の8:30までに、玄関先の道路から見える所へ出します。

量が多いときは、中之島信条クリーンセンターへの持ち込みもあります。前日までに電話し、料金は戸別収集と同額です。

市の制度だけでは足りないことがあります。量が多い、市で扱わない物が多い、階段や積雪期で搬出が難しい、遠方で何度も通えない場合です。そのときは、市のごみ収集運搬許可業者に見積りを取る方法があります。許可業者は、[長岡市の一般廃棄物 許可業者一覧](../nagaoka-shi-kyoka-gyosha/)にまとめています。費用の目安は、[新潟で実家を片付ける費用の目安](../jikkajimai-hiyou-niigata/)です。

売れる物は、リユースも選べます。長岡市は「おいくら」と連携しています。再販できる物だけが対象です。売り方は、[長岡市のリサイクルショップ・出張買取](../nagaoka-recycle-shop/)で整理しています。

## 長岡市の粗大ごみ、よくある質問

**Q　長岡市の粗大ごみは、いくらですか。**

**Q　長岡市のごみは、指定袋を使わずに持ち込めますか。**
持ち込めます。100kgまで300円で、超えた分は10kgごとに30円です。指定袋なら無料です。

**Q　長岡市の粗大ごみは、値上がりしますか。**
報道では、2027年7月に400〜2,000円へ改定する案です。市の公式ページには、まだ載っていません。

**Q　長岡市で、スプリング入りのマットレスはどう出しますか。**
市では収集できません。市のごみ収集運搬業許可業者に頼みます。

**Q　長岡市のごみ分別で迷ったときは、どこで調べますか。**
