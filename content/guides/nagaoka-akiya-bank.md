# 長岡市の空き家バンク｜登録の流れ・探し方・家財処分や解体に使える支援

## 結論：市は「掲載と連絡調整」まで。交渉と契約は当事者です

長岡市の空き家バンクは、所有者から預かった売りたい・貸したい情報を、探している人に紹介する制度です。市は情報提供と連絡調整を行います。ただし、売買の交渉や契約の仲介は行いません。

市は、トラブルを避けるために不動産業者を仲介に入れることを勧めています。

制度は平成22年3月に始まりました。長岡市の空き家対策のページに書かれています。

## 所有者が登録するとき

### 登録できる物件の条件

市の「空き家物件登録」ページには、次の条件が書かれています。

- 個人所有の一戸建て住宅で、不動産登記がされている（併用住宅は可）
- 抵当権・根抵当権が設定されていない（仲介業者が決まっている場合は可）
- 売買の場合は、土地の地目が農地以外
- 周辺に迷惑をかけず、管理されている空き家
- 居住できる状態である

「居住できる状態」の具体的な基準は、公式ページには書かれていません。傷みが大きい家は、事前に市へ聞いてください。[要確認: 居住可能の判断基準]

相続登記が済んでいない家を登録できるかも、ページには書かれていません。[要確認: 相続登記前の物件の扱い]

なお、相続登記は令和6年4月1日から義務化されています。相続を知った日から3年以内に申請が必要です（上越市の空き家情報バンクのページにも、義務化の案内があります）。

### 登録の流れ（6段階）

1. **登録申込**：申込書に記入し、登記簿謄本の写しを付けて、窓口か郵送で出します。
2. **現地調査**：所有者と市の担当者で、間取り・設備・写真を確認します。
3. **台帳登録**：審査のあと、登録決定通知書が届きます。
4. **情報公開**：市のホームページ、担当窓口、住宅情報誌、移住・定住イベントなどで物件が紹介されます。
5. **内覧・交渉**：所有者と希望者が直接やりとりします。市は交渉に入りません。
6. **契約・成約**：契約したら、抹消届を出して完了です。

登録内容に変更があったときは、変更の届出が必要です。

### 必要書類

- 長岡市空き家バンク登録申込書
- 土地と建物の登記簿謄本の写し

### 費用と登録期間

登録に費用がかかるか、登録の有効期間があるかは、公式ページに書かれていません。[要確認: 登録料の有無] [要確認: 登録の有効期間]

売買や賃貸の仲介を不動産業者に頼むと、仲介手数料が別にかかるのが一般的です。金額や上限は、依頼する業者と契約書で確認してください。

## 物件を探す側の使い方

長岡市の空き家バンクの物件は、市の公式ページと、at home版のサイトの両方で見られます。at home版は、アットホーム株式会社が提供するサイトで、運営は長岡市の都市政策課です。

### 探し方

- 全件検索
- 地域から探す
- 売買物件だけ／賃貸物件だけで絞る

at home版では、沿線・エリア・地図からも探せます。

### 申込の流れ

1. 市の「空き家内覧・購入等申込」から、外部のフォームで申し込みます。
2. 申込は先着順で処理され、物件が紹介されます。
3. 物件の所有者と、直接交渉します。
4. 市は、契約に不動産業者を仲介するよう勧めています。

### 見るときの注意

市のページには、次の注意が書かれています。

- 状態が良くない物件もあります。
- 「商談中」の物件は紹介の対象外です。
- 表示されている価格は、土地と建物の合計です。ほかに仲介手数料や不動産登記費用なども必要です。

雪の多い地域については、市が冬期情報のページで注意しています。海岸側は積雪が少なく、中山間地域は多くなります。雪下ろしや除雪の負担が大きいので、冬の暮らしも考えるように書かれています。

## 空き家バンクに関係する補助

### 購入者向け：空き家バンク登録・成約促進事業補助金

空き家バンクの物件を買った人が、リフォームをするときの補助です。売る側（所有者）は使えません。令和8年度のお知らせには、次の内容があります。

| 項目 | 内容 |
|---|---|
| 申請期間 | 令和8年4月1日〜10月30日（郵送は当日消印有効） |
| 受付 | 先着順。予算がなくなり次第終了 |
| 補助額 | 対象工事費の1/2、最大80万円 |
| 内訳 | 基本額50万円。まちなか居住区域は+10万円。県外在住の購入者は+20万円。市外（県外を除く）は+10万円 |
| 対象工事 | 屋根・外壁、床・内装、台所・浴室などの水回り |
| 対象の空き家 | 空き家バンクの登録物件で、建築後10年以上（平成27年12月31日以前の建築） |
| 対象者の条件 | 購入後6か月以内の個人。購入後10年以上住む人。市税の未納がない人 |
| 施工業者 | 長岡市内に本社がある法人か、市内に住民記録がある個人事業主。購入者自身（や代表を務める会社）は対象外 |
| 実績報告の期限 | 令和8年12月25日 |

契約や工事の着手は、交付決定のあとです。先に始めると対象外になります。この補助は、住宅金融支援機構の【フラット35】地域連携型の対象でもあります。

この記事を読んでいる所有者の方は、買い手に使える制度があることを、売るときの説明に使えます。ただし、申請期間は2026年10月30日までです。使えるかどうかは、買い手が市に確認します。

### 家財処分と解体：長岡市の公式ページで確認できたこと

実家を空き家バンクに出す前には、家の中の片付けが必要です。解体も気になるところです。確認できたことは、次のとおりです。

- **家財道具の処分費**：所有者向けの補助は、長岡市の公式ページでは確認できませんでした。[要確認: 所有者向けの家財処分補助の有無]
- **解体費**：長岡市の空き家対策総合支援事業補助金は、特定空家等の除却で、補助の対象は町内会などの地域団体です。補助対象経費の4/5、上限160万円。跡地を地域活性化のために使う場合が対象です。個人の所有者が直接申請できる解体補助は、公式ページでは確認できませんでした。

同じ新潟県内でも、家財処分や解体に補助を出している市があります。上越市と、新潟市の西蒲区です。長岡市の方も、比べてみてください。

都市整備部 都市政策課 住宅政策担当に、活用・管理・解体などの相談ができます。各支所の地域振興・市民生活課でも相談できます（中之島、越路、三島、山古志、小国、和島、寺泊、栃尾、与板、川口の各支所）。

- 電話：0258-39-2265
- メール：toshisei@city.nagaoka.lg.jp

### 市と協定を結んでいる団体

長岡市は、空き家の悩みごとに別の団体とも協定を結んでいます。相談内容に合わせて選べます。

| 相談の内容 | 団体 |
|---|---|
| 相続・登記・成年後見 | 新潟県司法書士会 |
| 所有者・相続人の調査、行政手続 | 新潟県行政書士会 |
| 空き家・空き地の法的な問題 | 新潟県弁護士会（空き家・空き地相談センター） |
| 建物の表示登記・境界・測量 | 新潟県土地家屋調査士会 |
| 物件紹介・仲介・空き家の無料相談 | 新潟県宅地建物取引業協会 長岡支部 |
| 管理・除草・見守り | 長岡市シルバー人材センター |
| 解体の相談・費用見積もり | 長岡構造物解体協同組合 |

このほか、片付けから売却まで扱う団体も、市の一覧に載っています。電話番号などは、市の「空き家に関する相談窓口一覧」（PDF）で確認してください。

遠方で管理が難しい方には、ふるさと納税の返礼品があります。長岡市シルバー人材センターの、空き家・空き地の見守り・管理サービスです。各ふるさと納税サイトで「長岡市 空き家・空き地管理サービス」を検索します。

## まず何から動くか

1. 登記簿を確認し、名義を整理する。
2. 家の状態を見て、「売る・貸す・壊す」の方向を考える。
3. 都市政策課か、宅建協会の無料相談で、空き家バンクに向くか聞く。
4. 登録するなら、家財の片付けの段取りを決める。
