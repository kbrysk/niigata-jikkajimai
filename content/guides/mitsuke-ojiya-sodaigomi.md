# 見附市・小千谷市の粗大ごみの出し方｜制度が違う2市を比較

見附市は、電話で申し込む戸別収集です。処理券は大990円・中660円・小330円で、1回5個までです。小千谷市は、戸別収集がありません。重さで決まる料金で、処理場へ自分で持ち込みます。

## この記事で分かること

- 見附市は電話で申し込む戸別収集、小千谷市は戸別収集がなく処理場へ持ち込む、という違い
- 実家じまいで出やすい品目の料金と分別（公式の早見表・分別一覧より）
- 持ち込み先と受付時間、市で出せない物

2市は、仕組みがまったく違います。この記事は、両市の公式情報だけでまとめました。内容は2026年10月2日の確認時点です。申し込む前に、公式ページで最新の情報を見てください。

## 結論の早見表

| 項目 | 見附市 | 小千谷市 |
|------|--------|----------|
| 戸別収集 | あり（事前申込制） | なし |
| 申込 | 収集日の1か月前〜1週間前までに電話 | 不要。身分証を持って処理場へ |
| 料金 | 処理券 大990円・中660円・小330円 | 重量制。可燃は100kg以下300円、不燃は20kg以下100円 |
| 収集日 | 行政区ごとの曜日（月〜金） | 10kg・2m以内の不燃粗大ごみだけ「埋立ごみの日」に出せる |
| 持ち込み先 | 見附市清掃センター（限られた場合のみ） | 時水清掃工場、クリーンスポット大原 |
| 持ち込み受付 | 月〜金 9:00〜16:00、土 9:00〜12:00 | 月〜金 8:30〜16:00、土 8:30〜11:00 |

## 申し込み方法

### 見附市

事前申込制の戸別収集です。ネット申込は、公式に記載がありません。

| 項目 | 内容 |
|------|------|
| 申込 | 収集指定日の1か月前から1週間前までに、電話 |
| 伝えること | 住所、氏名、電話番号、品目、数量 |
| 点数 | 1回の収集につき5個まで |
| 申込先 | 市指定の収集運搬業者。毎年3月発行の家庭ごみカレンダーの「粗大ごみ」欄で確認 |
| 受付時間 | 月〜金 8:30〜17:00（土日祝・年末年始を除く） |

令和8年度の申込先は、（株）高橋産業 0258-66-8688 です。令和8年度の家庭ごみカレンダーの「ごみの出し方」に載っています。

粗大ごみの条件は、指定袋に入らない物で、最長辺2m未満、重さ60kg未満です。鉄アレイやダンベルなど、指定袋に入っても粗大ごみになる物があります。

### 小千谷市

粗大ごみの申込制の戸別収集は、ありません。申込も不要です。処理場へ、自分で運びます。

自分で運べないときは、市の許可業者（有料）に頼みます。

## 料金の仕組みと品目別料金

### 見附市

粗大ごみ処理券は、大990円、中660円、小330円（運搬費・消費税込み）です。令和8年8月1日以降の価格です。

申込のときに、金額を知らされます。その金額の券を買って、粗大ごみごとに貼ります。券は、スーパー、コンビニ、ドラッグストア、ホームセンターなどで買います。市役所、収集業者、清掃センターでは売っていません。

### 小千谷市

品目別の料金表は、公式にありません。重さで決まります。

| 出し方 | 料金 |
|--------|------|
| 可燃粗大ごみを時水清掃工場へ | 100kg以下300円。超えると10kgごとに30円 |
| 不燃粗大ごみをクリーンスポット大原へ | 20kg以下100円。超えると10kgごとに50円 |
| 10kg・2m以内の不燃粗大ごみを収集場所へ | 処理券1枚100円、または埋立ごみの指定袋 |

直接搬入のときは、指定袋と処理券を使いません。

## 収集日と出し方

### 見附市

収集日は、行政区ごとの曜日です。月曜から金曜までで、土日祝と年末年始を除きます。たとえば、本町・新町は月曜、学校町・本所は火曜、今町1〜7丁目は金曜です。全行政区は、市のページで確認します。

当日の早朝から朝8時までに、自宅前に出します。共同住宅は、共用の出入り口付近です。立ち会いは不要です。家の中には入りません。収集日の前から出すと、不法投棄の原因になります。

### 小千谷市

粗大ごみは、収集しません。10kg以内、2m以内の不燃粗大ごみだけは、「埋立ごみの日」に収集場所へ出せます。地区別の曜日は、市の収集曜日のページで確認します。収集量に限りがあるため、できるだけ分けて出します。大量のときは、直接搬入です。

## 自分で持ち込む場合

### 見附市

直接持ち込めるのは、限られた場合だけです。

- 引越しや冠婚葬祭などで、一時的に大量のごみが出た場合
- 緊急の事情で、収集日まで待てない場合

特別な事情がないときは、持ち込めません。

| 項目 | 内容 |
|------|------|
| 施設 | 見附市清掃センター |
| 住所 | 椿澤町滝ノ入4834 |
| 電話 | 0258-63-3564（清掃センター。市の業務案内ページ、2026年7月2日更新） |
| 受付 | 月〜金 9:00〜16:00、土 9:00〜12:00。日・祝・年末年始は休み |
| 料金 | 粗大ごみは処理券。燃えるごみ・燃えないごみは重量制で、10kgまで110円、超えると10kgごとに110円（2026年8月1日改定、下の注を参照） |
| 手続き | 「廃棄物処理施設直接搬入届出書」を事前に記入し、窓口へ提出 |
| 事前連絡 | 予約の要否は、公式に記載がありません |

受付時間は、荷下ろしと精算を含みます。処理券は、事前に買って貼って持ち込みます。引き取れない物は、持ち帰ります。

重量料金は、2026年8月1日に改定されました。市のお知らせ（2026年7月14日更新）では、10kgまで100円から110円、10kgを超える分も10kgごとに100円から110円です。ガイドブック（令和8年7月改訂）も、10kgにつき110円です。清掃センターのページ（2026年3月18日更新）には、改定前の100円が残っています。

### 小千谷市

直接搬入が基本です。

| 項目 | 可燃粗大ごみ | 不燃粗大ごみ |
|------|--------------|--------------|
| 施設 | 時水清掃工場（サンクリーン時水） | クリーンスポット大原 |
| 住所 | 小千谷市大字時水1932-甲 | 小千谷市大字ひ生丁557-2 |
| 電話 | 0258-82-6100 | 0258-83-0731 |

受付は、2施設とも、月〜金 8:30〜16:00、土 8:30〜11:00です。日曜、祝日、振替休日、12月31日〜1月3日は休みです。

持ち込むときは、免許証などの身分証を見せます。分別と洗浄をして運びます。畳は1回に8枚まで、ふすまと障子戸は4枚までです。家の改築や取り壊しで出た物は、受け取りません。予約の要否は、公式に記載がありません。[要確認: 事前連絡の要否]

## 市で収集しない物

| 区分 | 見附市 | 小千谷市 |
|------|--------|----------|
| 家電4品目 | 収集しない。パソコンも不可 | 処理できない |
| 寝具 | スプリング入りのマットレス・ソファー（はずしていない場合） | スプリング入りも、不燃粗大ごみとして搬入できる |
| 大型 | 60kg以上の物（ピアノ、耐火金庫など） | ピアノ、バイク、農機具 |
| 危険な物 | 消火器、ボンベ、火薬類、灯油、ガソリン、農薬 | 消火器、ガスボンベ、燃料類、農薬、薬品 |
| その他 | タイヤ、自動車部品、建築廃材、農機具、事業系ごみ | タイヤ、自動車部品、建築廃材、コピー機、流し台、浴槽、事業系ごみ |

### 家電4品目の出し方

どちらの市も、方法は同じで、3つあります。1つ目は、購入した店か買い替える店に頼む方法です。2つ目は、郵便局で家電リサイクル券を買って、指定引取場所へ持ち込む方法です。事前に電話します。3つ目は、持ち込めないときに、市の許可業者に頼む方法です。

指定引取場所は、2市とも長岡市の2か所です。1か所は、豊和商事（新組町2474-1、0258-24-6322）です。もう1か所は、日本通運中越支店（要町1-4-44、0258-36-4400）です。リサイクル料金は、家電リサイクル券センター（0120-319640）で確認できます。見附市の案内ページは2023年8月更新ですが、ガイドブック（令和8年7月改訂）でも同じ2か所です。

## 分別で迷いやすい品目のQ&A

**Q1　布団は。**
見附市は、3枚まで1組で330円です。小千谷市は可燃粗大ごみです。60cm×30cm程度に切って指定袋に入れば、燃やすごみで出せます。羽毛布団は、30cm角程度に縛って指定袋に入れば、燃やすごみです。

**Q2　スプリング入りのマットレスは。**
見附市は、市では処理できません。小千谷市は、不燃粗大ごみとして、クリーンスポット大原に直接搬入します。

**Q3　ソファーは。**
見附市は、スプリングなしなら粗大ごみです。1人用は660円、2人以上は990円です。スプリング入りは、スプリングをはずした場合だけ粗大ごみ（990円）です。はずさない物は、処理できません。小千谷市は、スプリングなしが可燃粗大ごみ、スプリング入りが不燃粗大ごみ（直接搬入）です。

**Q4　仏壇は。**
2市とも、仏壇は公式の品目表に見つかりませんでした。[要確認: 仏壇の分別（見附市・小千谷市）]

**Q5　神棚は。**
見附市は、燃えるごみです。袋に入らない物は、引き取れません。小千谷市は、品目表に見つかりませんでした。[要確認: 神棚の分別（小千谷市）]

**Q6　石油ストーブは。**
見附市は、330円の粗大ごみです。石油は抜きます。小千谷市は、処理券100円の不燃粗大ごみです。灯油は使い切ります。使い切れない物は、販売店か許可業者へ頼みます。灯油そのものは、2市とも処理できません。

**Q7　物干し台は。**
見附市は、コンクリートの基礎部分がある物は処理できません。小千谷市は、コンクリート製の物干し台を、不燃粗大ごみとして直接搬入します。物干し竿は、見附市が330円、小千谷市が処理券100円です。

**Q8　電子レンジは。**
見附市は、660円の粗大ごみです。小千谷市は、埋立ごみです。10kgを超える物は、直接搬入します。

## 実家をまるごと片付けるときの考え方

見附市は、収集日の1週間前までに電話が必要です。1回5個までなので、量が多いと何回かに分けます。清掃センターへの持ち込みは、限られた場合だけです。

小千谷市は、申込がありません。重量制で、100kg以下なら可燃粗大ごみが300円です。ただし、車と人手を用意して、平日か土曜の午前に処理場へ運ぶ必要があります。

どちらの市でも、家電4品目やピアノ、耐火金庫は、市の収集や処理場では出せません。

次のようなときは、市の制度だけでは足りないことがあります。量が多い、市で扱わない物が多い、階段や積雪期で搬出が難しい、遠方で何度も通えない。そのときは、市の許可業者に見積りを取る方法があります。見積りの取り方は、[自分で出す？業者に頼む？](../jibun-de-dasu-ka-gyousha-ka/)を見てください。

小千谷市は、リユースのサービス「おいくら」と連携しています。再販できる物だけが対象です。
