# 新潟市の特定5品目とは｜対象・出し方・出してはいけない物

## 結論：特定5品目は月1回、中身の見える袋で出します

新潟市の「特定5品目」は、ごみ分別の区分の1つです。対象は、乾電池類、蛍光管、水銀体温計、ライター、スプレー缶類の5品目です。

収集は月1回です。中身の見える透明か半透明の袋に入れて出します。5品目は、まとめて同じ袋に入れて構いません。

収集日は、地区ごとに決まっています。お住まいの区の「家庭ごみ収集カレンダー」で確かめます。カレンダーには「毎月 第○○曜日」の形で書かれています。出す時間は、多くのカレンダーで「午前8時まで」です。

この記事は、新潟市の公式サイトだけでまとめました。内容は2026年10月17日の確認時点です。区分や出し方は変わることがあるため、出す前に公式ページを見てください。

この記事で分かること

- 特定5品目に入る物と、入らない物
- 品目ごとの出し方（袋、包み方、使い切り）
- 電池が外れない家電の出し方
- 収集日の調べ方
- 実家の片付けで、電池やスプレー缶がまとめて出たときの進め方

## 早見表

| 項目 | 内容 |
|---|---|
| 対象 | 乾電池類、蛍光管、水銀体温計、ライター、スプレー缶類 |
| 収集 | 月1回 |
| 袋 | 中身の見える透明または半透明の袋（90L以下） |
| 出す場所 | あらかじめ決められた、自分の地域のごみ集積場 |
| 収集日 | 地区ごとに違う（「毎月 第○○曜日」）。家庭ごみ収集カレンダーで確認 |
| 出す時間 | 多くのカレンダーで午前8時まで（秋葉区の1枚は8時30分まで）。お住まいの地区のカレンダーで確認 |
| 問い合わせ | 新潟市 環境部 廃棄物対策課 025-226-1407 |

袋の大きさ（90L以下）は、市の「ごみと資源の分け方・出し方（全市版）」の表記です。「特定5品目」のページには、袋の大きさの記載がありません。

集積場は、自治会・町内会、マンション・アパートの管理人が維持管理をしています。決められた場所と日以外には、出さないでください。袋の口は、しっかり結びます。

## 5品目の出し方

市の「特定5品目」のページにある、図とQ&Aをもとにした表です。

| 品目 | 含まれる物 | 出し方の注意 |
|---|---|---|
| 乾電池類 | 乾電池、ボタン電池、充電池、モバイルバッテリー、小型充電式バッテリー | 家電販売店等の店頭回収も利用できる。ボタン電池は、1つずつ両面にテープを貼って絶縁する |
| 蛍光管 | 蛍光管（ボール型を含む） | 割れないように紙に包むなどして出す。袋に入らない大きさは、無理に入れず紙等に包んで出す |
| 水銀体温計 | 水銀体温計（水銀血圧計も特定5品目） | 割れないように紙に包むなどして出す |
| ライター | ライター | 中身を使い切って出す |
| スプレー缶類 | スプレー缶（化粧品・殺虫剤など） | 中身を使い切って出す。穴は開けなくてよい。穴が開いていても収集する |

乾電池類の図には、リチウムイオン電池、ニッケル水素電池、ニカド電池のマークがあります。いずれも特定5品目です。

水銀血圧計も、「特定5品目」で出します。ただし、医療機関は自己処理となるため、出せません。

## スプレー缶類を出す前に

スプレー缶類は、できるだけ中身を使い切ります。市は、中身が残ったままだと、収集車や処理施設の爆発・火災事故の原因になると案内しています。

残ったガスは、製品についているキャップの「ガス抜き機能」で出します。使い方は、製品に書かれた説明を見ます。作業は、火の気がなく、風通しの良い屋外で行います。

穴を開ける必要はありません。やむを得ず中身が入ったまま出すときは、「中身入り」と表示します。ライターも同じです。

スプレー缶に付いていたプラスチック製のキャップは、必ず外します。キャップは「プラマーク容器包装」に出します。

## 電池が外れない家電は、どう出しますか

乾電池や小型充電式バッテリーで動く製品は、電池を外してから捨てます。外した電池は、特定5品目に出します。

電池が外せないときの扱いは、製品の大きさで変わります。

| 状態 | 出し方 |
|---|---|
| 本体が指定袋に入る大きさ | 本体ごと「特定5品目」に出す |
| 指定袋に入らず、粗大ごみの大きさ | 粗大ごみの申込みのときに「はずせない」と伝える |

市は、製品の構造上取りはずせない場合に、無理に分解しないよう求めています。リチウムイオン電池は、破損や変形で発熱・発火する危険があるためです。

電池を外した本体は、材質で分けます。プラスチック製のおもちゃは燃やすごみ、家電製品は燃やさないごみです。指定袋に入らない大きさは、粗大ごみです。外した電池類は、燃やさないごみに入れず、特定5品目に出します。

粗大ごみの出し方は、[新潟市の粗大ごみの出し方](../niigata-shi-sodaigomi/)にまとめています。

### 電池類だけを特定5品目に出す物

次の物は、電池類が外せる場合は、本体を燃やさないごみに出します。電池類は特定5品目です。

- 電気シェーバー
- 電動歯ブラシ
- 電子たばこ（本体）
- 加熱式たばこ（本体）

照明器具と電気スタンドは、蛍光管を外して特定5品目に出します。本体は燃やさないごみです。指定袋に入らなければ、粗大ごみです。

ナツメ球は燃やさないごみです。その中の蛍光灯は特定5品目です。

温度計（電子式を含む）は、電池類が外せない場合は本体ごと特定5品目です。水銀温度計は、特定5品目です。

### 特定5品目ではない物（市の記載）

| 品目 | 区分 |
|---|---|
| 電球（白熱球・LED） | 燃やさないごみ。厚紙等に包んで【危険】と表示 |
| 電子体温計 | 燃やさないごみ |
| 刃物、割れたガラス | 燃やさないごみ |
| 消火器 | 排出禁止物（市で収集しない）。消火器リサイクルセンターに相談 |
| ガスボンベ（LPガス用）、プロパンガスのボンベ | 排出禁止物。販売店に相談 |
| バッテリー（車・バイク用） | 排出禁止物。販売店に相談 |

ボール型の蛍光管は、水銀を含むため特定5品目です。白熱電球とLED電球は、水銀を含まないため燃やさないごみです。

簡易消火器と消火器は、区分が違います。簡易消火器は特定5品目、消火器は市で収集しません。

## 販売店の回収ボックスも使えますか

市の案内では、使える場合があります。

- 乾電池：販売店の回収ボックスも利用できる
- ボタン電池：特定5品目、または電気店やカメラ店などの販売店の回収ボックス
- 家電等の充電式電池：特定5品目、または電気店やカメラ店などの販売店の回収ボックス

どの店に回収ボックスがあるかは、市のページに載っていません。[要確認: 回収ボックスを置く販売店の一覧（各販売店・新潟市廃棄物対策課）]

## 収集日と出す時間は、どう調べますか

特定5品目の収集は月1回です。具体的な曜日や日付は、市の分別のページには書かれていません。地区ごとに違うためです。

令和8年度版のカレンダーでは、たとえば中央区の1枚（カレンダーコード13-1）が「毎月 第4金曜日」、西蒲区（巻）の1枚が「毎月 第2火曜日」でした。ご自宅の地区は、次のどちらかで調べます。

- 市の「家庭ごみ収集カレンダー」（北区、東区、中央区、江南区、秋葉区、南区、西区、西蒲区の区別に掲載）
- ごみ分別アプリ「さんあ～る」の収集カレンダー

ごみカレンダーには、ごみ出し時間が書かれています。品目によっては、地域でごみ出し時間が変則的になっています。詳しくは、区役所区民生活課（中央区は窓口サービス課）、近所の人、または自治会・町内会に確認するよう、市が案内しています。

特定5品目を出す時間は、カレンダーの「ごみ出し時間」の欄を見ます。令和8年度版を、8つの区から1枚ずつ確かめました。7枚は「午前8時まで」、秋葉区の1枚は「午前8時30分まで」でした。ただし、市の注意書きのとおり、地域によって変則的な場合があります。ご自宅の地区のカレンダーで確かめてください。

## 実家の片付けで、まとまって出るとき

古いスプレー缶、乾電池、蛍光管、ライターなどが、一度に出ることがあります。次の順で進めます。

1. 5品目に分けます。乾電池類、蛍光管、水銀体温計、ライター、スプレー缶類の5つです。
2. 家電から、電池を外します。外した電池は、特定5品目の袋に入れます。
3. スプレー缶とライターは、使い切ります。ガス抜きは、屋外の風通しのよい場所で行います。
4. 蛍光管と水銀体温計は、割れないように紙に包みます。
5. 袋に入れます。5品目は、同じ袋にまとめて入れて構いません。中身が見える透明か半透明の袋です。
6. 収集カレンダーで、特定5品目の日と、ごみ出し時間（多くは午前8時まで）を確認します。月1回です。

月1回なので、片付けの時期によっては、次の収集日まで間が空きます。それまでの保管の仕方は、公式ページに記載がありません。[要確認: 次の収集日まで保管するときの注意（新潟市廃棄物対策課）]

袋の数や、1回に出せる量の上限も、公式ページに記載がありません。[要確認: 1回に出せる袋の数・量の上限（新潟市廃棄物対策課・区役所区民生活課）]

電池が外れない家電が、粗大ごみの大きさのときは、申込みのときに「はずせない」と伝えます。粗大ごみの申込みは、粗大ごみ受付センター（025-290-5353）です。受付は、祝休日および12月29日から1月3日を除く月曜～土曜の午前9時から午後5時まで、とされています。インターネットとチャットボットは、24時間受付です。

次の物は、特定5品目に出せません。

- 家電4品目（エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機）：市では収集しません。[新潟の家電4品目の出し方](../kaden4hinmoku-niigata/)を見てください。
- パソコン：市では収集しません。[パソコンの処分](../pc-sumaho-shobun-niigata/)にまとめています。
- 消火器、ガスボンベ、車・バイク用バッテリー：排出禁止物です。販売店などに相談します。

## 施設に自分で持ち込むとき

特定5品目を、処理施設に自己搬入する場合の、公式ページの記載は次のとおりです。

- 「燃やさないごみ」の中に「特定5品目」が含まれる場合は、分けて搬入します。
- 豊栄環境センターでは、乾電池、蛍光管、水銀体温計は搬入できません。
- 家庭系ごみの手数料は、10キログラムまでごとに100円です（2026年6月1日から）。

亀田一般廃棄物処理場（江南区亀田1870番地1）は、上の自己搬入の施設一覧には載っていない別の施設です。この処理場のページには、「特定5品目の持ち込みはできません」と書かれています。

豊栄環境センターと亀田一般廃棄物処理場以外の施設が、特定5品目を受け付けるかどうかは、自己搬入のページに書かれていません。[要確認: 自己搬入の各施設での特定5品目の受け入れ可否と、ライター・スプレー缶類の扱い（新潟市循環社会推進課 025-226-1423）]

自己搬入の施設、受付時間、料金の計算例は、[新潟市のごみ持ち込み](../niigata-shi-gomi-mochikomi/)にまとめています。

## なぜ、分ける必要があるのですか

市は、ごみ処理施設で、電池類や小型充電式バッテリーが原因とみられる発煙・発火が頻繁に起きていると案内しています（2025年5月26日更新のページ）。

また、焼却灰・排ガスから基準値に近い水銀が検出されることがあるとして、水銀を含む物の分別の徹底を求めています（2025年7月1日更新のページ）。

## 新潟市の特定5品目、よくある質問

**Q　新潟市の特定5品目とは何ですか。**
乾電池類、蛍光管、水銀体温計、ライター、スプレー缶類の5品目です。爆発や破裂の危険があるもの、水銀などの有害物を含む場合があるものとして、市が分けています。月1回、中身の見える透明か半透明の袋で出します。

**Q　新潟市の特定5品目は、いつ出しますか。**
月1回です。曜日は地区ごとに違うため、区ごとの家庭ごみ収集カレンダーで確かめます。

**Q　スプレー缶は、穴を開けて出しますか。**
開けなくてよいです。使い切って、キャップの「ガス抜き機能」を、火の気がなく風通しのよい屋外で使います。穴が開いている缶も収集します。

**Q　電球は、特定5品目ですか。**
白熱電球とLED電球は、燃やさないごみです。ボール型の蛍光管は、特定5品目です。

**Q　電池が外れない家電は、どうしますか。**
指定袋に入る大きさなら、本体ごと特定5品目に出します。入らない大きさなら、粗大ごみの申込みのときに「はずせない」と伝えます。

**Q　水銀血圧計は、出せますか。**
特定5品目で出せます。ただし、医療機関は自己処理となるため、出せません。
