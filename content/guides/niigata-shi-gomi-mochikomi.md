# 新潟市のごみ持ち込み｜全6施設の受付時間・料金・持ち込めない物

## 結論：持ち込みは月〜土の日中、料金は10kgまでごとに100円です

新潟市のごみは、市の処理施設へ自分で持ち込めます。これを「自己搬入」といいます。受付は月曜から土曜の8:30〜16:00（土曜は15:00まで）です。鎧潟クリーンセンターだけは、日曜と祝日も受け付けます。料金は、重さ10kgまでごとに100円です。支払いは現金のみです。

実家の片付けでは、一度に大量のごみが出ます。収集日を待たずに運びたいときに、持ち込みが選べます。

この記事は、新潟市の公式ページだけで書いています。確認日は2026年10月4日です。出かける前に、公式ページで最新の情報を確かめてください。

この記事で分かること

- 持ち込める6施設の住所・電話・受付時間
- 住んでいる区で、行ける施設が決まること
- 料金の仕組みと計算例（2026年6月1日に改定）
- 手数料が免除される場合（火災ごみ）
- 持ち込めない物、分け方、袋のルール
- 粗大ごみの収集との使い分け
- 実家のごみを一度に運ぶ手順

## 新潟市のごみ持ち込みは、どの施設に行けばよいですか

行ける施設は、住んでいる区で決まります。市の「受入日時と区ごとに自己搬入できる施設」のページに、区別の一覧があります。

| 住んでいる区 | 持ち込める施設 |
|------|------|
| 北区 | 新田、亀田、新津、白根、豊栄（5施設） |
| 東区・中央区・江南区・秋葉区・南区・西区 | 新田、亀田、新津、白根（4施設） |
| 西蒲区・四ツ郷屋地区（西区） | 新田、亀田、新津、白根、鎧潟（5施設） |

豊栄環境センターに持ち込めるのは、北区の人です。鎧潟クリーンセンターに持ち込めるのは、西蒲区と四ツ郷屋地区の人です。

実家が自宅と別の区にある場合は、どちらの区で見るかが問題になります。この点は公式ページに記載がありません。[要確認: 住んでいる区と、ごみが出る家の区が違うときの扱い]

祝日は、鎧潟クリーンセンターを除く5施設で持ち込めません。月〜金曜が祝日の場合も、土曜が祝日の場合も同じです。市のページによると、2026年度は祝日が土曜に当たる日がありません。

鎧潟クリーンセンターだけは、日曜と祝日も受け入れます。土曜・日曜・祝日は、午後が15:00までです。電気設備の点検日は、持ち込めません。

### 年末年始はいつから休みですか

12月31日の午後から1月3日までは、全施設で持ち込めません。年末の片付けは、12月30日までに終えるのが安全です。

新潟西バイパスの「新通IC」から、車ですぐです。「アクアパークにいがた」のとなりにあります。

### 新津クリーンセンターへの行き方

秋葉区役所から、車で10分です。

### 白根環境事業所への行き方

国道8号の「白根交差点」から、小須戸方面へ車で5分です。

### 鎧潟クリーンセンターへの行き方

JR越後線の「巻駅」から、車で10分です。北陸自動車道の「巻潟東IC」から、車で5分です。

### 豊栄環境センターへの行き方

豊栄郷清掃施設処理組合が運営する施設です。新新バイパスの「豊栄IC」から、車ですぐです。持ち込めるのは、北区にお住まいの方です。

### 赤塚や、亀田一般廃棄物処理場は持ち込み先ですか

「赤塚」は、第4赤塚埋立処分地（西区東山123番地1）のことです。公式の受入施設一覧（2023年10月2日更新）には、載っていません。市のページでは、枝葉・草の持ち込みを受け入れる施設です。

亀田一般廃棄物処理場（江南区亀田1870番地1）も同じです。上の6施設とは別の施設です。この処理場は、特定5品目の持ち込みを受けていません。

ただし、手数料改定のページには、第4赤塚埋立処分地が対象施設として載っています。ごみの持ち込みを受けるかどうかは、受入施設一覧に記載がありません。[要確認: 第4赤塚埋立処分地で、枝葉・草以外のごみを受けるか]

## 持ち込みの料金はいくらですか

家庭から出るごみは、10kgまでごとに100円です。事業活動で出たごみは、10kgまでごとに130円です。

2026年5月31日までは、家庭ごみが10kgまでごとに60円でした。2026年6月1日に100円へ改定されました。市は、手数料を処理にかかる費用に近づけるためと説明しています。見直しは3年ごとです。

集積所に出すときの指定袋と、粗大ごみ処理券の料金は変わっていません。

### 料金の計算例

重さは、積んだ車の重さと、荷を下ろした後の車の重さの差で決まります。

| ごみの重さ | 2026年6月1日以降 | 参考：5月31日まで |
|------|------|------|
| 10kg | 100円 | 60円 |
| 50kg | 500円 | 300円 |
| 100kg | 1,000円 | 600円 |
| 200kg | 2,000円 | 1,200円 |
| 300kg | 3,000円 | 1,800円 |

10kgに満たない端数の扱いは、公式ページに記載がありません。最低料金の有無も同じです。[要確認: 10kg未満の端数の計算方法]

### 支払いは現金だけですか

市の資料では、お支払いは現金のみです。出口の計量のあとに精算します。キャッシュレス決済の記載はありません。

### 有料の指定袋に入れたごみも、重さで料金がかかりますか

かかります。有料指定袋に入れたごみも、持ち込めば重さで計算されます。指定袋に入るごみは、集積所に出すよう案内されています。

## 手数料が免除される場合はありますか

居住用家屋の火災ごみのうち、家財道具は、持ち込みの手数料が免除されます。受け入れる量に上限はありません。運ぶ費用は、自己負担です。

搬入できるのは、一般家庭の家財道具だけです。コンクリート基礎、家屋の構造物、家電4品目は搬入できません。免除の申請様式（一般廃棄物処理手数料免除申請書）は、市のページにあります。

天災などの場合も、無料で受け入れることがあります。問い合わせ先は、廃棄物対策課業務係（025-226-1403）です。

## 何を持ち込めて、何を持ち込めませんか

持ち込めるのは、燃やすごみ、燃やさないごみ、粗大ごみです。分け方は、集積所に出すときと同じです。迷う品目は、[新潟市のごみ分別で迷う品目50](../niigata-shi-gomi-bunbetsu-mayou/)で確認できます。

### 持ち込めない物

市の資料では、次の物は持ち込めません。

| 持ち込めない物 | 備考 |
|------|------|
| 産業廃棄物 | 市で収集も処理もしません |
| 家電4品目 | エアコン、テレビ、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機 |
| パソコン | 本体とディスプレイ |
| 排出禁止物 | 農薬、タイヤ、塗料など |
| 乾電池、蛍光管、水銀体温計 | 豊栄環境センターだけ搬入できません |

家電4品目の出し方は、[新潟の家電4品目の処分方法](../kaden4hinmoku-niigata/)にまとめています。

### 資源物や枝葉は、持ち込めますか

資源物は、集積所か拠点回収に出すよう案内されています。自己搬入もできますが、手数料がかかります。

家庭の枝葉・草は、集積所に出します。多量のときは、専用の持ち込み先があります。次の項で説明します。

## 袋・分け方・降ろし方のルール

公式ページが求めるのは、次の点です。

- 「燃やすごみ」「燃やさないごみ」「粗大ごみ」に必ず分けます。
- 燃やさないごみに「特定5品目」が入るときは、分けて持ち込みます。
- 特定5品目は、乾電池類、蛍光管、水銀体温計、ライター、スプレー缶類です。
- 中身が見えるように、袋に入れます。
- 袋は、90リットル以下の無色透明か、無色半透明にします。
- 袋に入らない粗大ごみは、そのままで構いません。
- ごみは、持ち込んだ人が自分で降ろします。
- 量が多い、または重いときは、複数人で行きます。

車種の制限、積み方の決まり、1回に持ち込める量は、公式ページに記載がありません。[要確認: 車種・積載量・台数の制限]

粗大ごみの大きさや重さの上限も、持ち込みについては記載がありません。[要確認: 持ち込める粗大ごみの寸法・重量の上限]

## 受付から精算までの流れ

市の資料に書かれた流れは、次のとおりです。

1. 受付に「廃棄物処理依頼書」を出します。
2. ごみを積んだ車ごと、計量器で量ります。車のまま、施設の中へ進みます。
3. 指定の場所で、自分でごみを降ろします。
4. 出口でもう一度、車を量ります。1回目との差が、ごみの重さです。
5. その重さで手数料を払います。現金のみです。

廃棄物処理依頼書は、市のサイトからダウンロードできます。各施設にも用紙があります。事前に書いておくと、スムーズです。豊栄環境センターだけ、別の様式です。

事前の予約が要るかどうかは、公式ページに記載がありません。依頼書を出す流れだけが書かれています。[要確認: 事前予約や事前連絡の要否]

## 混雑する日はいつですか

市は、次の日が混雑すると案内しています。

- 年末年始
- お盆
- 引っ越しシーズン
- 連休の翌日
- 土曜日

公式ページによると、近年は少量のごみの持ち込みが非常に多くなっています。多い日は100台以上が並び、1時間以上待つ状況です。周辺道路で渋滞も起きています。

混雑の状況によっては、安全のため持ち込みを断られることがあります。上の日を避けると、待ち時間を減らせます。

## 粗大ごみの収集と、持ち込みの使い分け

粗大ごみの収集は、事前に申し込む戸別収集です。品目ごとに100〜500円で、収集日は申込後3日〜1週間以降です。申し込み方法と品目別の料金は、[新潟市の粗大ごみの出し方](../niigata-shi-sodaigomi/)にまとめています。

軽い家具が数点なら、収集が安くなることがあります。重くてかさばる物を大量に運ぶなら、持ち込みが向きます。どちらが安いかは、重さで決まります。

たとえば、収集の手数料は、たんす（合計2.5m未満）300円、布団100円、ソファー500円で、合計900円です。持ち込みで900円は、90kg分です。

## 実家のごみを一度に大量に持ち込むときの手順

市は、少量の持ち込みが増えて混雑していると説明しています。量が多いときは、次の順番で準備します。

1. 出す物を、燃やすごみ・燃やさないごみ・粗大ごみに分けます。
2. 家電4品目、パソコン、タイヤ、塗料、農薬を外します。持ち込めません。
3. 燃やさないごみの中の、電池・蛍光管・ライター・スプレー缶を別にします。
4. 袋に入るごみは、90リットル以下の透明か半透明の袋に入れます。
5. 行ける施設を、住んでいる区で選びます。
6. 廃棄物処理依頼書を、事前に書いておきます。
7. 混雑する日を避けて、受付時間の中に着くようにします。
8. 荷下ろしができる人数で行きます。
9. 現金を用意します。

重さの目安は、10kgごとに100円で考えます。たとえば200kgなら2,000円、500kgなら5,000円です。自分で出すか、業者に頼むかの考え方は、[自分で出す？業者に頼む？](../jibun-de-dasu-ka-gyousha-ka/)で整理しています。

量が多くて、自分では運べない場合は、許可を持つ業者に見積りを取る方法があります。業者の探し方は、[新潟市の一般廃棄物 許可業者一覧](../niigata-shi-kyoka-gyosha/)を見てください。

高齢の親が住む実家などで、ごみを外へ出す人手がないときは、ごみ出し支援事業があります。地域の団体が対象のときに使えます。くわしくは、[新潟市の粗大ごみの出し方](../niigata-shi-sodaigomi/)の「運び出しが難しいときの支援」を見てください。

遠方に住んでいる人が、市内の実家のごみを持ち込めるかどうかは、公式ページに記載がありません。市の資料に書かれた対象は、新潟市にお住まいの方と、所在地のある事業者です。[要確認: 市外に住む家族が、市内の実家のごみを持ち込めるか]

## 庭木・枝葉・草は、どこへ持ち込めますか

庭の剪定枝や草は、「ごみ」ではなく「資源」として無料で持ち込める施設があります。事業系は受け付けません。

| 施設 | 住所 | 電話 |
|------|------|------|
| 亀田一般廃棄物処理場 | 江南区亀田1870-1 | 025-381-3501 |
| 第4赤塚埋立処分地 | 西区東山123-1 | 025-239-2777 |
| 白根環境事業所 | 南区臼井2135-1 | 025-371-5070 |

受付は、月〜金曜が8:30〜12:00と13:00〜16:00です。土曜は午後が15:00までです。祝休日は休みです。通年で受け付けています。

荷姿の条件は、1本の長さが1m以内、1本の太さが直径15cm以内です。一束の太さは直径30cm以内で、ひもで結ぶか、透明か半透明の袋に入れます。

角材、ベニヤ板、木製家具は、枝葉・草として出せません。燃やすごみか粗大ごみです。

この大きさにできない枝木は、「ごみ」として有料の施設へ持ち込みます。受け入れ寸法は、施設で違います。

| 施設 | 受け入れ寸法 |
|------|------|
| 新田・亀田・白根・新津 | 太さ10cm以内、長さ50cm以内 |
| 豊栄環境センター（北区の人） | 太さ20cm以内、長さ300cm以内 |
| 鎧潟クリーンセンター（西蒲区・四ツ郷屋地区の人） | 太さ5cm以内で長さ50cm以内。太い幹は太さ20cm以内で長さ200cm以内（枝は切り落とす） |

この寸法には、ひもも袋も不要です。表の値は、家庭系の枝木の場合です。市のページには、民間の木くずリサイクル業者の一覧もあります。

## 新潟市のごみ持ち込み、よくある質問

**Q　新潟市のごみは、予約なしで持ち込めますか。**
予約の記載は、公式ページにありません。受付で、廃棄物処理依頼書を出す流れです。[要確認: 事前予約の要否]

**Q　新潟市のごみの持ち込みは、いくらかかりますか。**
家庭ごみは、10kgまでごとに100円です。50kgなら500円、100kgなら1,000円です。2026年6月1日に、60円から改定されました。現金のみです。

**Q　新田清掃センターと亀田清掃センターは、日曜に持ち込めますか。**
持ち込めません。月曜から土曜の受け入れです。日曜、祝日、12月31日の午後から1月3日までは休みです。日曜と祝日に受け入れるのは、鎧潟クリーンセンターだけです。

**Q　新潟市で、エアコンやテレビは持ち込めますか。**
持ち込めません。家電4品目は、市で処理していません。販売店や、指定の引取場所を使います。パソコンも持ち込めません。

**Q　持ち込むごみは、袋に入れますか。**
中身が見えるように、袋に入れます。90リットル以下の無色透明か半透明です。袋に入らない粗大ごみは、そのままで構いません。
