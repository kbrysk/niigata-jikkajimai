# 実家の食器・本・写真・人形の処分｜新潟市・長岡市の区分と出し方、人形供養の考え方

## 先に答え：小物は「燃やさない」「古紙」「古着」「燃やす」に分かれます

実家の小物は、品目ごとに出し先が違います。新潟市・長岡市とも、陶器やガラスの食器は燃やさないごみです。本は古紙（雑誌類）、写真は燃やすごみです。人形は、市のごみとして出せます。供養を望む場合は、寺社に別に相談します。

ただし、新潟市と長岡市で区分が違う品目があります。アルバムは、新潟市が燃やすごみ、長岡市が燃やさないごみです。

この記事は、2026年10月4日時点の公式情報で、次の7つの小物をまとめました。

- 食器（陶器・ガラス・金属）
- 本・雑誌・アルバム
- 写真・手紙（個人情報を含む紙）
- 衣類・着物・布
- 人形・ぬいぐるみ・ひな人形
- 賞状・トロフィー
- 薬・化粧品・スプレー缶

仏壇・位牌・神棚の処分は、[仏壇・神棚・位牌の処分](../butsudan-kamidana-shobun-niigata/)で扱っています。この記事では説明しません。

## 食器は何ごみですか（陶器・ガラス・金属）

### 割れ物は、包んで表示して出します

新潟市は、ガラス類と陶磁器類の割れ物を、新聞紙などで包みます。袋に「割れ物危険」と表示します。割れた皿・食器・びんと、包丁やはさみは、厚紙などで包んで【危険】と表示します（分別早見表）。

長岡市は、包丁・電球・鏡・ガラスなどを紙で包みます。指定袋の外側に「キケン」「ワレモノ」と表示します。

### 長岡市の食器の区分

長岡市の分別表は、「陶磁器類」を燃やさないごみとしています。花瓶も燃やさないごみです。燃やさないごみのページには、金属・陶磁器・ガラス類が対象と書かれています。

長岡市には、もう一つの出し先があります。「資源物の拠点回収」です。

- 対象は、壊れていないセトモノ・金属・ガラス製の食器です。茶碗、グラス、スプーンなどです。
- ひび割れした食器と箸は、対象外です。
- 割れないよう紙で包み、箱に入れて持ち込みます。
- 実施は、土・日曜日の午前9時から正午です。祝日と年末年始は休みです。悪天候で中止することがあります。
- 会場により、日程が違います。和島支所は偶数月の第4日曜日だけです。寺泊支所と旧栃尾クリーンセンターは、毎月第2・4土曜日と翌日曜日です。
- 希望が丘資源物ステーションと旧栃尾クリーンセンターは、令和8年度から1月と2月が休止です。

食器は、使えるものと、割れたものを先に分けます。使えるものは拠点回収、割れたものは燃やさないごみです。

### びんとの違いに注意します

ガラスのコップは、新潟市のびん回収には出せません。新潟市のページは、耐熱ガラスとコップを、びんの対象外としています。出し先は、燃やさないごみです。

## 本・雑誌は大量でも出せますか

### 新潟市は月2回の古紙回収に出します

新潟市は、本を古紙類（雑誌・雑がみ）としています。辞書・辞典も同じです。雑誌は、まとめて紐で十文字に縛ります。古紙の回収は月2回で、雨の日でも出せます。

出せないものもあります。

- 写真は、燃やすごみです。
- アルバムは、古紙として回収しないものの例です。分別表では燃やすごみです。
- 感熱紙（レシートなど）、油紙、ビニールでコーティングされた紙は、燃やすごみです。
- 圧着はがき（「ここからあけてください」と書いてあるはがき）も、古紙に出せません。

### 長岡市も月2回の回収です

長岡市は、本を「雑誌・チラシ」としています。新聞、雑誌・チラシ、段ボールの3つに分けます。紐で十字に縛ります。出す時間は、収集日の午前8時30分までです。

雨や雪の日でも収集します。大雨や大雪などの荒れた天気では、次の収集日まで保管するか、ブルーシートをかけるよう案内しています。

感熱紙とラミネート紙は、燃やすごみです。金具は取って燃やさないごみへ、フィルムは取ってプラスチック容器包装材へ出します。小さな紙は、雑誌や二つ折りのチラシにはさむか、古封筒に入れます。

### 大量の本の考え方

本が数百冊あっても、公式の案内に冊数の上限は見つかりませんでした。[要確認: 1回に出せる古紙の量の上限]

実際は、月2回の回収日に、少しずつ出します。紐で縛る手間もかかります。収集日を先にカレンダーで確認し、回数を割り振ります。

長岡市は、拠点回収にも新聞、雑誌・チラシ、段ボールを持ち込めます。それぞれ分けて、紐で十字に縛ります。新潟市の自己搬入は、資源物が対象外です。古紙には、ごみ集積所や拠点回収を使うよう案内しています。

売れる本がある場合、買取は民間のサービスです。この記事では扱いません。

## 写真・手紙・アルバムは、どう処分しますか

### 区分は、市で違います

| 品目 | 新潟市 | 長岡市 |
|---|---|---|
| 写真 | 燃やすごみ | 燃やすごみ |
| 写真のネガ・フィルム | 燃やすごみ | 燃やさないごみ |
| 写真立て | 燃やさないごみ（木製は燃やすごみ） | [要確認: 長岡市の写真立ての区分] |
| アルバム | 燃やすごみ | 燃やさないごみ |
| 手紙 | 古紙類（雑誌・雑がみ） | 封筒、はがき、名刺は雑誌・チラシ。便箋は [要確認: 長岡市の便箋の区分] |

新潟市のネガとフィルムは、写真と同じ区分で、燃やすごみです。長岡市は、写真フィルムが燃やさないごみです。

長岡市の拠点回収では、「ミックスペーパー」に写真が含まれています。シュレッダーごみも、対象です。

### 個人情報を含む紙の注意

手紙、年賀状、通帳の明細、病院の書類などは、住所・氏名・口座番号が載っています。そのまま出さず、読み取れない状態にします。

- 住所・氏名・番号の部分を、破るか切り分けます。
- 細かくするほど、読み取られにくくなります。
- 家族の写真は、顔の部分を折るなどして、袋の外から見えないようにします。

シュレッダーにかけた紙の扱いは、市で違います。

- 新潟市は、雑がみの例に、シュレッダー紙を挙げています。単独で、中身の見える透明か半透明の袋に入れます。
- 長岡市は、燃やすごみです。雑誌・チラシには出せません。長岡市の拠点回収は、ミックスペーパーで、受け付けています。

量が多い場合は、一度に出さず、数回に分けます。ごみ袋の中身は、外から見えないようにします。

### 残すものを決めてから捨てます

写真や手紙は、一度捨てると戻せません。遺品整理の途中で、判断が変わることもあります。捨てるものは、家族と相談してから決めます。写真のお焚き上げを望む場合は、寺社の公式サイトで受付の有無を確かめます。確認できた新潟縣護國神社のページは、人形が対象で、写真の記載はありませんでした。[要確認: 新潟県内で写真・アルバムのお焚き上げを受ける寺社]

進め方は、[遺品整理を自分でやるとき](../ihinseiri-jibunde-niigata/)にまとめています。

長岡市は、古着・古布をごみステーションで集めています。

人形やぬいぐるみを、そのままごみに出すことに抵抗がある人もいます。供養を望む場合は、寺社に相談します。

人形供養は、市のごみ収集とは別の話です。寺社ごとに、受付の方法が違います。公式サイトで確認できた例は、次のとおりです。

ぬいぐるみを受け付けるかも、公式ページでは確認できませんでした。[要確認: 各寺社のぬいぐるみの受付可否]

人形供養の有無や条件は、寺社によって違います。他の寺社を探す場合は、その寺社の公式サイトで、受付日・料金・持ち込み方法を確認します。

## 賞状・トロフィーは、何ごみですか

| 品目 | 新潟市 | 長岡市 |
|---|---|---|
| トロフィー | 燃やさないごみ。袋に入らなければ粗大ごみ | [要確認: 長岡市のトロフィーの区分] |
| 賞状 | 公式の分別表に記載なし [要確認: 新潟市の賞状の区分] | 公式の分別表に記載なし [要確認: 長岡市の賞状の区分] |
| 賞状入れの紙筒（のりで固めたもの） | 記載なし | 燃やすごみ |

三条市の分別表では、トロフィーは燃えないごみです。

## 長岡市の拠点回収：実家の小物で使える品目

長岡市の資源物の拠点回収は、無料で引き取る持ち込み窓口です。実家の片付けでは、次の品目が使えます。

| 品目 | 対象 | 出し方 |
|---|---|---|
| 食器類 | 壊れていないセトモノ、金属、ガラス製。ひび割れた食器と箸は除く | 紙に包み、箱などに入れる |
| かばん・ベルト | 壊れていないかばん、切れていないベルト。スーツケースなどは除く | 2種まとめて透明か半透明の袋に入れる |
| 靴 | 破れや汚れがひどくない靴。長靴、下駄、サンダル、ロングブーツは除く | 泥を落とし、透明か半透明の袋に入れる |
| 古着・古布 | 破れや汚れのない衣類全般、タオル、シーツ、毛布、タオルケット | 洗濯して、たたんで袋に入れる |
| 古紙類 | 新聞、雑誌・チラシ、段ボール | 分けて、紐で十字に縛る |
| ミックスペーパー | 写真、シュレッダーごみ、紙筒、ビニール窓付封筒など。銀紙、油紙、ティッシュ、シールは除く | 透明か半透明の袋に入れる |

回収場所は、環境衛生センター（寿3丁目）と希望が丘資源物ステーション（西津町）です。中之島・越路・三島・和島・寺泊の各支所と、旧栃尾クリーンセンターでも受け付けます。日程は、会場によって違います。

## 量が多いとき、持ち込めますか

### 新潟市

新潟市は、「ごみの自己搬入」の制度があります。引っ越しなどで一時的に多量のごみが出たときや、通常の収集日に出せないときに使えます。

| 項目 | 内容 |
|---|---|
| 手数料 | 家庭系ごみは、重さ10kgまでごとに100円 |
| 支払い | 現金のみ |
| 分け方 | 燃やすごみ、燃やさないごみ、粗大ごみに分ける |
| 袋 | 90リットル以下の無色透明か無色半透明。粗大ごみはそのまま |
| 荷降ろし | 搬入者自身で行う |
| 重さの計り方 | 入口と出口で車両の重さを量り、差で決める。有料指定袋で持ち込んだ物も、重さの対象 |
| 受入時間 | 多くの施設は、月〜金が午前8時30分〜正午と午後1時〜4時。土曜は午前8時30分〜正午と午後1時〜3時。祝休日は不可 |
| 持ち込めない | 家電リサイクル法の対象品目、パソコン、排出禁止物（農薬、タイヤ、塗料など） |
| 資源物 | 対象外。集積所や拠点回収を使う |

施設は、住む区によって違います。鎧潟クリーンセンターは、土日・祝休日も午前8時30分〜正午と午後1時〜3時に受け付けます。事前に、市のページで確認してください。

### 長岡市

長岡市は、持ち込みを、引っ越しなどで多量のごみが出た場合に限っています。前日までに電話をして、施設の確認を受けます。

| 項目 | 内容 |
|---|---|
| 施設 | 寿クリーンセンター（燃やすごみのみ）、中之島信条クリーンセンター（燃やすごみ、燃やさないごみ、粗大ごみ） |
| 受付 | 月曜日から土曜日の午前8時30分から午後4時30分。祝日と年末年始は休み |
| 指定袋入り | 無料 |
| 指定袋なし | 100kgまで300円。超えた分は10kgあたり30円を加算 |
| 粗大ごみ | 200円、600円、1,000円。戸別収集と同額 |
| 持ち込み方 | 中身が見えるようにする。段ボール箱に入れての持ち込みは禁止。大きい物は50cm四方に切る |

### 上越市・三条市・柏崎市

- 上越市は、木製家具や畳などの燃やせるごみを、クリーンセンターへ直接搬入できます。手数料は、10kgまでごとに30円です。指定袋・指定シールで搬入する場合は、手数料がかかりません。受付日時は、ページに書かれていませんでした。[要確認: 上越市クリーンセンターの受付日時]
- 三条市は、品目別分別表（2026年9月18日現在）で、茶碗・トロフィー・陶磁器を燃えないごみとしています。茶碗は、セトモノ・金属・ガラス製です。人形と写真は燃えるごみです。本は古紙類で、ビニールカバーははずします。アルバムは必ずばらして、燃えるごみに出します。
- 柏崎市は、クリーンセンターかしわざきに、燃やすごみ、燃やさないごみ、粗大ごみを持ち込めます。平日は午前8時30分から午後4時30分、土曜日と祝日は午前8時30分から午前11時30分です。資源物は対象外です。

どれも、公式の持ち込みの案内がある範囲です。量が多すぎる場合の業者への依頼は、[自分で出す？業者に頼む？](../jibun-de-dasu-ka-gyousha-ka/)で比べています。

## 小物を片付ける順番

1. 残すもの（写真、手紙、思い出の品）を、先に分けます。
2. 使える食器と衣類は、拠点回収や古着回収に回せるかを、確認します。
3. 本と雑誌は、月2回の古紙回収の日に合わせて、縛ります。
4. 割れ物は、包んで「割れ物危険」「キケン」と表示します。
5. スプレー缶と薬は、他のごみと別にします。
6. 人形は、ごみにするか、供養に出すかを決めます。

家全体の進め方は、[実家の片付けで親が捨てさせないとき](../jikka-katazuke-oya-ga-sutenai/)も参考になります。

## よくある質問

### 食器は、燃やさないごみですか。

陶磁器、ガラス、金属製の食器は、新潟市・長岡市とも燃やさないごみです。割れ物は、包んで「割れ物危険」（新潟市）、「キケン」「ワレモノ」（長岡市）と表示します。長岡市は、壊れていない食器を、拠点回収にも出せます。会場により日程が違います。

### 本を大量に処分する方法は、ありますか。

新潟市も長岡市も、本は古紙として、月2回の回収に出せます。紐で縛って出します。一度に出せる上限は、公式ページに書かれていませんでした。長岡市は、拠点回収にも古紙を持ち込めます。新潟市の自己搬入は、古紙が対象外です。

### 人形供養は、どこでできますか。

公式サイトで確認できた例は、新潟縣護國神社（新潟市）と千手観音千蔵院（長岡市）です。護國神社は、45リットルの袋に入るだけを1件とします。ガラスケースは受け付けません。受付日と料金は、公式ページで確認できませんでした。事前に、各寺社に確認してください。

### 写真は、どう処分すればいいですか。

新潟市・長岡市とも、写真は燃やすごみです。新潟市は、写真を古紙に出せません。長岡市は、拠点回収のミックスペーパーに、写真を出せます。人の顔や名前が写っている場合は、袋の外から見えないようにします。お焚き上げを受ける寺社は、公式サイトで確かめます。

### 衣類を大量に処分するには、どうしますか。

新潟市は、洗濯済みで汚れや破れのない衣類を、古布・古着の回収場所に出せます。着物も対象で、布団は対象外です。汚れた服は、燃やすごみです。長岡市は、古着・古布がステーション収集で、月2回です。1月から3月は収集がありません。拠点回収も使えます。
