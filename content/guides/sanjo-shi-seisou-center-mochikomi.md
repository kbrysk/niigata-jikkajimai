# 三条市清掃センターへの持ち込み｜受付時間・料金・流れ・持ち込めない物

## 結論：月〜土の8:30〜17:00。重さで10kgあたり65円、粗大ごみも重さで精算します

三条市清掃センターは、三条市福島新田乙239にあります。電話は0256-45-4797です。

- **いつ行けるか**：月曜日〜土曜日の8:30〜17:00です。祝日も営業しています。日曜日と年始は休みです。手続きがあるため、16:30までに着くよう市が案内しています。
- **いくらか**：ごみの重さ10kgあたり65円です。粗大ごみ（布団、タンス、ストーブなど）も、重さで精算します。粗大ごみ処理券は買わなくて構いません。
- **手数料がかからない場合**：三条市の指定ごみ袋に入れた家庭ごみと、粗大ごみ処理券（シール）を貼った家庭ごみは、清掃センターでの手数料がかかりません。計量も精算も不要です。
- **予約**：公式ページに、予約が必要とは書かれていません。
- **持ち込める人・ごみ**：三条市内で出た家庭ごみです。三条市外で出たごみは持ち込めません。
- **持ち込めない物**：家電4品目、パソコン、スプリング入りのソファ・マットレス、ピアノなど。神棚・仏壇は、魂抜きなどをして解体した場合だけ持ち込めます。

この記事は、三条市の公式情報だけでまとめました。内容は2026年10月17日の確認時点です。持ち込む前に、公式ページで最新の情報を見てください。

- 受付時間・休み・所在地・電話
- 搬入の流れ（受付棟での記入から精算まで）

- 持ち込めない物と、持ち込み先が別の物
- 実家の片付けで持ち込むときの手順

## 受付時間と休み

清掃センターのページ（2026年8月10日更新）の記載です。

| 項目 | 内容 |
|------|------|
| 受付時間 | 月曜日〜土曜日（祝日は営業）の午前8時30分〜午後5時 |
| 入口ゲート | 午後5時に閉まる |
| 来所の目安 | 搬入の手続きがあるため、午後4時30分までに来るよう案内 |
| 休み | 日曜日、1月1日〜1月3日 |

手続きと精算に時間がかかります。市のパンフレットも「時間に余裕を持って持ち込んでください」と案内しています。

年末年始の休みは、公式の資料で書き方が違います。

- 清掃センターのページ（2026年8月10日更新）は、「1月1日〜1月3日」です。
- 令和8年度の「家庭ごみの分け方・出し方」（PDF）は、「12/31PM〜1/3は休み」です。

PDFには、年末の営業日の詳細は広報さんじょうの12月1日号に載せる、とあります。この年末の営業日は、確認できていません。[要確認: 年末年始の休業日（広報さんじょう12月1日号、または清掃センター 0256-45-4797）]

## 搬入の流れ

搬入の流れは、市の「ストックヤード（ごみ持込みの流れ）」のページ（2025年7月9日更新）に、図で載っています。指定袋やシールを使うかどうかで、流れが変わります。

### 指定袋・粗大ごみシールを使わない場合

重さで精算する流れです。市のパンフレット（令和8年度「家庭ごみの分け方・出し方」、2ページ）にも、同じ5段階が載っています。

1. 受付棟で、廃棄物処分依頼書に記入します。
2. 車両ごと計量します。
3. ストックヤード構内に入り、ごみを降ろします。ごみの種類によって、置き場所が分かれています。
4. ごみを降ろしたあと、もう一度、車両ごと計量します。
5. 受付棟で精算します。

降ろす前と後の重さの差で、料金を計算する流れです。ごみの分別と積み下ろしは、搬入する人が自分で行います。

### 指定袋に入れたごみ・粗大ごみシールを貼ったごみ

受付棟脇の「指定カゴ」に入れます。計量と精算の手間が省けます。パンフレットでも、指定袋に入れた燃えるごみ・燃えないごみは「精算手続き不要」です。

### 持ち込むときの決まり

次の決まりが、同じパンフレットに載っています。

- 粗大ごみ、燃えるごみ、燃えないごみを、種類ごとに分けます。
- 燃えるごみ・燃えないごみは、透明か半透明の袋に入れます。
- タンスなど、粗大ごみの品目にある物は、切ったり分解したりしなくて構いません。

粗大ごみを1人で降ろせないときは、2人以上で来るよう、市の粗大ごみのページ（2025年12月18日更新）に案内があります。

## 料金：10kgあたり65円

料金は、清掃センターのページに「ごみの重量10キログラム当たり65円」とあります。

| 持ち込み方 | 手数料 |
|------|------|
| 三条市の指定ごみ袋に入れた家庭ごみ | 清掃センターでは手数料なし |
| 粗大ごみ処理券（シール）を貼った家庭ごみ | 清掃センターでは手数料なし |
| 上記以外（粗大ごみを含む） | ごみの重量10kgあたり65円 |

10kgあたり65円で単純に計算すると、次のとおりです。

| ごみの重さ | 手数料 |
|------|------|
| 50kg | 325円 |
| 100kg | 650円 |
| 200kg | 1,300円 |

10kgに満たない端数の扱いは、公式ページに記載がありません。精算のときに、受付棟で聞いてください。支払い方法（現金かキャッシュレスか）の記載もありません。念のため、現金を用意すると安心です。

### 粗大ごみ処理券は、持ち込みでは買わなくて構いません

市の「粗大ごみの出し方」のページと「よくある質問」は、粗大ごみを清掃センターへ直接持ち込むときは、重さで精算するため処理券は不要としています。処理券を買うのは、戸別収集に出すときです。

処理券は、大1,000円・中500円・小300円の3種類です（市の「粗大ごみ処理券（シール）」ページ、2025年4月25日更新）。1枚ずつ売っています。

## 持ち込める物・持ち込めない物

### 持ち込める物

清掃センターのページは、受け入れできる物を、燃えるごみ・燃えないごみ・粗大ごみと案内しています。市の「よくある質問」には、布団、タンス、ストーブなどの粗大ごみを、清掃センターへ直接持ち込める、とあります。細かい分け方は、市の「家庭ごみの分け方・出し方」で確認します。

### 持ち込めない物

次の2つは、持ち込めません。

- 三条市外で発生したごみ（市の「ストックヤード（ごみ持込みの流れ）」ページ）
- 「市で引取りできないごみ」（清掃センターのページが案内）

事業所で出たごみには、指定袋も粗大ごみ処理券（シール）も使えません。

「市で引取りできないごみ」のページ（2024年6月10日更新）にある主な品目は、次のとおりです。

| 区分 | 品目 |
|------|------|
| 家電リサイクル品 | テレビ、エアコン、冷蔵庫・冷凍庫、洗濯機、衣類乾燥機 |
| パソコン | デスクトップパソコン、ディスプレイ（ノートパソコンは小型家電回収ボックス） |
| 処理困難物 | スプリング入りソファ、スプリング入りマットレス、ピアノ、耐火金庫、健康器具、温水器・給湯器、オイルヒーター、建築資材、便器、農業用ビニール、廃油、石・砂利などの自然物 ほか |
| 消火器・オートバイ・注射針など | 専用の処分方法が案内されている |

このほかにも、材質などで引き取れない物があります。迷う物は、清掃センターに問い合わせるよう、市が案内しています。

次の2つは、例外や持ち込み先が別です。

- 神棚・仏壇：魂抜きなどの処置をして解体した場合に限り、清掃センターへ直接搬入できます。
- 庭木のせん定枝：清掃センターではなく、「緑のリサイクルセンター」へ持ち込みます（三条市代官島2721-1、電話0256-34-4921）。市内で発生したせん定枝が対象で、無料です。枝は長さ30cm〜1m・太さ10cm未満、樹木の幹は長さ50cm以下・太さ10〜50cmです。受入日は、市のページ（2026年5月21日更新）にある「令和8年度せん定枝受入カレンダー」で確認します。

リチウムイオン電池などの充電式電池は、指定袋に入れて出さないよう、市が強く呼びかけています。清掃センターでは、2022年3月28日に、指定袋に混ざった電池が原因の火災が起きました。2025年11月13日にも、電池が原因と推定される火災が起きています。

家電4品目の出し方は、[新潟の家電4品目の出し方](../kaden4hinmoku-niigata/)にまとめています。

## 実家の片付けで持ち込むときの手順

三条市の条件は、「三条市外で発生したごみは不可」です。実家が三条市内なら、そこから出たごみは市内で発生したごみです。持ち込む人の住所や、1回に持ち込める量の上限は、公式ページに記載がありません。

次の順で進めます。

1. 出す物をリストにします。品目、大きさ、数量を書きます。
2. 市で引取りできない物を、先に外します。
3. 予約が必要とは書かれていませんが、初めてのときは、清掃センターへ電話で聞いておくと安心です。
4. 燃えるごみ・燃えないごみは、透明か半透明の袋に分けます。指定袋なら精算が不要です。
5. 粗大ごみは、種類ごとに分けて車に積みます。降ろしやすい順にします。
6. 16:30までに着くように行きます。
7. 受付棟で記入し、計量、荷降ろし、再計量、精算の順に進みます。

家屋の中から運び出せないときや、自分で持ち込めないときは、一般廃棄物収集運搬許可業者に頼みます。料金は業者ごとに違います（市の粗大ごみのページの案内）。許可業者の確かめ方は、[上越・柏崎・新発田・三条の許可業者の確認方法](../joetsu-kashiwazaki-shibata-sanjo-kyoka-gyosha/)にあります。

自分で運ぶか業者に頼むかの考え方は、[自分で出す？業者に頼む？](../jibun-de-dasu-ka-gyousha-ka/)が判断の材料になります。

粗大ごみの戸別収集は、持ち込みとは別の制度です。申込先や処理券の金額は、[上越市・三条市の粗大ごみの出し方](../joetsu-sanjo-sodaigomi/)で説明しています。この記事では、重ねて書きません。

## 三条市清掃センター、よくある質問

**Q　三条市清掃センターの受付時間は、何時までですか。**
月〜土の8:30〜17:00です。祝日も営業しています。17:00に入口ゲートが閉まり、手続きのため16:30までに来るよう案内されています。

**Q　三条市清掃センターの持ち込み料金は、いくらですか。**
ごみの重量10kgあたり65円です。三条市の指定ごみ袋に入れた家庭ごみと、粗大ごみ処理券を貼った家庭ごみは、手数料がかかりません。

**Q　タンスや布団などの粗大ごみも持ち込めますか。粗大ごみ処理券は要りますか。**
持ち込めます。重さで精算するため、処理券は買わなくて構いません。

**Q　三条市清掃センターに、予約は要りますか。**
公式ページに、予約が必要とは書かれていません。初めてのときは、清掃センター（0256-45-4797）へ電話で聞いておくと安心です。

**Q　三条市清掃センターは、日曜日や祝日も開いていますか。**
日曜日は休みです。祝日は営業しています。年始は、清掃センターのページでは1月1日〜1月3日が休みです。年末の営業日は、広報さんじょうの12月1日号で案内されます。

**Q　三条市清掃センターで、持ち込めない物は何ですか。**
三条市外で出たごみと、「市で引取りできないごみ」です。家電4品目、パソコン、スプリング入りのソファ・マットレス、ピアノなどが当たります。せん定枝は「緑のリサイクルセンター」へ持ち込みます。
