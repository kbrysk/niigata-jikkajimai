# 実家じまいでやってはいけない7つのこと｜後戻りできない失敗を先に知る

実家じまいで取り返しがつかないのは、次の7つです。合意前の処分、無許可業者、補助金の着工後の申請、税の思い込み、名義の放置などです。どれも、先に確認すれば防げます。迷ったら、いったん止めて、市の窓口か専門家に確認してください。

## 7つの早見表

| やってはいけないこと | 先にやること |
|---|---|
| 相続人の合意前に処分する | 全員で話し合い、意向を確認する |
| 書類を確認せず片付ける | 遺言書・通帳・年金書類を1か所に集める |
| 無許可業者に任せる | 市の許可業者を確認し、複数社の見積りを取る |
| 着工後に補助金を申請する | 着工前に市町村へ相談・申請する |
| 税を思い込みで判断する | 解体前に、税額の変化を市で確認する |
| 名義を放置する | 3年以内の相続登記を、司法書士に相談する |
| 雪の季節に動く | 初冬までに作業を終え、冬は管理に徹する |

## この記事で分かること

- 実家じまいで、あとから取り返しにくい7つの失敗
- それぞれの根拠（国・県・市の公式ページ）
- 税や法律の判断が必要な場面で、どこに相談するか

実家じまいは、手順を間違えても「やり直し」がききにくい作業です。壊した家は戻りません。捨てた物も戻りません。

この記事は、失敗の多い場面を7つに絞りました。どれも、公的機関のページに根拠があるものです。税や法律の個別判断は、税理士・司法書士・弁護士などの専門家に相談してください。

## 1. 相続人の合意がないまま、家財や家を処分する

親が亡くなったあとの家や家財は、相続の対象です。相続人が複数いるときは、全員の話し合いで分け方を決めるのが基本です。

話し合いがまとまらないときは、家庭裁判所の調停という手続きがあります。裁判所のページには、遺産分割調停の流れが載っています。

先に処分してしまうと、あとで揉める原因になります。「勝手に捨てた」「あの品は価値があった」といった争いです。

自治体の補助金でも、合意を求めるものがあります。

- 胎内市の空き家等解体補助金は、相続人がいる場合、全相続人の同意を条件にしています。
- 妙高市の特定空き家等除却費補助金は、権利者全員の同意を条件にしています。

やってはいけないのは、**全員の了解を取る前に、家や大きな家財を処分すること**です。

親がご存命のうちは、家の物は親のものです。親の了解なしに処分しないでください。

相続放棄を考えている場合は、さらに注意が要ります。相続放棄は「自己のために相続の開始があったことを知ったときから3か月以内」に、家庭裁判所へ申述します。この期間内に、遺品を処分してよいかどうかは、専門家に確認してください。

## 2. 貴重品と書類を確認せずに、片付けを始める

片付けを急ぐと、大事な物をごみと一緒に出してしまいます。先に探すのは、次のような物です。

- 遺言書
- 通帳、保険証券、年金関係の書類
- 不動産の権利に関する書類、固定資産税の納税通知書
- 契約書、借入に関する書類

**遺言書**は特に注意が必要です。封のされた遺言書は、家庭裁判所で相続人などの立会いのもとで開封する手続き（検認）があります。裁判所のページに案内があります。見つけても、自分で開けないでください。

**年金**も確認が必要です。年金を受けていた人が亡くなったときは、届出をします。日本年金機構のページによると、提出が遅れると、受け取りすぎた年金を後から返す場合があります。未支給の年金を、同じ生計だった遺族が受け取れる場合もあります。

書類は、捨てる前に「いったん1か所に集める」と決めておくと安全です。仕分けは、そのあとです。

## 3. 「無料回収」「格安」の業者に、そのまま任せる

家庭から出るごみの収集運搬は、市町村の許可が必要です。環境省のページは、許可のない回収業者を使わないよう呼びかけています。理由として、不法投棄の例があることや、高額な料金を請求される例があることを挙げています。

国民生活センターは、次のようなトラブルを公表しています。

- 定額パックを頼んだのに、作業後に高額な料金を請求された
- 遺品整理で、作業当日に追加料金が出て、見積りの2倍になった
- 「処分しないで」と頼んだ品が、処分された

対策は、国民生活センターが示しています。

- 市区町村のホームページで、許可業者を確認する
- 複数社から見積りを取る
- 追加料金とキャンセル料を、事前に確認する
- 納得できなければ、その場で支払わない。困ったら消費者ホットライン188へ

詳しい分かれ目は、[自分で出す？業者に頼む？新潟の実家片付け、分かれ目の5つの基準](../jibun-de-dasu-ka-gyousha-ka/) にまとめています。

## 4. 解体補助金を、着工前に申請しない

空き家の解体には、市町村の補助金があります。ただし、公式ページで確認できた多くの制度は、**着工したあとの申請を対象外**としています。

次は、公式ページにある記載です。

| 市 | 公式ページの記載（要旨） |
|---|---|
| 上越市 | 施工業者との契約・除却工事の前に申請する。申請前に契約・着手すると対象外 |
| 柏崎市 | 解体工事の前に、審査・交付申請・交付決定が必要。決定前に着手した工事は対象外 |
| 魚沼市 | 交付決定前に着手した工事は対象外（契約を含む） |
| 南魚沼市 | 交付決定を受けてから着工する。決定前に着工した工事は対象外 |

**受付期間にも注意**が必要です。令和8年度は、受付がもう終わった制度があります。

- 十日町市: 2026年4月13日〜5月13日（終了済み）
- 魚沼市: 2026年5月14日〜5月29日（終了済み）
- 村上市: 2026年4月15日〜5月15日（終了済み）

予算に達した時点で終わる制度も多くあります。県内30市町村の一覧は、[実家じまいに使える補助金｜新潟県30市町村の空き家解体補助金一覧](../jikkajimai-hojokin-niigata/) にまとめています。

長岡市は、個人が申し込める老朽空き家の解体補助を、公式ページで確認できませんでした。市の補助金は、町内会などの地域団体が対象です。「補助があるはず」と思い込んで先に壊さないよう、市の窓口で確認してください。

## 5. 空き家の「固定資産税」を、思い込みで判断する

固定資産税には、住宅用地の特例があります。新潟市のページによると、課税の基準になる額は、住宅用地の広さで変わります。

- 小規模住宅用地（200平方メートル以下）：価格の6分の1
- 一般住宅用地（200平方メートル超）：価格の3分の1

思い込みやすい点は、2つあります。

**① 空き家を放っておいても、税は変わらない**

変わる場合があります。空家法は2023年に改正されました。国土交通省のページによると、特定空家になる前の「管理不全空家」も、市町村の指導の対象です。勧告を受けると、住宅用地の特例が受けられなくなります。

**② 解体すれば、税が安くなる**

そうとは限りません。南魚沼市の補助金ページに、注意書きがあります。解体後の土地は、住宅用地の特例が適用されなくなり、固定資産税などが上がります。

解体の前に、税額がどう変わるか、市の税務担当で確認してください。売る場合の税金は、国税庁の案内があります。相続した空き家を売ったときは、条件を満たせば、最高3,000万円の控除があります。

- 相続人が3人以上の場合は、控除額が2,000万円です（2024年1月1日以後の売却）
- 売却は、相続開始から3年を経過する年の12月31日までに行います
- この特例の対象は、2027年12月31日までの売却です
- 売却代金が1億円以下であることが条件です
- 1981年5月31日以前の建築であることなど、ほかにも条件があります

適用できるかどうかは、税務署か税理士に確認してください。

空き家の売る・貸す・壊すの比べ方は、[新潟の実家が空き家になったら](../akiya-uru-kasu-kowasu/) で整理しています。

## 6. 名義を、親のままにしておく

実家の名義が親や祖父母のままだと、売ることも、補助金を申し込むことも難しくなります。

法務省のページによると、**相続登記は2024年4月1日から義務化**されました。

- 相続で不動産を取得したと知った日から、3年以内に登記を申請する
- 正当な理由なく怠ると、10万円以下の過料の対象になる
- 2024年4月1日より前に相続した不動産も対象。期限は2027年3月31日まで

遺産分割がまとまらないときは、「相続人申告登記」を申し出る方法があります。申し出れば、申請義務を果たしたものとみなされます。ただし、権利関係を公示するものではありません。売却や抵当権の設定のときは、別に相続登記が必要です。

登記は、司法書士に相談できます。名義の確認は、解体や売却を決める前に済ませておくと、動きやすくなります。

兄弟姉妹で、とりあえず共有名義にする方法もあります。ただし、共有物に重大な変更を加えるときは、共有者全員の同意が必要です（法務省）。決め方は、司法書士や弁護士に相談してください。

## 7. 冬の雪を見越さずに、日程を組む

新潟では、冬に作業が止まります。そして、雪は空き家の問題になります。

新潟県は、空き家の管理は所有者の責任だと案内しています。雪処理が不十分な空き家には、落雪や倒壊の危険があります。雪が積もった空き家には、近づかないよう呼びかけています。

雪下ろしは、命に関わる作業です。県のページによると、令和6年度の除雪作業による人的被害は137件でした。死亡事故の多くは、一人作業中に起きています。屋根やはしごからの転落が主な原因です。

実家じまいの日程は、次のように考えると安全です。

- 10〜11月のうちに、片付けと業者の見積りを終える
- 冬は、家の状態の確認と、雪の管理の手配にとどめる
- 解体や大きな工事は、雪が解けたあとに組む

制度や費用の詳細は、[冬の実家じまいと雪対策](../fuyu-no-jikkajimai-yukioroshi/) にまとめています。

## よくある質問

### 実家じまいで、最初にやってはいけないことは何ですか？

相続人全員の了解を取る前に、家や大きな家財を処分することです。あとで「勝手に捨てた」と争いになる原因です。親がご存命なら、親の了解が先です。

### 補助金は、解体したあとに申請できますか？

公式ページで確認できた多くの制度は、着工後の申請を対象外としています。契約や着手の前に、市町村の窓口へ相談してください。

### 家を解体すると、固定資産税は安くなりますか？

安くなるとは限りません。南魚沼市のページには、解体後の土地は住宅用地の特例が外れ、税が上がるとあります。解体の前に、市の税務担当へ確認してください。

### 相続登記をしないと、どうなりますか？

相続で取得したと知った日から3年以内に申請しないと、10万円以下の過料の対象になる場合があります。2024年4月1日より前の相続は、2027年3月31日までです。

### 「無料回収」の業者に頼んでも大丈夫ですか？

おすすめしません。家庭ごみの収集運搬には、市町村の許可が必要です。環境省は、許可のない回収業者を使わないよう呼びかけています。

### 遺言書を見つけたら、開けてもよいですか？

封がされている場合は、開けないでください。家庭裁判所で、相続人などの立会いのもとで開封します（検認）。

### 冬に実家じまいを進めてもよいですか？

雪下ろしは危険です。片付けと見積りは初冬までに終え、冬は管理にとどめると安全です。
