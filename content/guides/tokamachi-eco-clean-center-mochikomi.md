# 十日町市エコクリーンセンターの持ち込み｜受付日時・料金・流れ・持ち込めない物

## 結論：月〜土の8:45〜17:00。家庭ごみは50kgまで450円です

十日町市エコクリーンセンター（十日町市高田町六丁目915番地2）は、ごみを自分で運べる市の施設です。持ち込めるのは、燃やすごみと埋立てごみです。

- 受付：月〜土曜の8:45〜17:00。日曜、祝日、12月31日〜1月3日は休み
- 手数料（家庭系）：50kgまで450円。50kgを超えると、10kgごとに90円が加わる
- 計量：燃やすごみと埋立てごみを同じ車で運ぶときは、種類ごとに量って、種類ごとに手数料を払う
- 袋：市の指定袋は使わず、市販の透明か半透明の袋に入れる（指定袋でも受け付けるが、手数料は同じ）
- 大きさ：長さ200cm以内、幅90cm以内
- 持ち込める物：ステーションに出せる燃やすごみ・埋立てごみ、布団、畳、木製家具、材木・枝・草、コンクリートがらなど
- 持ち込めない物：長さ200cm・幅90cmを超える家具、農業用マルチ2袋以上、塩ビ管、化学畳、建屋の材木、分解していない物。家電4品目、ピアノ、消火器、農機具は、市の品目表で「収集しない」物

資源物（紙類、ペットボトル、びんなど）は、同じ敷地の「資源物回収センター」へ運びます。無料です。受付は通りません。

予約が要るかどうかは、公式ページに書かれていません。不安なときは、電話（025-752-3924）で確かめます。この記事は、十日町市の公式情報だけでまとめました。確認日は2026年10月17日です。

## 受付の日時と休み

市のページ（2024年9月20日更新）と、市の冊子「ごみ・資源物の自己搬入」のページは、同じ内容です。

- 搬入日は、月曜日から土曜日です。
- 日曜日、祝日、年末年始（12月31日〜1月3日）は、休みです。
- 搬入時間は、午前8時45分から午後5時までです。

昼休みの記載は、ありません。資源物回収センターも、同じ日時です。

ごみの状況によっては、受付できない場合があります。冊子の注意事項にあります。

市の別の案内（ボランティア清掃向け）には、ごみ焼却場は平日の13〜14時が混雑しにくい、と書かれています。

## 所在地と電話

所在地は、〒948-0056 十日町市高田町六丁目915番地2です。環境衛生課 廃棄物対策係の事務所も、この敷地の中にあります。

電話は、025-752-3924です。環境衛生課 廃棄物対策係の直通で、ファクスは025-757-1751です。市の冊子の「家庭用ごみ分別品目表」（令和4年4月1日現在）には、「エコクリーンセンター（025-755-5587）」とも書かれています。市の現在のページは、025-752-3924です。

## 搬入の流れ

市の冊子には、搬入の方法が、次のように書かれています。

| 持ち込む物 | 流れ |
|------|------|
| 燃やすごみ、埋立てごみ | エコクリーンセンターの受付を通る。係員の指示に従う |
| 廃食用油、危険・有害物、小型家電、インクカートリッジ | 受付に声をかけて、職員の指示に従って搬入する |
| 資源物 | 受付を通らず、直接「資源物回収センター」に搬入する |

燃やすごみと埋立てごみを、同じ車で運ぶときは、種類ごとに重さを量ります。手数料も、種類ごとに払います。支払いの方法は、書かれていません。

搬入の前に、次のことが求められています。

- 中身を確認しやすい、透明か半透明の袋を使います。
- ごみを、しっかり分解・分別します。
- 市指定ごみ袋は使いません。指定袋で持ち込んでも受け付けますが、手数料の減免や袋の返却はありません。
- 家具と寝具は、金属部分を取り除きます。
- 長さ200cm、幅90cmを超える物は、分解するなどして小さくします。

## 手数料（家庭系）と計算例

| 処理量 | 家庭系の手数料 |
|------|------|
| 50kgまで | 450円 |
| 50kgを超える分 | 10kg増すごとに90円 |

令和6年4月1日現在の額です。事業系は、50kgまで550円、10kg増すごとに110円です。

家庭系の計算例です。

| 搬入量 | 手数料 |
|------|------|
| 30kg | 450円 |
| 50kg | 450円 |
| 80kg | 450円＋90円×3＝720円 |
| 100kg | 450円＋90円×5＝900円 |
| 150kg | 450円＋90円×10＝1,350円 |

10kgに満たない端数の計算は、書かれていません。窓口で確かめます。

燃やすごみと埋立てごみを、1台の車で運ぶと、種類ごとに計算します。燃やすごみ40kg、埋立てごみ40kgなら、それぞれ450円で、合計900円になります。これは、公式の「種別ごとに手数料を徴収」の記載から出した計算です。

資源物、廃食用油、危険・有害物、小型家電、インクカートリッジは、無料です。ただし、LEDランプと白熱球は、埋立てごみのため有料です。

## 持ち込めるもの

### 燃やすごみ

出せる大きさは、長さ200cm以内、幅90cm以内です。ステーションに出せる燃やすごみも、持ち込めます。指定袋に入っていても、手数料は必要です。

| 区分 | 例 | 注意 |
|------|------|------|
| 布類など | カーテン、カーペット、ブルーシート、布団、毛布 | |
| 建具・家具 | 木製家具、畳、障子戸、ふすま | 長さ200cm以内、幅90cm以内にして、金属部分を取り除く。畳、障子戸、ふすまは、1日6枚まで |
| 材木・木の枝・草 | 材木、囲い板、草 | 長さ200cm以内、直径9cm以内。材木は1日10本以内 |

### 埋立てごみ

| 区分 | 例 |
|------|------|
| ステーションに出せる埋立てごみ | ガラス類、陶器類、電化製品など |
| 大型の物・重い物 | コンクリートがら（30kgまで）、モルタルがら（30kgまで）、セメントがら（30kgまで）、アンテナ、レンガ（5個まで）、コンクリートブロック（5個まで）、長さ120cm・直径50cm・重さ30kgを超える物 |

大型のごみは、エコクリーンセンター内の「粗大ごみ破砕機」で、焼却炉に入れられる大きさに砕かれます。

### 無料で受け付ける物

次の物は、受付に声をかけて、職員の指示に従って搬入します。事業所から出た物は、搬入できません。

| 品目 | 条件 |
|------|------|
| 廃食用油 | 家庭で使った植物性の食用油。「揚げかす」などの固形物を取り除き、ペットボトルなどに入れる。動物性・鉱物性の油、水分を含む物は不可 |
| 危険・有害物 | 使い捨てライター（ガスを使い切る）、電池類、家庭用の蛍光灯、水銀体温計・水銀血圧計など。割れた蛍光灯は埋立てごみ |
| 小型家電 | 携帯電話、パソコン、タブレット、DVD・BDレコーダー、ゲーム機、USBメモリー、ACアダプターなど。電池は外し、データは消す。分解しない |
| インクカートリッジ | インクジェット式プリンター用のみ。トナーカートリッジ、廃トナーは不可 |

小型家電で、対象でない物は、「埋立てごみの日」にステーションに出します。

## 持ち込めない物

市の冊子に、搬入できない物が、次のとおり書かれています。

| 区分 | 搬入できない物 |
|------|------|
| 燃やすごみ | 長さ200cm・幅90cmを超える建具・家具。長さ200cm・直径9cmを超える木材・木の枝。指定袋（中）2袋以上の農業用マルチ・農業用ビニール。塩ビ管、ポリ管、あぜシート。化学畳（発泡プラスチック系断熱材入り）。建屋に使用された材木・板 |
| 埋立てごみ | 分解・分別していない物（例：ガラス戸のガラスと枠）。長さ200cm・幅90cmを超える物 |
| 無料の品目 | 事業所から出た物 |

市の「家庭用ごみ分別品目表」（令和4年4月1日現在）には、次の記載があります。この表の「収集しない」は、ごみステーションの収集についての表です。施設で受け付けるかどうかは、表に書かれていません。上の「搬入できない物」に当てはまらないときは、電話で確かめます。

- ピアノ、オルガンなど、分解・運搬ができない物は、収集しません。
- 消火器、農機具は、収集しません。
- トナーカートリッジは、収集しません。家電販売店などの回収ボックスに出します。
- テレビ、エアコン、冷蔵庫・冷凍庫、洗濯機、衣類乾燥機は、家電リサイクルの対象です。家電販売店へ相談します。

家電4品目の処分方法は、市の「家電4品目・パソコンの廃棄（リサイクル）の方法」のページ（2024年3月1日更新）にあります。方法は3つです。購入店か買い替え先に頼む、市の許可業者に頼む、指定引取場所へ自分で持ち込む、の3つです。指定引取場所は、長岡市の2か所（株式会社豊和商事本社、日本通運株式会社中越支店）です。持ち込む前に、引取場所へ連絡します。詳しくは、[新潟の家電4品目の出し方](../kaden4hinmoku-niigata/)にあります。

## 予約は要りますか

公式ページに、予約や申込の記載はありません。

冊子には、「受付を通ってください」とあります。

## 資源物回収センター（同じ敷地）

家庭から出る資源物は、無料で回収されます。受付を通らず、直接持ち込みます。

| 項目 | 内容 |
|------|------|
| 品目 | 紙類、ペットボトル、プラスチック類、ガラスびん、あき缶（アルミ缶、スチール缶、スプレー缶）、古着など |
| 日時 | エコクリーンセンターと同じ（月〜土 8:45〜17:00） |
| 不可 | 事業所から出た物。指定品目以外 |

冊子には、指定品目以外を搬入すると、不法投棄として処罰されることがある、と書かれています。車は駐車場に停めて搬入します。出入口の付近は駐車禁止です。

## 量が多いとき・運べないとき

ステーションに出せない大きな物や、重い物で、分解や自己搬入が難しい場合は、運搬の許可を持つ業者に頼みます。有料です。冊子の品目表の最初の注意書きにあります。

処理が難しい一部のごみには、1日に出せる数量の制限があります（例：○枚まで、○個まで、○○kg以下）。一度に大量に出る場合は、数日に分けるか、専門業者に相談するよう、品目表に書かれています。

許可業者は、市の「業者にごみの収集運搬を依頼する場合」のページ（2024年2月29日更新）に載っています。料金は、各業者に直接聞きます。最新の一覧は、市のページで確かめます。

十日町市の粗大ごみの考え方は、[十日町市・魚沼市・南魚沼市の粗大ごみの出し方](../tokamachi-uonuma-sodaigomi/)にまとめています。冬の実家の片付けは、[冬の実家じまいと雪おろし](../fuyu-no-jikkajimai-yukioroshi/)を見てください。自分で運ぶか、業者に頼むかは、[自分で出す？業者に頼む？](../jibun-de-dasu-ka-gyousha-ka/)が判断の材料になります。

## よくある質問

**Q　十日町市エコクリーンセンターの受付時間は、何時までですか。**
月〜土曜の8:45〜17:00です。日曜、祝日、12月31日〜1月3日は休みです。

**Q　十日町市のごみ持ち込みは、いくらですか。**
家庭系は、50kgまで450円です。50kgを超える分は、10kgごとに90円です。燃やすごみと埋立てごみは、種類ごとに計算します。

**Q　十日町市のごみ持ち込みで、袋は何を使いますか。**
市指定ごみ袋は使わず、市販の透明か半透明の袋を使います。指定袋でも受け付けますが、手数料の減免や袋の返却はありません。

**Q　十日町市のごみ持ち込みに、予約は要りますか。**
公式ページに、予約の記載はありません。受付を通って、係員の指示に従います。電話番号は、025-752-3924です。

**Q　十日町市のエコクリーンセンターで、家具や布団は持ち込めますか。**
長さ200cm以内、幅90cm以内にして、金属部分を取り除けば、燃やすごみとして持ち込めます。布団も、燃やすごみの持ち込める物に載っています。畳、障子戸、ふすまは、1日6枚までです。
