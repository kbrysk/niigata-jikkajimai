# 柏崎市の粗大ごみの出し方｜申込・料金・クリーンセンターかしわざきへの持ち込み

柏崎市の粗大ごみは、クリーンセンターかしわざきへ電話で申し込みます。月1回の戸別収集で、1回5点までです。処理券は1枚300円で、品目ごとに1〜3枚貼ります。自分で運ぶ場合は、点数の制限なく持ち込めます。

## この記事で分かること

- 柏崎市の粗大ごみの申し込み方法と、処理券の使い方
- 実家じまいで出やすい品目の料金（公式の分別辞典より）
- クリーンセンターかしわざきへ自分で持ち込む方法と、市で収集しない物

実家を片付けると、たんすや布団、仏壇などが一度に出ます。この記事は、柏崎市の公式情報だけでまとめました。内容は2026年10月2日の確認時点です。申し込む前に、公式ページで最新の情報を見てください。

## 申し込み方法

粗大ごみは、申込制の戸別収集です。電話で申し込みます。ネット申込は、公式に記載がありません。

| 項目 | 内容 |
|------|------|
| 電話 | 0257-23-5170（クリーンセンターかしわざき） |
| 受付時間 | 月〜金 8:30〜17:15（土日祝・年末年始を除く） |
| 点数 | 1回の申込は5点まで |
| 申込期限 | 収集日ごとに決まっています。地区別の「資源物・ごみ収集カレンダー」に記載 |
| 変更・取消 | 収集日前の受付時間内に連絡します |

受付時間は、市の「分別ガイドブック」（令和2年2月時点の情報）の記載です。最新の受付時間は[要確認: 電話の受付時間]です。

ガイドブックには別の電話番号も載っていますが、市の現在のページにある 0257-23-5170 を使います。

## 料金の仕組みと品目別料金

粗大ごみ処理券は、1枚300円です。品目ごとに決められた枚数を貼ります。300円は1枚、600円は2枚、900円は3枚です。

処理券は、市内のスーパー、コンビニなどの小売店と、柏崎市役所の売店で買えます。取扱所の一覧は、市の「指定ごみ袋・粗大ごみ処理券などの取扱所と価格」のページにあります。買った券には、氏名を書きます。アパートは、部屋番号も書きます。

処理券1枚300円は、2026年1月更新の市のページでも確認できます。ガイドブックの主な対象品目は、布団、マットレス、テレビ台、自転車、石油ストーブ、たんすです。

## 収集日と出し方

月1回、決められた収集日に、申し込んだ家へ伺います。収集日と申込期限は、地区別の収集カレンダーで確認します。

出し方は次のとおりです。

- 収集日の朝8時までに、申し込んだ品物に処理券を貼って出します。
- 出す場所は、玄関前や車庫前など、分かりやすい所です。
- 屋内には入りません。立ち会いは不要です。

収集が月1回のため、申込期限に間に合わないと、次の月になります。

## 自分で持ち込む場合

引越しや大掃除などで大量に出た場合や、収集日に出せない場合は、直接持ち込めます。

| 項目 | 内容 |
|------|------|
| 施設 | クリーンセンターかしわざき |
| 住所 | 柏崎市松波4-13-13 |
| 電話 | 0257-23-5170 |
| 受付 | 月〜金（祝日を除く）8:30〜16:30、土・祝 8:30〜11:30。日曜・12月29日〜1月3日は不可 |
| 料金 | 粗大ごみ処理券（1枚300円）を、品目の枚数分 |
| 手続き | 受付で、粗大ごみ処理申請書を提出します |
| 点数 | 制限なし。ただし畳は1日16枚まで |
| 事前連絡 | 予約の要否は、公式に記載がありません |

新しいごみ処理場の建設工事のため、受付は仮設事務所です。場所は、公式ページの図面で確認します。[要確認: 仮設事務所の場所]

処理券は、事前に市内の販売所で買います。

燃やすごみ・燃やさないごみは、指定ごみ袋に入れて持ち込みます。指定袋を使わない場合の手数料は、ガイドブック（令和2年2月時点）に「350kg以下で3,150円」とあります。最新の金額は[要確認: 指定袋なしの手数料]です。

## 市で収集しない物

市では収集できない物があります。公式の分別辞典に「収集不可」とある物の例は、次のとおりです。

| 区分 | 品目 |
|------|------|
| 家電4品目 | テレビ、エアコン、冷蔵庫・冷凍庫、洗濯機・衣類乾燥機 |
| 楽器 | ピアノ、オルガン、電子ピアノ |
| 電動の家具 | 電動ベッド、電動ソファー、介護用ベッド |
| 大型・特殊 | 耐火金庫、物置（屋外収納庫）、浴槽、除雪機 |
| 危険な物 | 消火器、ガスボンベ、灯油などの石油類、バッテリー |
| 車両関係 | タイヤ、バイク |

事業系ごみも、ごみ集積所には出せません。

### 家電4品目の出し方

方法は2つです。

1. 購入した店、または新製品を買う店に、引き取りを頼みます。
2. 指定引取場所へ、自分で持ち込みます。事前に郵便局でリサイクル料金を払います。

指定引取場所は、ガイドブック（令和2年2月時点）に載っています。上越市2か所（上越マテリアル、日本通運高田支店）と、長岡市2か所（日本通運中越支店、豊和商事本社）です。最新の情報は[要確認: 指定引取場所]です。

リサイクル料金は、家電リサイクル券センター（0120-319640）で確認できます。

## 分別で迷いやすい品目のQ&A

金額は、分別辞典（令和2年2月時点）によります。

**Q1　布団は粗大ごみですか。**
300円の粗大ごみです。50cm四方以下に切れば、燃やすごみとして出せます。毛布も同じです。

**Q2　カーペットは。**
600円の粗大ごみです。50cm四方以下に切れば、燃やすごみです。電気カーペットも600円です。

**Q3　ソファーは。**
1人用が600円、2人用以上が900円です。電動ソファーは、収集できません。

**Q4　ベッドやマットレスは。**
ベッドは900円です。ベッドマットとマットレスは、スプリングなしが300円、ありが900円です。電動ベッドと介護用ベッドは、収集できません。

**Q5　仏壇や神棚は。**
仏壇は900円の粗大ごみです。神棚は、分別辞典に品目がありません。[要確認: 神棚の分別]。位牌、仏具も同じです。[要確認: 位牌・仏具の分別]

**Q6　石油ストーブは。**
300円の粗大ごみです。灯油タンクを空にして出します。灯油そのものは、収集できません。

**Q7　電子レンジや掃除機は。**
どちらも使用済み小型家電で、燃やさないごみです。

**Q8　畳は。**
1畳300円です。クリーンセンターへ直接搬入します。1日16枚まで持ち込めます。

**Q9　パソコンは。**
使用済み小型家電として出せます。出せない場合は、ガイドブックの56ページを見ます。

## 実家をまるごと片付けるときの考え方

市の収集は月1回で、1回の申込は5点までです。量が多いと、何か月もかかることがあります。持ち込みなら点数制限はありませんが、品物を運ぶ車と人手が要ります。

ピアノ、耐火金庫、物置、家電4品目は、市の収集では出せません。実家には、こうした物がまとまってある場合があります。

次のようなときは、市の制度だけでは足りないことがあります。量が多い、市で扱わない物が多い、階段や積雪期で搬出が難しい、遠方で何度も通えない。そのときは、市の一般廃棄物収集運搬許可業者に見積りを取る方法があります。見積りの取り方は、[自分で出す？業者に頼む？](../jibun-de-dasu-ka-gyousha-ka/)を見てください。

売れる物は、リユースも選べます。柏崎市は、リユースサービス「おいくら」と連携しています。再販できる物の買取が対象です。査定によっては、引き取れない場合があります。
