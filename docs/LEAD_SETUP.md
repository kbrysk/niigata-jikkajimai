# 完全ガイド（無料PDF）の申し込みとステップメール — 仕組みと立ち上げ手順

## 1. 仕組み

| 部分 | 場所 | 役割 |
|---|---|---|
| 特典PDF | `public/dl/niigata-jikkajimai-kanzen-guide.pdf` | 「新潟の実家じまい 完全ガイド」。`node scripts/build_guide_pdf.mjs` で作り直す（Edge か Chrome が要る。GitHub Actions では作らないので、作り直したらコミットする） |
| PDFの元 | `content/roadmap/roadmap.json`・`data/*.json`・`site.json` | 進め方ページ・市町村データと同じもの。サイトを直してPDFを作り直せば、中身がそろう |
| 申し込みページ | `/kanzen-guide/`（`lead.mjs`） | フォーム（メールアドレス必須、市町村・状況は任意、同意のチェック必須） |
| 追従CTA | 全ページ（`lead.mjs` の floatCta） | PCは右下のカード（×で小さなタブに畳む。3日たつと戻る）。スマホは下部の固定バーの左ボタン「無料ガイドPDF」。申し込みページ・相談ページ・業者向けページには出さない |
| ステップメールの本文 | `content/lead/sequence.md` → `/lead/sequence.json` | 5通（すぐ・2日後・5日後・9日後・14日後）。**`approved: true` にするまで1通も送られない** |
| 受付と送信 | `scripts/gas/lead_mail.gs`（Google Apps Script） | 申し込みをスプレッドシートに記録し、Gmail で送る。配信停止リンクもここで受ける |
| 送り先の設定 | `site.json` の `lead.endpoint` | Apps Script のウェブアプリの URL（…/exec）。**空のあいだは、既存のお問い合わせ用 Google フォームに「その他のお問い合わせ」として届く**（申し込みを取りこぼさない） |
| 計測 | GA4 | 申し込み: `lead_submit`（lead_kind=kanzen_guide、lead_type=状況、city）。追従CTAのクリック: `guide_cta_click`（position=float / float-tab / sticky）。PDF内のリンクには `utm_source=kanzen_guide&utm_medium=pdf` |

申し込んだ人は、送信のあとすぐに画面のボタンから PDF を開ける。メールの配信が動いていれば、1通目に PDF を添付して送る。

## 2. 立ち上げ手順（大久保さんの作業。15分ほど）

分離ルール（docs/SEPARATION_RULES.md の C-8）に従い、**このサイト専用の Google アカウント**で行う。

1. このサイト専用の Google アカウントで、Google スプレッドシートを新しく作る（名前の例: 「新潟実家じまいナビ 完全ガイド申し込み」）。
2. スプレッドシートのメニュー「拡張機能 > Apps Script」を開き、最初からあるコードを消して、`scripts/gas/lead_mail.gs` の中身を全部貼り付けて保存する。
3. 関数の選択で `setup` を選んで「実行」。権限の確認が出たら許可する（スプレッドシート・Gmail送信・外部URLの読み込み・トリガー）。シート「leads」と、1時間ごとの `runSteps` のトリガーができる。
4. 「デプロイ > 新しいデプロイ > 種類: ウェブアプリ」。次のユーザーとして実行: **自分**、アクセスできるユーザー: **全員**。デプロイして出た URL（…/exec）を控える。
5. Apps Script の「プロジェクトの設定 > スクリプト プロパティ」に、`WEBAPP_URL` = 4. の URL を足す（配信停止リンクに使う）。
6. 関数 `sendTestToMe` を実行すると、5通がまとめて自分のアドレスに届く。文面と見た目を確かめる。
7. 4. の URL を `site.json` の `lead.endpoint` に入れて、ビルド・公開する。ここから申し込みがシートに入り、1通目（PDF添付）がすぐ届く。
8. 文面は 2026-10-12 に承認済み（`content/lead/sequence.md` が `approved: true`）。止めたいときは `false` に戻して公開する。

※ 7. より前（Apps Script の設置前）の申し込みは、お問い合わせ用 Google フォームに「その他のお問い合わせ」として届いていて、シート「leads」には入らない。その人たちには、フォームの本文で同意を確かめてから、Gmail で手動で1通目（PDFのURL）を送る。2通目以降のステップメールは届かない。

## 2.5 設置の記録（2026-10-12）

- 設置先: 運営者の個人 Google アカウント（**分離ルール C-8 の例外**。サイト専用アカウントが無かったため、大久保さんの判断で設置）。移管・売却のときは、スプレッドシート「新潟実家じまいナビ 完全ガイド申し込み」と Apps Script「新潟実家じまいナビ 完全ガイド ステップメール」の所有者を承継先に移すか、承継先のアカウントで作り直して `site.json` の lead.endpoint を差し替える。
- 手順 1〜8 は完了。スクリプト プロパティ WEBAPP_URL も設定済み。1時間ごとの runSteps トリガーも作成済み。
- コードを直したときは、Apps Script に貼り直して保存し、「デプロイ > デプロイを管理 > 編集 > バージョン: 新バージョン」で更新する（URL は変わらない）。

## 3. 運用

- 文面を直すときは `content/lead/sequence.md` を直して公開するだけ（Apps Script は10分以内に新しい文面を読む）。止めたいときは `approved: false` に戻す。
- 公開の前に、`node build.mjs && node scripts/preview_lead_mails.mjs` で5通の見た目を確かめる（`.pdf-build/mail-preview.html`。Apps Script と同じ組み立て方で表示する）。記法は `[文字](URL)` がテキストリンク、リンクだけの段落がボタン、`**太字**`。
- 名乗り・署名・差出人名は運営者の名字だけ（site.json の operatorPerson から差し込む）。返信は送信元の Gmail に届くので、運営者が読んで返す。
- 申し込み一覧・配信状況・配信停止は、スプレッドシートの「leads」で見る（状態: 配信中／配信完了／配信停止）。個人情報なので、このリポジトリには入れない。
- 無料の Google アカウントの送信上限は1日100通。1日の申し込みが30件を超えるようになったら、Google Workspace か、送信サービス（Resend など。このサイト専用のアカウントで契約）への切り替えを検討する。
- 特典PDFを作り直したら、`/kanzen-guide/` のページ数表示も自動で変わる（ビルド時にPDFから数える）。
- 移管するときは、スプレッドシートと Apps Script の所有者を、承継先の Google アカウントに移す。

## 4. 法令の確認（特定電子メール法）

- 同意: 申し込みフォームの「受け取ることに同意します」のチェックが必須。同意の日時はシートの「同意」列に残る（Google フォーム経由のときは本文に残る）。
- 表示: 全メールの末尾に、送信者名（サイト名・運営会社）、所在地、問い合わせ先（フォームのURL）、配信停止のリンクを自動で付ける（`lead.mjs` の footer）。
- 配信停止: リンクを押すとすぐに「配信停止」になり、以降は送らない。同じアドレスで再び申し込んでも送らない。
