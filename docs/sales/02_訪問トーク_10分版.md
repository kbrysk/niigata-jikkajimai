# 訪問トーク 10分版（にいがた実家じまい帖）

方針: 売り込む前に聞く。実績はまだ無いので、無いと正直に言い、条件（最初の2か月は依頼が来なければ無料）で安心してもらう。数字は提案書に載せたものだけを話す。

## 持ち物
提案書（01）1枚、掲載契約書の案（03・弁護士等の確認前の草案と伝える）、名刺、PRの表示例（ad-policy.md）。

## 流れ（10分）
| 時間 | 内容 |
|---|---|
| 0:00〜0:30 | 自己紹介 |
| 0:30〜3:30 | 相手の集客状況を聞く |
| 3:30〜6:30 | 提案 |
| 6:30〜9:00 | 反応別の返し |
| 9:00〜10:00 | 次回アポ |

## 1. 自己紹介（30秒）
「長岡に住んでいる大久保です。株式会社Kogeraで、新潟の実家の片付けを案内する『にいがた実家じまい帖』を運営しています。県外から実家を片付けに来る方向けに、地元でお願いできる業者さんを載せたくて、お話を伺いに来ました。」

## 2. 質問リスト（3分・メモを取る）
1. 今のお客さまはどこから来ますか（紹介・自社サイト・ポータル・広告）。
2. 遺品整理や実家の片付けのご依頼は、県外のお子さまからが多いですか。
3. 自社の広告を出していれば、1件の依頼を取るのにいくらかかりますか（CPA）。
4. 紹介料を払うとしたら、1件いくらなら妥当ですか（遺品整理・不用品回収それぞれ。相場観）。
5. 対応エリアはどこまでですか。山間部や離れた市町村はどうですか。
6. 積雪期（12〜3月）に搬出できますか。雪下ろしや空き家の確認は受けますか。
7. 一般廃棄物収集運搬の許可はお持ちですか。ない場合、提携先はありますか。
8. 遠方の方へ、鍵の受け渡しや作業後の写真報告は可能ですか。

## 3. 提案（3分）
- 読者は県外の子世代。県内のごみ・分別・持ち込みの検索は月約8,200回（24_KW調査）。
- 掲載は市町村ページ・業者一覧・取材記事。掲載料は月額で、紹介料は1件ごと。
- 最初の2か月は依頼を渡せなければ掲載料は無料。最低期間なし、1か月前に連絡すれば解約できる。
- 広告は「PR」と明記する。

## 4. 反応別の返し
| 反応 | 返し |
|---|---|
| 高い | 金額は案です。先ほど伺った紹介料の相場観に合わせて調整します。 |
| 依頼は来るのか | 公開したばかりで、実績はまだありません。だから最初の2か月は依頼が来なければ無料にしています。 |
| 自社広告で足りている | 自社広告と重ならない、県外のお客さまとの接点として使ってください。 |
| 許可がない | 許可業者との提携を説明できれば掲載できます。説明できない場合は掲載できません。 |
| 個人情報は大丈夫か | 依頼者が業者への提供に同意した内容だけをお渡しします。契約書に取扱いを定めます。 |
| 考えておく | 提案書と契約書の案を置いていきます。2週間後に一度だけ、メールでご連絡してもよいですか。 |

## 5. 次回アポ（1分）
「来週か再来週、30分、条件と取材のご都合を詰めさせてください。」日時を決め、メモを残す。訪問後は当日中に進捗管理表（05）を更新し、お礼メール（04）の下書きを作る。
