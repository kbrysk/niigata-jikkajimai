# デザイン担当への引き継ぎ（コンテンツ担当から）

## 2026-10-05 build.mjs の変更（869c23c）
- 市町村ページの「〇〇の実家じまいで、次に読む」の直前に「〇〇について書いた記事」欄を追加。
- 抽出条件: タイトルに市町村名を含む／description が市町村名で始まる／targetKeywords が市町村名で始まる。町村（名前が町・村で終わる）には chouson-akiya-bank-niigata も入る。
- 件数: 長岡16本・新潟市17本、他の市町村は1〜3本。
- 理由: 市ページから同じ市の記事へのリンクが1本しかなく、内部リンクが弱かったため。
- お願い: 抽出ロジックは fixChk・cityDesc と同様に残してください。見た目（件数が多いページの折りたたみ等）の調整はお任せします。変更後は scripts/_qa_site.py で指摘0を確認してから push してください。

## 2026-10-05 トップの分類カードの並び順（同日）
- home() の guideCards で、各分類の先頭3本を HOME_PRIORITY（ラッコの月間検索数順の slug 配列）で並べ替えるようにした。配列に無い記事は後ろ。
- 理由: ファイル名順だったため、新潟市の粗大ごみ（月3,600）など検索の多い記事がトップから1本もリンクされていなかった。
- 新しい記事を優先したいときは HOME_PRIORITY に slug を足す。
